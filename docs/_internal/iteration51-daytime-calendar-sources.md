## Daytime-only common profile

The full configured futures pool across SHFE, INE, DCE, CZCE, CFFEX, and GFEX can use the common continuous-trading windows below on ordinary, non-holiday trading days:

| China Standard Time | Intersection basis |
| --- | --- |
| 09:30–10:15 | Starts with CFFEX day trading and ends at the commodity-exchange morning break. |
| 10:30–11:30 | Shared second morning session after the commodity-exchange break. |
| 13:30–15:00 | Shared afternoon interval; CFFEX index products end at 15:00, commodity exchanges start at 13:30. |

SHFE/INE and commodity-exchange daytime sessions start at 09:00, pause 10:15–10:30, resume to 11:30, then run 13:30–15:00. CFFEX index futures run 09:30–11:30 and 13:00–15:00; its treasury futures run 09:30–11:30 and 13:00–15:15, with the last trading day limited to the morning session. The common grid therefore excludes auction periods, night sessions, the non-overlapping 13:00–13:30 interval, and the extra CFFEX treasury-futures afternoon minutes. On a CFFEX treasury-futures last trading day, only the morning common windows apply. These profile choices do not remove any product or contract from the configured candidate universe.
