## 设计决定

1. 保留 `FactorStrategy + ResearchSpec + FactorPanel` 的离线研究边界，不删除其 live 拒绝检查。
2. 实时侧复用同一 `FactorSpec`、因子类、native/build 构图和 Cerebro 指标调度，增加薄的实时装配和决策入口；不另写公式或数值执行器。
3. 行情必须在指标推进之前形成同一闭合时点的整批输入。只在 `Strategy.next()` 检查时间戳不够，因为子指标届时已经计算。
4. 补上原始行情严格校验、闭合 bar 元数据与时间口径、开放式网格、预热切换、跨品种同步、缺格及迟到处理。
5. 因子结果到交易意图只增加必要的身份、就绪检查和持久决策记录。下单、撤单、成交、UNKNOWN 对账、租约、订单恢复继续复用现有执行链路。
6. 必须处理循环缓冲区索引和无限诊断列表，不能用关闭 `preload/runonce` 代替长期内存验收。
7. 全101因子在字段完整的合成流上验收；真实市场只接受具备真实字段和交易路由的具体因子、资产与账户范围。没有行业、市值等输入时不得声称全部101可实盘。
