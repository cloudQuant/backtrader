## 5. C 类 config 选层契约

### 5.1 确定性真值表（R5a）

`entry.tier` 规范值 `dry | replay | live`，`backtest` 为 `replay` 的文档别名（证据记 `effective_mode: replay` 与证据级别）。CLI 模式参数互斥，未识别 argv 继续拒绝。

| `entry.tier` | 无模式参数 | `--dry`（新增） | `--replay` | `--live` |
|---|---|---|---|---|
| 缺省 | dry | dry | replay | live |
| `dry` | dry | dry | BLOCKED `config_tier_conflict` | BLOCKED `config_tier_conflict` |
| `backtest`/`replay` | replay | dry | replay | BLOCKED `config_tier_conflict` |
| `live` | live 无写观察 | dry | replay | live |

- 非法值、错误类型、`entry: null`、配置解析失败一律在**任何 provider 副作用之前** `BLOCKED`；不得回落 live。
- **旧命令向后兼容是硬约束**：缺省（无 `entry`）时 `--live`、`--live --allow-write`、`--replay` 行为与改前逐字一致；把缺省当"上限"从而把 `--live` 降级为 dry 属实现错误。
- `--allow-write` 不选层、不因出现在离线命令中而启用写；有效通道为 live 时仍须满足原写授权、环境、候选准入与有界操作条件。
- 证据至少记：`config_requested_tier`、`cli_requested_tier`、`effective_mode`、`tier_selection_reason`、`write_grant_result`。

### 5.2 配置边界（R5a，回应 P1 03）

复用各例既有 `entry` 段（`012_1/config.yaml:49` 已含 venue/credentials/policy），在其中新增 `tier`：入口层严格校验 `entry.tier`，**校验后显式移除入口字段**再把投影交给原 replay/策略校验器（`015/legacy_runner.py:636,655-668` 这类 `_require_exact_keys` 需按例定向扩充允许集合并加负例），未知字段仍全面拒绝；旧 `mode` 保持原语义，不为迁就新入口字段而改成 live。逐一核查 C 类 `run.py`/`legacy_runner`/`run_runtime` 三条加载链。

## 8. 每轮迁移台账（P2 10）

每轮记录分列三类，互不混同：① Git 跟踪文件（`git mv` + rename 检测）；② 被忽略的私有文件（由原受控流程迁移，验证新路径访问规则、缺文件拒绝、旧路径不被隐式尝试，**不入 Git、不读其内容、不输出其值**）；③ 可重建产物（`output/`、`__pycache__/`、`logs/`、evidence、models、journal —— 不统称垃圾递归删除，已消耗 claim/generation/结果/保留 host 维持原限制）。

引用角色四分类：活跃源码（随迁移修正）、活跃文档（随迁移修正）、冻结测试材料（保留旧字节，由新适配器/新版本承接）、历史证据（只读，映射表说明）。

## 9. 明确不做

不扩 SDK、不注册 live runner、不重新执行历史已消耗的账户调用；不把 `007_ctp` 已封死的 legacy 入口借新增分派复活；不把 `sample`/L2 fixture 宣称为统一双通道示例；不重建 `010`/`ctp_options_simnow_*` 等已退役条目；不拆散 99 例目录；不为搬迁把私有 config 纳入 Git；不把根 manifest 与 approval 模块的移动与前序搬迁混提（各轮可独立 revert 与审阅）。
