## 2. 用例定义

### AC35-01 数据加载与启动校验（FR35-01 / D35-02）

- 前提/输入：`tests/datas/XAUUSD_M1.csv`；构造乱序日期行、low>high 行的两个坏副本。
- 操作：正常加载断言行数/时间范围（2021-08-12 03:02 ~ 2026-03-24 10:20）；坏副本分别启动。
- 预期：正常加载通过且 fromdate/todate 切片生效；坏数据以 `DATA_INVALID` 拒绝且退出码非 0。
- 证据：单元测试输出 + 启动日志。

### AC35-02 窗口构造正例与负例（FR35-02 / D35-03）

- 前提/输入：合成 2 个交易日 M1 序列：完整日、含 1 分钟缺口日、跨 00:00 边界时刻。
- 操作：对每根 bar 调用窗口构造；检查窗口序列长度=74 与 time-of-day 连续性。
- 预期：完整日有效；缺口落在窗口内的 bar 返回 `NO_WINDOW`；窗口起点 tod<0（跨日）不产生窗口。
- 证据：单元测试断言（含窗口边界 bar 的逐一枚举）。

### AC35-03 候选池对齐与取样（FR35-03 / D35-04）

- 前提/输入：合成 70 个交易日（其中 8 个日同时段缺 bar 或尾部不足 16 bar），当前日 d0 也有同时段窗口。
- 操作：构建候选池（lookback_days=60）。
- 预期：候选=从 d0 之前按日期降序收集的 60 个**有效**日（自动跳过 8 个无效日，即回溯至第 68 个历史日）；d0 不在池内；候选窗口与当前窗口 time-of-day 逐点相同。
- 证据：单元测试断言候选日期列表与对齐索引。

### AC35-04 Pearson 相关 oracle（FR35-04 / D35-05）

- 前提/输入：r=[0.01, 0.02, −0.01, 0.005]；候选=2r、−2r、r+0.1、[1,0,0,0]、常数序列。
- 操作：向量化相关计算。
- 预期：corr=+1.0、−1.0、+1.0、=0.2000（容差 1e-8）；常数候选 NaN 剔除。
- 证据：单元测试与独立手算值对照。

### AC35-05 方向调整统计 oracle（FR35-05 / D35-05、D35-06）

- 前提/输入：设计文档 D35-06 算例（正相关 5 个 + 负相关 3 个）。
- 操作：计算 adj、up_prob、expected_return。
- 预期：up_prob=0.75、expected_return=7e-5（容差 1e-10）；n_selected=8 ≥ min_matches=5。
- 证据：单元测试断言。另设 n_selected=4 < 5 用例断言 `INSUFFICIENT_MATCHES`。

### AC35-06 概率与期望门边界（FR35-06 / D35-06）

- 前提/输入：up_prob 恰=0.75、=0.749…、=0.25、=0.2501；expected_return=+ε、=0、=−ε。
- 操作：逐组判定。
- 预期：恰 0.75 → LONG（≥ 含等号）；0.749 → PROB_BELOW；er=0 或负 → NEGATIVE_EXPECTATION；0.2501 → PROB_BELOW；0.25 → SHORT。
- 证据：单元测试参数化断言。

### AC35-07 方向映射四象限（FR35-07 / D35-05、D35-06）

- 前提/输入：仅正相关候选（多数 fr>0）／仅正相关（多数 fr<0）／仅负相关（多数 fr>0）／仅负相关（多数 fr<0）四组。
- 操作：分别判定方向。
- 预期：依次为 LONG／SHORT／SHORT／LONG，与初始需求第 5、6 条文字规则逐字对应；同时验证与 adj 公式等价。
- 证据：单元测试四象限表。

### AC35-08 到期退出时序（FR35-08 / D35-07）

- 前提/输入：合成数据构造一次确定开仓；horizon_bars=15。
- 操作：推进 bar，检查成交/平仓的 bar 时刻与价格。
- 预期：t0 收盘信号 → t0+1 open 成交 → t0+15 收盘触发 close → t0+16 open 平仓；bars_held=15；数据末端未到期时最后 bar 强制平仓且 `forced_liquidation_count` 计数。
- 证据：TradeLogger trade.log 与 signals.jsonl 时间戳。

### AC35-09 止损止盈价格与 OCO（FR35-09 / D35-07）

- 前提/输入：D35-06/07 oracle（entry=2000.00，m_log=2.1e-4）；另造 bar 内触价序列。
- 操作：开仓后检查挂单价；构造触发止损的序列；构造触发止盈的序列。
- 预期：止盈 2000.4200 / 止损 1999.5800（相对容差 1e-8）；一腿成交后另一腿被撤销（无重复平仓）；stop_count 统计正确。
- 证据：单元测试价格断言 + order.log 的 OCO 撤销记录。

### AC35-10 单仓约束（FR35-10 / D35-08）

- 前提/输入：合成数据在持仓期间持续出现满足条件的信号。
