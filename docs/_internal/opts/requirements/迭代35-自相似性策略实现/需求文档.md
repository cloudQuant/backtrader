# 迭代35：自相似性策略需求

版本1.0；2026-09-20；需求与设计约束。实现与验收状态以[验收与追踪](验收文档.md)为准。

依据：[初始需求](初始需求.md)（逐字保留）。配套：[迭代计划](迭代计划.md)、[设计](设计文档.md)、[验收](验收文档.md)、[任务](任务.md)。
本迭代为本地研究型示例迭代：仅离线回测与参数研究，不连接任何实盘/仿真交易链路，不修改 backtrader 核心公共 API。

## 1. 目标与边界

基于 XAUUSD 1 分钟 K 线实现"自相似性"（日内同时刻模式匹配）规则策略，以独立示例目录交付，
支持单次回测详细日志与参数优化两种运行模式，并给出参数稳定性与样本外评估。盈利是需要样本
证明的研究目标，不是交付承诺；成本必须计入；样本不足或期望非正必须显式拒绝交易。

**范围边界**：不接入 BtApiStore/CTP/SimNow；不新建 examples 公共层；不依赖其他 `examples/`
目录；数据仅使用 `tests/datas/XAUUSD_M1.csv`（MT5 格式，2021-08-12 ~ 2026-03-24，约 163 万行）。

## 3. 术语与口径

- **交易日**：MT5 服务器日期（`DATE` 列）相同且时间升序的全部 bar 归属同一交易日；周末/假日自然无数据。
- **时刻对齐**：窗口锚点以"自 00:00 起的分钟数"（time-of-day）对齐；当前窗口与候选窗口起点时刻相同。
- **逐分钟收益率**：对数收益 `r_t = ln(C_t / C_{t-1})`；前瞻收益同口径（可加性、与执行换算精确一致）。
- **方向调整收益**：`adj_d = sign(corr_d) × fr_d`，其中 `fr_d` 为候选 d 的 15 分钟前瞻对数收益。
- **前瞻收益口径**：与回测执行口径一致——信号 bar t0 收盘判定，t0+1 开盘成交，持有 15 根 bar，
  t0+16 开盘平仓；统计 `fr = ln(Open[t0+16] / Open[t0+1])`。
- **概率门**：`up_prob = P(adj > 0)`；做多要求 `up_prob ≥ prob_threshold`，做空要求 `up_prob ≤ 1 - prob_threshold`。
- **预期收益**：`expected_return = mean(adj)`（对数收益）；开仓硬约束 `expected_return > 0`。
- **止损/止盈距离**：`m = exp(exit_multiple × expected_return) - 1`（做多）；做空对称。

## 4. 功能需求

所有 FR 均为 P0（除标注 P1）。验收 ID 在[验收文档](验收文档.md)逐项展开。

| ID | 必须满足的需求 | 通过标志 |
|---|---|---|
| FR35-01 | 经 `backtrader.utils.load_data.load_mt5_csv` 加载 XAUUSD_M1.csv；支持 fromdate/todate 切片；数据行数、时间范围、单调性启动校验 | 非法/乱序数据在回测前拒绝并给原因码 |
| FR35-02 | 窗口构造：最近 75 根 M1 bar，同交易日且 time-of-day 连续（每分钟一根，无缺口、不跨日）；窗口收益率序列长度 74 并缓存（key=bar 时间） | 缺口/跨日/长度不足不产生信号，不抛异常 |
| FR35-03 | 候选池：最近 60 个能提供完整候选窗口（同时刻对齐、时刻连续、且窗口后存在 16 根 bar 供前瞻统计）的历史交易日；排除当前交易日；不足 60 个时用现存有效者 | 候选数、逐日对齐索引可审计；假日/缺口日自动剔除 |
| FR35-04 | 相关性：当前序列与每个候选序列的 Pearson 相关；筛选 \|corr\| ≥ corr_threshold（默认 0.6）的候选进入统计集 | 数值 oracle（一致/镜像/平移序列）通过 |
| FR35-05 | 统一统计：对入选候选计算方向调整收益 adj=sign(corr)×fr；统计 up_prob 与 expected_return；入选数 < min_matches（默认 5）则放弃本次信号 | 正/负相关混合池的 oracle 算例通过 |
| FR35-06 | 概率与期望门：up_prob ≥ 0.75 做多、≤ 0.25 做空，且 expected_return > 0；任一不满足不开仓，原因写入信号日志 | 边界（恰等于阈值、er=0、样本不足）行为明确 |
| FR35-07 | 方向映射：做多当（正相关候选预测上涨）或（负相关候选预测下跌）；做空对称；由 adj 统一公式等价实现 | 四象限映射表与 adj 公式一致性用例通过 |
| FR35-08 | 到期退出：开仓成交后持有 15 根 bar，随后以市价平仓（下一根开盘）；平仓前撤销未触发挂单 | 持仓 bar 计数独立可审计 |
| FR35-09 | 止损止盈：以 expected_return 的 3 倍（exit_multiple 参数）按对数收益精确换算价格，开仓同时挂 OCO 止损/止盈单；触发后另一腿自动撤销 | 价格公式 oracle；触发后无重复平仓 |
| FR35-10 | 单仓约束：仅空仓时执行信号判断逻辑；持仓期间不评估新信号 | 持仓期间信号计数为零 |
| FR35-11 | 执行时序：所有信号在 bar 收盘数据完整后判定，以次 bar 开盘价成交；任何决策不得引用决策时点之后的数据 | 篡改 t+1 及之后 bar 不改变 ≤t 决策序列（审计用例） |
| FR35-12 | 参数化：窗口/持有/回溯天数/相关性阈值/概率阈值/最小样本/退出倍数等全部逻辑参数进入策略 params 与 config.yaml，均有默认值 | 参数表与 config schema 一一对应，无隐藏常量 |
| FR35-13 | 单次回测装配 TradeLogger observer（订单/成交/持仓/信号日志落盘到本示例 logs/）；同时输出 signals.jsonl 信号诊断流 | 日志文件存在且字段完整；MySQL 关闭 |
| FR35-14 | 优化模式：参数网格 × 并行（默认 8 进程）；每组仅输出最终指标行（净利/交易数/胜率/夏普/最大回撤等），不产生任何 per-trade/per-bar 日志 | 优化产物目录中日志文件数为零；结果行数=组合数 |
| FR35-15 | 标准结果：输出 backtest_result.json，字段对齐 functional 套件（rows/bar_num/buy_count/sell_count/win_count/loss_count/sum_profit/trade_num/stop_count/final_value/sharpe_ratio/annual_return/max_drawdown/return_rate）并扩展策略专属指标 | JSON schema 校验通过；口径定义见设计 D35-13 |
| FR35-16 | 目录结构：examples/016_self_similarity/ 含 config.yaml、run.py、self_similarity_strategy.py、README.md；从本目录可直接运行；不依赖其他 examples 目录 | 隔离运行退出码 0；导入图审计无兄弟目录 |
| FR35-17 | 数据质量：分钟缺口、假日、数据首尾预热/尾部不足均按"窗口不完整→不信号"处理；预热期（首日及候选池不足）显式跳过 | 构造缺口用例行为符合预期 |
| FR35-18 (P1) | 稳定性评估：训练/验证/样本外时间三分回测；选优参数邻域敏感性分析；报告区分结构性验证与经济性结论 | 三分报告与敏感性表落盘 reports/；OOS 只评估一次 |
