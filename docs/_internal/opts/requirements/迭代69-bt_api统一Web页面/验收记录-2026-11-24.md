## 3. 安全与会话边界

- 默认仅监听 loopback；客户端来源也限制为字面 loopback。Host 与 Origin 按精确来源检查，拒绝远程客户端、跨站 Origin 和非只读方法。
- 连接模式使用一小时内存 Web 会话；浏览器只把会话令牌保存在同源 `sessionStorage`，不签发会话 Cookie。退出、过期和 Web 进程重启会使会话失效。
- SPA 静态外壳可匿名加载，因为浏览器文档导航不能携带 `sessionStorage` 的 Bearer 头；外壳不含观察数据或凭据。`/api/v1/dashboard` 仍逐请求强制认证，未授权访问返回 401 并清除会话、回到登录页。
- 上游地址、服务令牌和来源配置只在宿主构造时确定；浏览器不能修改。上游私密字段、错误正文、重定向、代理环境变量和超限响应不会进入 Dashboard。
- 复核轮预算语义：宿主对每个组件最多等待 2.0 秒，五个组件并发读取；HTTP 读源单请求总截止 0.45 秒，Gateway 四页合计截止 1.8 秒。读源超时后即使工作线程仍悬挂，也会在宽限期后释放该组件的占用标记，后续轮询可恢复；同一组件已有读取未完成时不重复启动。单组件失败不影响其他组件，拒绝与未知可保留上一份成功快照并标记旧数据。
- CSP 默认 `frame-ancestors 'none'`；AFI 嵌入必须显式提供精确 `trustedHosts`。该字段只用于宿主策略，不写入浏览器 host-config。
- 未读取 `.env`、私有 `config.yaml`、账户凭据或私密捕获；未启动账户连接、下单、撤单或任何管理操作。
