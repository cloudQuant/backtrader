## 一页结论

1. **迭代35 的经济性被证伪但根因未定**：默认参数零交易（corr≥0.6 命中率 0%）；降阈值后 27 组参数全亏（夏普 −14.8~−0.17）。被证伪的是"同时刻 60 日池 + Pearson + 方向概率 0.75"这一特定组合，而非"自相似性"本身——候选池被压缩 4 个数量级、度量对相位漂移零容忍、小样本点估计无置信修正，三者叠加足以让任何真实规律漏检。
2. **最确定的杀手是成本**：信号期望 ~0.007% vs 双边成本 ≥0.04%（点差还没算），剪刀差一个数量级；SPREAD 列与滑点未建模。
3. **改进优先序（首推 4 项，成本极低）**：信号级 IC 框架（D36-084）、噪声对照实验（D36-083）、成本计入期望门（D36-038）、信号结构化数据库（D36-095）——先建立度量衡，再决定向哪个大方向投入。
4. **正交机会**：同一套匹配基础设施可承载但迭代35 未触碰的策略面——波动率预测（信噪比远高于方向）、公告后动量（NFP 后 15 分钟单边概率 89%/8%，文献先验最强）、日内时段/定盘价结构。

## 推进原则

- 每次后续迭代吸收 1~2 个方向按五件套流程立项，不大爆炸重写；
