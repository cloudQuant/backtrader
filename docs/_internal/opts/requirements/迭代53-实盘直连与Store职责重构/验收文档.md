## 验收矩阵

| 场景 | 方法与必需证据 | 合格结果 / 限制 |
|---|---|---|
| 无服务插件 direct 安装 | 全新隔离 wheel；只装 Backtrader、`bt_api_py`、base 与所选 exchange package；记录依赖树与来源。 | Store / Feed / Broker 可构造并连接 direct client；五个服务插件未安装；只证明安装 / 组合。 |
| 默认 direct 路由 | 不设置插件路由、按原 Store API 正常注入 SDK/client；验证缺少插件包时仍走 direct。 | 不要求新增 `direct` 显式开关；仅协议/身份/账户/交易所约束可拒绝。 |
| CTP SDK / facade mock | 在 §6.1 S3 后以 fake bt_api_py 统一接口和 fake provider leaf 覆盖订单、回报、撤单与身份映射；不引入 BT CTP 专用 adapter。 | SDK CTP 字段和 native/session/callback 合同由 bt_api_ctp 验证；BT 只验证 provider-neutral DTO 到 Order/Position/Feed/Broker 的映射；无真实登录、请求或账户操作。 |
| 其他 provider direct mock | 对每个已声明的 SDK package 通过 bt_api_py 统一 facade 和该 SDK 的 fake provider leaf 验证。 | BT 不为每个交易所新建独立 adapter；只接受已列能力，代码分支不等于真实账户可用。 |
| 无插件订单状态机 | 合成 Feed / Broker / Store；提交、接受、成交、撤单、拒绝、关闭。 | BT 状态、数量与通知匹配合同；不记为真实账户证据。 |
| 部分成交和撤单竞态 | fill-before-cancel、cancel-before-late-fill、重复事件、重连后终态。 | 幂等归并、数量守恒；顺序不确定保持 UNKNOWN。 |
| UNKNOWN / 超时 / 断线 | 请求前后、等待响应、回报前后崩溃；恢复只查原 id。 | 不换 id 自动重发；查询不足则阻断。 |
| reconnect | fake disconnect / reconnect、跨 generation callback、账户 / 订单 / 成交快照。 | 先对账再接新写；过时代次不得污染当前状态。 |
| execution 聚合（后续目标） | 多个注册 Strategy 同周期提交相同 / 相反信号，锁定 scope、策略版本、冲突规则。 | 所有信号有来源与结果；分配可复算，不静默丢弃。 |
| 拆单 / 算法（后续目标） | parent 分多个 child，注入 partial、限速、暂停、撤销、重启。 | parent-child、分配、费用、剩余量守恒；不重发未知 child。 |
| 父子额度守恒（相关能力实现时） | synthetic risk ledger 对相同 parent/child 分配、成交、拒绝、撤单、UNKNOWN 做幂等操作。 | 父额度只 reserve 一次，子额度从父预留拆分；confirmed terminal release，UNKNOWN 保留，不重复占用或重复释放。 |
| 风控顺序（相关能力实现时） | 记录聚合、父级风控、拆分、子级风控、journal、dispatch 的 event sequence。 | 父级先于拆分，子级先于对应写入；风险拒绝 / 故障不绕过。 |
| selected plugin fail-closed | 缺包、坏版本、初始化失败、超时、异常、清理失败。 | 未选插件时 direct 正常；选中后明示失败且不 fallback；按可观察边界核对写调用。 |
| Gateway / monitor / runtime | 无包环境跑 direct，再分别显式选择并注入服务故障。 | direct 不依赖它们；选中后不改账户；monitor 无写权限；失败不落回 direct。 |
| 本地合成服务 | 使用项目本地 synthetic service / fake API 注入连接、回报、故障与恢复。 | 可按普通测试流程运行，不需要真实账户额外审批；证据只标 fake/synthetic。 |
| schema / thread / 安装 | 临时 DB、多线程回报、崩溃点、版本化 wheel。 | journal 单写者、迁移边界明确、安装无 ambient dependency。 |
| external paper | 逐 provider 按明确账户 / 品种 / 数量 / 时间授权，核对真实回报。 | 只接受授权范围内场景，不外推 production。 |
| partial / disconnect 实际场景 | 在获准 paper 场景中观察自然发生的部分成交或断线；另有 fake fault injection。 | 自然场景未发生则记 `NOT_RUN`；fake 不能冒充真实事件，不强行制造风险。 |
| live read-only | 明确只读授权，验证未调用写 API。 | 只读证据不能升级为写权限或实盘下单通过。 |
| production live write | 符合用户已有有效授权；若授权不覆盖该动作，先取得具体账户、环境和操作授权。 | 本计划本身不授予授权；无证据即未执行 / BLOCKED。 |


真实账户验收属于独立证据层：仅在有效授权范围内由正式入口操作；没有条件时保留 NOT_RUN/BLOCKED。真实 partial/断线未自然出现时不强行制造；fake 只证明 fake。
