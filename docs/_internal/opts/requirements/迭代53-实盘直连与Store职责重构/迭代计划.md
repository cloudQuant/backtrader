## 工作优先级

1. 直接迁移已确定的 SDK 通用能力，并同步替换调用；service/runtime、risk、monitor、gateway、execution 只有按其真实职责和显式启用边界承接，避免新造重复机制。
2. 对所有 provider 按相同职责规则迁移并修复引用，不优先进行 CTP 功能闭环；在 BT 不引入交易所专用 adapter。已有会话、授权和 UNKNOWN 约束应原样保留，发现功能缺陷先登记。
3. 按来源核对账户/行情/对账和因子归属的事实及事务；活跃调用和 `backtrader_runtime` 必需能力全部有可追踪新 owner 后才关闭结构任务。
4. 对不同文件/owner 并行，单文件或共享状态指定唯一修改者；保留原始证据、未消费/已消费调用及历史受保留 host。记录范围与真实证据级别，不用文件数量估算进度。
