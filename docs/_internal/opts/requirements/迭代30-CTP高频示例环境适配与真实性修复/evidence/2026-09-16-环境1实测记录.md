### 4.2 `bt_api_ctp.ctp_env_selector.select_reachable_ctp_environment` 实测

```
env=set1 profile=set1_group1     -> profile=set1_group1_vpn  td=tcp://182.254.243.31:30001 md=tcp://182.254.243.31:30011 readiness=tcp_pair_reachable
env=set1 profile=set1_group1_vpn -> profile=set1_group1_vpn  （同一对）
env=set1 profile=set1_group2     -> RuntimeError: no reachable CTP front pair for the selected profile group
env=set2 profile=set2_7x24_4000x -> profile=set2_7x24_4000x  td=tcp://182.254.243.31:40001 md=tcp://182.254.243.31:40011 readiness=tcp_pair_reachable
env=auto  is_trading_day=True    -> profile=set1_group1_vpn
```

结论：

1. `set1_group1` 会在**同族内**自动回退到冻结备用对 `set1_group1_vpn`；
2. **`set1_group2` 本机无任何可达路径**，回退耗尽后失败关闭（不跨族）；
3. `auto` + 已验证交易日会选第一套，与"默认第一套"一致。

SDK 侧显式声明（`bt_api_ctp/ctp_env_selector.py` 注释与文档字符串）：备选对是"deliberately frozen and named"，选路"based only on TCP reachability of a complete TD/MD pair, never on VPN geography or the process's public IP address"。因此 profile 名中的 `vpn` 只是历史命名，不代表需要 VPN。

### 7.3 L2（quote 资格）在 CTP 原生路径不可达的源码依据

- `bt_api_ctp/feeds/live_ctp_feed.py:60-64`（回执类文档字符串）："The receipt deliberately contains no configurable qualification facts. ... until then, ``execution_qualified`` remains false."
- `bt_api_ctp/feeds/live_ctp_feed.py:1717-1745`：`_attach_managed_quote_v2_receipt` 以末两位参数 `False, False` 构造回执（`freshness_verified=False`、`execution_qualified=False`），并在文档字符串中说明"上传的公共元数据不能改变该回执"。
- `bt_api_py/bt_api.py:3202-3225`：父级证明要求 `receipt.get("execution_qualified") is True` 且各资格字段与行一致，否则不签发。
- `backtrader/feeds/ctpcohort.py:570-601`：cohort 校验要求 `quality_flags` 为空且 `execution_eligible is True`。

因此在本机 CTP 链路上，L2 结构性不可达，与 launcher 是否声明 `source_clock_quality` 无关。
