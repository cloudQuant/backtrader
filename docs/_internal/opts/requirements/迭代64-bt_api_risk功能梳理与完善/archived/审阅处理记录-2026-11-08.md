## 用户新决定

1. 已选 Risk 且资金预检为 deny，Execution 母单按整笔最坏情况预留，子单复用额度；off/warn 不由此变为 deny。
2. Risk 整体不可用时，拒绝新的开仓与平仓；撤单经 Gateway 发起。存储损坏不能仅依据 Gateway 当前账户快照恢复所有策略占用与未知状态，证据不足保持不可用，人工对账并按证据恢复。
3. 限仓、日内开仓量、交割月限制等纳入首期可配置检查：集中维护，通过 `config.yaml` 配置地址，使用时读取；首期只实现单账户。规则值、适用口径和数据来源不能由本次回答推定。
4. R-02 参考最新成交价；缺失或过期拒绝受该规则约束的开仓。开启价格带时，市价开仓和平仓都拒绝；限价平仓按既有 `apply_to_close` 决定该规则是否适用。
