## 新版提供的能力

6.7.13 CHM 的 `6.7.13BBGXSM.html` 第 1.3—1.4 节，以及 `JYJK/CTHOSTFTDCTRADERAPI/SUBSCRIBEPRIVATETOPIC.html`、`JYJK/CTHOSTFTDCTRADERSPI/ONRTNPRIVATESEQNO.html` 说明：新增 `THOST_TERT_RESUME_FROM_SEQ_NO`，可以指定私有流重传起点；新增 `OnRtnPrivateSeqNo(int nSeqNo)`，在处理私有流前通知即将处理的序号。这是可研究的回放锚点，不证明该序号的消息已处理、已持久化或流已追平。

本机公开源码 [bt_api_ctp/setup.py](/Users/yunjinqi/Documents/new_projects/bt_api_py/bt_api/bt_api_ctp/setup.py:18) 声明 API `6.7.7`；其 [Linux 头文件](/Users/yunjinqi/Documents/new_projects/bt_api_py/bt_api/bt_api_ctp/src/bt_api_ctp/ctp/api/6.7.7/linux/ThostFtdcTraderApi.h:568) 和 [Python 包装](/Users/yunjinqi/Documents/new_projects/bt_api_py/bt_api/bt_api_ctp/src/bt_api_ctp/ctp/ctp_trader_api.py:827) 的 `SubscribePrivateTopic` 仅接受一个重传模式参数；当前源码未接入上述新回调。Darwin ARM64 原生绑定另有 6.7.7 ABI 约束。升级必须核验匹配的头文件、原生库、SWIG director 与各平台 ABI；不能仅换动态库或补枚举。源码版本不等于实际运行或柜台版本。

## 仍未证明的共同切点

已查看的新版订阅、回调、订单查询和持仓查询章节未提供：回放追平完成的可验证标记；查询快照与该私有流序号共享的线性化水位；外部终端和其他会话的账户覆盖、清流及非成交持仓变化的完整证明。`bIsLast` 是单次查询响应的结束标记；订单行里的 `NotifySequence` 也不能因名称相似就当成 `OnRtnPrivateSeqNo`。这是对已查材料的范围性结论，并非断言厂商绝无其他专有接口。
