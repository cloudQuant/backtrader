6. **R-08 deny**：已复现缺费用、币种、策略预算与有效费率仍能放行，以及终态先于逐笔成交/账户快照覆盖时过早释放占用。完整覆盖证明未建立前，deny 对 OPEN 失败关闭，旧预留及母单同样检查；off/warn 不构成 deny 级保护。SDK 修复零可用资金被非零余额覆盖及跨币种回退，**GAP**。
7. **恢复与写者准入**：在当时的 SDK `4fa4f39c` 合成测试中，Gateway 有序重启后 Risk 在原进程清理确认后重注册并重放，旧命令不重发；该结果不适用于后续严格注销版本，见下文；清理或注销不确定则保留宿主及 writer fence。旧 run 状态查询不改变现有写者，旧许可写入核对原 run；母单及 Execution 子单服务写入口在资格合同缺失时，新请求拒绝；历史原身份重试保留 UNKNOWN 与原占用，仅授权状态可读。Registry 检查与 handler 的并发栅栏、控制/行情/账户 runtime 重连仍为 **GAP**。账户快照刷新曾有一次失败，随后单独及完整组重跑未复现，根因未定。
8. **非阻塞 writer fence**：先取得账户锁再初始化 SQLite；一般非阻塞 token 签发使用零等待并保留不同账户同库 BUSY 与同账户锁占用的区别。多进程与故障测试为源码/合成证据，Windows 错误分类仅 mock，实机 **NOT_RUN**。
9. **其他界限**：代理事件缺代理原生强身份键；Q39 跨日映射和内部转移依赖 63/65.03a；真实期货公司规则、完整行情和账户来源仍需单独证据。不得凭运行配置、路由名或哈希推断授权。

## 2026-11-13 注册不确定性与重启补充

SDK `2b6625c1` 将底层 `unknown_registration_count` 传入线程快照；清理只接受明确的整数零，缺字段、未知或非零均不得替换原 runtime。真实 ServiceRegistry 和模拟传输复现过“注册已提交、回复丢失”：注册表有 session，旧快照却错误认为清理完成；修复后保留原句柄，不重发业务命令。运行时、线程、Risk 客户端及服务定向 **352 passed**；异常重启两场景 **1 passed / 1 xfailed**，XFAIL 仅在观测到原注销不确定时严格触发，保留原始失败事实。

严格注销 ACK 工作区改动出现新的回归：Gateway 重启合成进程测试 1 passed / 1 failed，Risk 观察流 40 秒未恢复，因果待核实；此前 `4fa4f39c` 的重启通过仅适用于当时版本。公开 runtime 注入也曾绕过严格配置，正在修复，当前工作区未验收。

现有 runtime 在注销未确认后关闭 transport 并只保留未决数，缺按原注册身份、scope、epoch 和认证对端进行权威查询/撤销的恢复通道。新 epoch 或时间经过不能自行证明旧注册与迟到 handler 已失效；Risk 自动恢复仍为 **GAP**。对应恢复需与 Registry owner、Risk 原 journal/fence 及 UNKNOWN 原请求身份一并设计和故障验证。

## 剩余交付及解除条件

- **R-05 / Gateway 与 CTP owner → SDK → Risk**：Gateway 已有活动订单读取和账户事实流，但未提供可由 Risk 消费的同一账户、会话、交易日和来源的完整快照与流水共同切点，也未建立快照订单与事实流的可信强身份关联。CTP 现有策略基线仅接受空活动单；本机缓冲前后无变化也不能单独排除网络在途回报。须由 provider/owner 证明查询和回报衔接、发布受授权的版本化快照与切点，Risk 原子装载并按身份去重、断连或来源变化后失效及重建。不能证明时维持拒绝；Risk 检查后绕过路径的新单在观察之前仍有已知窗口。
- **R-03 / R-08 / Gateway、provider、Risk**：建立账户快照与事件覆盖的可比较凭据、资金币种和费用、策略预算及费率时效；Risk 需要按证明处理在途、终态待逐笔、迟到事实和重启，不得仅删除失败关闭条件。跨 63/65 的母单、内部转移和资金守恒须以共同回执联调。
- **R-04 / R-11 / Gateway、Risk、运营**：提供交易日开始的完整基线、报撤单/UNKNOWN 尝试身份及来源覆盖证明；完善规则文件的账户、合约适用性、来源、生效及过期合同，并取得实际规则。缺少期货公司确认时不自行填阈值。
- **R-07 / Gateway、provider、Risk**：提供来源有效期限、交易日、日初权益及覆盖当日的高水位；策略预算增减不能直接当损益，须提供独立来源绑定的净资金流调整 PnL 和调整后高水位。策略内部转移归属、费用或预算时点不完整时继续 UNKNOWN；CTP 现有独立账户查询不能拼作同一 Gateway 快照切点。
- **母子单 / Base、SDK、Risk、Execution**：Risk 专用写者资格、独立 Execution 客户端及 Registry 到 handler 的原子栅栏尚缺；现有 group policy 的 scope 与 Risk 不兼容。核心曾在 fake 测试中允许跨 venue/数量单位及不同主体关联旧母单；恢复前须绑定完整合约、单位、有效期、主体、run 与授权版本，旧 UNKNOWN 占用不释放。64.10 / 65.03a 共同联调前保持服务入口不可用。
- **政策发布 / Gateway、Risk**：明确并实现跨服务派发线性化与旧请求栅栏，覆盖已排队但尚未由 Gateway 派发时发布收紧的竞争。任何仅靠本地时间或查询不到命令的推断都不足以释放或重发。
