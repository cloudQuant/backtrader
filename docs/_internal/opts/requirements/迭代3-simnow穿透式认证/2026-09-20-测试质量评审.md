## 改进建议

### 1. 恢复模块缓存，消除测试间共享状态

**严重级别**：P1（High）  
**位置**：tests/unit/live_certification/test_simnow_penetration_certification.py:15  
**量表行**：H4  
**依据**：[test-quality.md](../../../../../.agents/skills/bmad-testarch-test-review/resources/knowledge/test-quality.md)

load_suite() 删除通用模块名后只恢复 sys.path，而不恢复调用前的模块对象。应使用 fixture
保存受影响的 sys.modules 条目，并在 finally 中恢复它们；这样任一用例可独立、任意顺序运行。

~~~python
@pytest.fixture
def loaded_suite():
    original = {name: sys.modules.get(name) for name in affected_names}
    try:
        yield _load_suite_without_global_leak()
    finally:
        for name, module in original.items():
            if module is None:
                sys.modules.pop(name, None)
            else:
                sys.modules[name] = module
~~~

### 2. 按主题组织认证契约测试

**严重级别**：P2（Medium）  
**位置**：tests/unit/live_certification/test_simnow_penetration_certification.py:29  
**量表行**：M4  
**依据**：[test-levels-framework.md](../../../../../.agents/skills/bmad-testarch-test-review/resources/knowledge/test-levels-framework.md)

将 23 个顶层测试分为“场景映射”“结果与对账”“运行时入口”“源码契约”等 pytest 类或独立模块，
使失败输出能立即指向主题。

### 3. 复用账户快照构造器

**严重级别**：P2（Medium）
