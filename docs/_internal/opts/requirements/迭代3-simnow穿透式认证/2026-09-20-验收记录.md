## 阻断的精确归属

1. 本仓的 direct CTP 路径仅能对 SDK 的“已登记券商仿真前置”调用
   arm_registered_sim_execution()；官方 SimNow 7×24 前置不属于该登记表，所以在任何写入前
   返回 ctp_execution_gate_environment_unverified。
2. ctp_gateway 兼容适配器也明确拒绝 place_order() 与 cancel_order()，以避免绕开受管
   SDK capability、arm 和 preflight。
3. 当前生效的 bt_api_py==0.15.3 是指向本机 SDK 工作区的 editable 分发；当前导入面未提供
   Backtrader 受管路径所需的公开 BtApi、GatewayClient 或
   CtpExecutionApprovalCapability。这只是当前安装/制品事实，不等同于把 SDK 源工作区的
   在途质量改动归责为缺陷。

因此，基础交易、报撤单监测、阈值触发、远端拒单、批量撤单和交易日志等依赖写入的场景均不能
在本轮开始。其余不写入场景也未通过正式的 33 场景运行器执行，统一保持 NOT_RUN，而非
根据本次会话探测推断 PASS。
