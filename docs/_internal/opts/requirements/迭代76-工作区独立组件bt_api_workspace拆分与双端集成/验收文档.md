  - `pyproject.toml`：`requires-python = ">=3.10"`，核心依赖仅 `pydantic>=2.5,<3`（零 SQLAlchemy、零回测引擎、零重依赖），可选 extra `[fastapi]`（`fastapi>=0.110,<1`，兼容 `C:\anaconda3` 与各 repo `.venv`）。
