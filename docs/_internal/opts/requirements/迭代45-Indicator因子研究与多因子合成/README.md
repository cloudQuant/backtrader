## 2. 本版重点

- 普通Indicator保留原line语义；同一个PanelFactorIndicator支持build表达式和__init__/next手写算法。手写模式真实初始化、self.datas接入同步资产视图，每资产独立输出线；共享grid屏障避免重复调度，正式结果通过get_dataset返回。
- 迭代45只实现next；迭代46完成全101 native；迭代47实现build/expression、相关算子增强和20式等价；迭代48完成全101 build。任何迭代不得把后续交付物提前标PASS。
- build是声明前端，算法交给底层PanelEngine/已注册算子；相关算子加到对应Indicator/共享指标类，native和build共用，不建立build专用第二套算子。
- 公式内部rank/scale/行业去均值与fincore事后评价变换分开；共同评价池、标签周期和权重不能改写原始Alpha。
- formula_universe覆盖预热；数据包括OHLCV、VWAP、ADV美元成交额、市值及三个历史行业层级，禁止未来分类回填。
- alpha101-v1明确排名、窗口取整、并列、数值域及min/max/power语义，公开工程约定与原文不充分定义之处。
- 20个代表式为#1、2、3、4、7、9、13、29、48、56、58、62、63、67、81、84、92、96、100、101；以独立参考、区别错误实现的用例和真实Cerebro模式一致性验收。迭代46/48的全101均复用这20式并新增其余81式。
- 全部所需算子还须单独测试，20个配方不替代101条依赖盘点；四迭代完成前不宣称101个生产类或101个build类已实现，不承诺原论文收益或所有资产都具有股票字段。
