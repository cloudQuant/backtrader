## 2. 本版实质修订

- 明确调用方提供的完整 UTC bar grid、日历/频率/Feed时刻声明、研究窗口与预热/尾部的关系；拒绝从主Feed或日期交集暗推研究日历。
- 明确配置对象与字典转换、`direction_overrides`、Feed重名检查和预计算收益的bar时序；同池比较写成明确的集合运算。
- 将研究局部严格错误传播列入R1前置交付。当前核心的部分恢复分支会吞异常或将非有限值恢复为0，仅包一层模板回调无法兑现失败语义。
- 列明fincore 14模块的复用/新增/范围外映射；IC、分位及质量损失独立，不套用旧清洗结果删掉可用IC。
- 保留eligible总分母，明确阈值等于可通过、严格大于才失败；补分段边界精确计数，修正ICIR输入夹具并增加并列分箱/零方差负例。
- 分开数据集身份、规范配置摘要和评价身份，绑定实际fincore算法修订；补类型化异常和导出/命令状态细节。
- 修正“核心无需pandas/绘图库”的错误承诺：保留已有安装依赖，保证研究功能不新增核心fincore依赖；明确两仓wheel安装和研究Python版本检查。
- 两例确定为各自独立的固定seed生成器，登记真实复制契约和入口清单，最终在strict模式下验收。

没有采纳的方向包括：直接以主Feed代替权威grid、因结构性损失删减候选分母、将min_quantile_assets任意提高到统计显著性门槛、为规避类型检查另起包、强制复用不符合缺失语义的KDJ或旧清洗模型，以及新增HAC/机器学习/动态权重。

## 3. 后续使用与变更规则

本轮完成的是文档整理，未开始R1，未实现任何拟议API、测试或示例。后续按用户安排启动开发，每轮执行“本轮实现→针对性验收→明确范围提交dev→下一轮”。fincore增量先提交，Backtrader再集成；无增量不制造空提交。
