## 3. 测试设置和断言摘要

设计文档 [DS45-05](设计文档.md#ds45-05-收益标签与分周期样本)、[DS45-06](设计文档.md#ds45-06-截面变换组合与样本池)、[DS45-07](设计文档.md#ds45-07-绩效与现有-fincore-差异) 和 [DS45-08](设计文档.md#ds45-08-结果损失与失败语义) 是公式、默认值、异常映射和样本顺序的唯一来源。本节只列独立手算 fixture 的设置和断言摘要。

所有微型分析调用显式设置 min_assets=2；F-ICIR3 以三资产输入显式设置 min_assets=3。触发分位路径时显式设置 quantiles 和 min_quantile_assets；除特别注明外用 quantiles=2、min_quantile_assets=1。通常设置 max_loss=0.35。全缺失样本的 UNEVALUABLE 用例可显式设置 max_loss=1.0 以到达结果状态，同时必须用同一输入另测默认 0.35 并断言 DataQualityError；不得自动放宽。每份 fixture 证据保存实际 EvaluationSpec，避免小样例误用生产默认阈值或分组数。

每个有效 signal variant（raw、oriented、transformed，以及 composite）都检查 Pearson 与 Spearman 两列。截面 rank 只转换因子 x，不转换标签 y；因此 F-IC3 的 transformed x 与 y 的 Pearson 仍为 4√3/7（约 0.989743），而 Spearman 为 1。不能把 Pearson(transformed_x,y) 错当成 Rank IC 或期待它等于 1。

### Alpha101-v1冻结算子profile与手算fixture

以下为本项目冻结的公开工程profile，供基础设施与代表式验证；这不是Alpha101原论文的唯一实现，也不构成历史绩效复现。alpha101-v1只定义算子语义，不在本方案重复101项公式表；公式身份和依赖映射由同目录Alpha101覆盖清单.md单独维护。

| 算子 | alpha101-v1固定语义 |
|---|---|
| rank(x) | 对当期有限值取平均秩并除以n；n=1时为1，n=0时缺失；并列不拆分。 |
| ts_rank(x,d) | 在完整d格点窗口中，对当前值取平均秩并除以d。 |
| scale(x,a) | a*x/sum(abs(x))，a默认1；分母为0时缺失。 |
| industry去均值 | 按该时点PIT research group逐组去均值；单成员组输出0。 |
| window/delay/delta参数 | 小数向下取整；window>=1，delay>=0。delay=0取当前格点。 |
| ts_argmin/ts_argmax | 返回窗口内位置，最老为1、最新为d；并列取最早位置。 |
| std/cov/corr | std和cov使用ddof=0；corr为完整窗口Pearson，常量输入时缺失。 |
| decay | 窗口最老位置权重1、最新位置权重d，并在窗口内归一。 |
| TS窗口 | 每个窗口使用完整研究grid上的d个位置；缺bar不压缩、不前值填补、不做其他插补。 |
| min/max解析 | native显式区分rolling ts_min/ts_max和逐元素min/max；迭代47的build才按RHS纯数窗口或表达式消歧，不能运行时猜测。 |
| 幂 | ^为普通实数幂；SignedPower(x,a)=sign(x)*abs(x)^a。0且a>=0得0，0的负幂缺失，普通0^0=1。 |
| 数学域错误 | log非正、除零、定义域错误或overflow产生NaN并带DOMAIN_ERROR；未预期异常或源输入±inf仍失败。 |
| comparison/where | comparison采用三值逻辑；where只依被选中分支的有效性决定结果，不能把NaN比较当False。 |
| 既有后处理 | postprocess到[-1,1]的既有行为不变，alpha101-v1不隐式替换。 |

### 8.1 输入错误

| 新公开配置校验错误 | `ConfigError(code=INVALID_CONFIG)` |
| Replay/live/tick/mixed-timeframe 或其他不支持时钟 | `ConfigError(code=UNSUPPORTED_CLOCK)`；时钟错误不另设异常类 |
| 必需输入缺失/多输入不对齐 | `DatasetError(code=MISSING_INPUT)` |
| schema 不兼容、摘要损坏或未完成数据集 | `DatasetError(code=INVALID_DATASET)` |

| `FactorLossExceededError` | 优先于基类判断并映射为 `DataQualityError(code=LOSS_LIMIT_EXCEEDED)`，保留结构化 report；只接受符合新损失口径的 report |
| EnhancedNonMatchingTimezoneError 或兼容 NonMatchingTimezoneError | `DatasetError(code=INVALID_DATASET)` |

| 旧 `MaxLossExceededError` 误入新研究路径 | 集成 FAIL；不把旧清洗入口中包含分箱损失的 report 冒充新口径 |
| 缺研究依赖、API 或 Python 前提 | `DependencyError(code=DEPENDENCY_UNAVAILABLE)` |
| Indicator/Line 公式的意外异常 | `FactorComputationError(code=FACTOR_COMPUTATION_FAILED)`，附 factor/asset/phase 并拒绝完整数据集 |
| 未知内部异常或未分类 ValueError | 保留异常并失败；不能猜作输入错误、缺失值或成功结果 |

所有异常保留原 cause 和可用结构化诊断；不以错误文本猜分类，也不把输入/数据质量错误归成“统计结果很差”。

### 8.2 数据覆盖和质量诊断

每个 signal × pool × group × horizon 都按设计文档 DS45-08 验证并报告覆盖：候选分母在因子可用性筛选、标签 mask 与分位处理之前确定，为研究区间内该 group 中已知 universe=true 的候选行数。每个 segment 的 eligible 分母保留该段完整候选数；SEGMENT_BOUNDARY 行不参与该段指标，但要留在 coverage/loss 分母。known false 单列 excluded；unknown universe 先产生诊断并以 DatasetError 拒绝封存完整数据集，不能静默删除后再计算分母。对 own、组合和 common 池均保留形成前 eligible 候选数；组合/common 的成员有效交集另报 pool-formation loss，不能先过滤 factor-valid 候选来缩小 max_loss 分母。

对每个 slice 分别报告因子损失、有限信号上的标签损失，以及 eligible 候选到有限 signal+该 horizon 标签配对的总损失；另列 qcut/标签筛选后的组样本数及每组缺失原因。max_loss 默认 0.35，按 DS45-08 以候选数和有效配对数验收；分位损失另以有限配对数为分母，单独报告，不重复计入 max_loss。任何显式覆盖值须随 EvaluationSpec 留证，禁止自动放宽。比较规则严格为 loss > max_loss 才超限；等于阈值通过。F-LOSS-THRESHOLD 先单独验证相等边界，再同一次请求一好一坏两个 slice，超限须使整次 evaluate 抛 `DataQualityError(code=LOSS_LIMIT_EXCEEDED)`，保留全部诊断且不返回部分成功结果。另精确记录 min_assets、min_quantile_assets、quantiles、horizon、方向、变换、组合权重与实际池成员。

### 8.3 分析结果状态

结果状态按设计固定为 OK、PARTIAL、UNEVALUABLE。请求的评价项全部符合合同且可用时为 OK；仍有有效结果但部分请求序列/指标退化或不可用时为 PARTIAL；没有任何可计算的请求评价截面时为 UNEVALUABLE，并保留空表 schema 和诊断。名称、参数、索引、时间或 schema 错误，以及未完成运行，不是结果状态，应以类型化 ConfigError/DatasetError 拒绝评价；缺依赖以 DependencyError 表达；损失超限优先抛 DataQualityError(code=LOSS_LIMIT_EXCEEDED)。采集可用性 reason 与评价指标退化 reason 分列。统一FactorIndicator基础可用性 reason 为 `READY`、`NOT_READY`、`NO_CURRENT_BAR`、`NONFINITE_INPUT`。所有因子按DS45-08的实际依赖还使用 `MISSING_FIELD`、`NOT_YET_AVAILABLE`、`UNKNOWN_CLASSIFICATION`、`FORMULA_INELIGIBLE`、`INCOMPLETE_WINDOW`、`DOMAIN_ERROR`；这些计算原因不得误记成IC退化。已定义数学域无效按profile记录NaN+DOMAIN_ERROR；意外异常或源±inf仍使采集失败。不得将无当前bar、预热不足或未知分类伪装为IC退化。

逐项 reason 按 DS45-08 精确断言，例如 INSUFFICIENT_ASSETS、CONSTANT_FACTOR、CONSTANT_RETURN、NONFINITE_INPUT、QUANTILE_DEGENERATE、MISSING_LABEL、NO_VALID_PERIODS、ZERO_IC_STD、SEGMENT_BOUNDARY、INVALID_ABLATION。分位退化只使该截面的分层指标不可用并记录 QUANTILE_DEGENERATE，不抹除样本合法的 IC；标签有效总样本少于 min_assets 时不计算该期 IC/分层收益；单个 quantile 组有效标签少于 min_quantile_assets 时只使该组均值缺失，spread 在任一端缺失时也缺失。常数 IC/零标准差 IR 不造 0。命令退出码与库结果状态分开：0=必需输出可用且验收通过，1=计算、数据或断言错误，2=缺依赖/输入等前置条件受阻，3=中断等运行结果未知。按 F-CLI-PARTIAL 做正反例：事前声明为可选的诊断缺失、所有必需输出有效时允许结果为 PARTIAL 且 CLI 退出0；该项若事前声明为必需，则相同缺失使 PARTIAL 且退出1。不得事后改 required/optional；UNEVALUABLE/空报告永不以退出码0表示通过。
