## DS45-01 分层与实现归属

```text
Backtrader dev
  Feed + ResearchSpec -> Cerebro + FactorStrategy
                        -> 普通 Indicator / 共享 PanelEngine + 公式图或手写Indicator
                        -> Collector -> ResearchDataset -> 保存/加载
                                              |
                                      fincore_adapter
                                              |
fincore dev                                   v
  标准面板 -> 标签 -> 当期分组/变换/组合 -> 分周期评价 -> 通用结果/表/图
```

| 所属 | 实施内容 | 边界 |
|---|---|---|
| Backtrader `backtrader/research/` | FactorSpec/ResearchSpec、FactorStrategy、普通Indicator采集、面板双模式/算子/调度、PIT输入绑定、ResearchDataset、fincore_adapter、示例装配 | 公式内部rank/scale/滚动相关/行业去均值归计算层；不得复制评价阶段的Pearson IC、ICIR、分位、标准化、组合或因子相关矩阵 |
| fincore `fincore.factor_analysis` | 标准价格标签、截面变换、固定组合、样本策略、全部统计、分析模型与分析导出 | pandas/数值输入，独立使用及测试不依赖 Backtrader |
| 用户 Indicator | 普通类的逐资产输出线；或PanelFactorIndicator子类的表达式图/手写多资产算法（DS45-11） | 不读取未来收益，不负责报告、评价共同池或自动订单；面板逐资产输出不冒充整个截面的单条BT线 |

新增分析能力必须先在 fincore 现有本地 `dev` 验收并提交，再由 Backtrader 现有本地 `dev` 接入该提交。没有 fincore 功能增量的轮次不制造空提交。两仓不得基于 `master` 重开本轮开发，也不创建新 worktree。

普通 Indicator 可以在自身 `__init__` 中声明线运算，或按 Backtrader 合同实现 `next/once`；并非要求公式只能写在 `Indicator.next()`。策略生命周期统一由模板承担，不要求用户继承 FactorStrategy 或覆写 `Strategy.next()`。FactorStrategy 不调用买卖、平仓、撤单等 Broker 写接口；默认 Cerebro Broker 的存在不使该研究入口变成交易策略。

## DS45-02 公开入口与配置合同

### 2.1 目标使用方式

```python
# 拟议接口；尚不能直接执行。
from backtrader.research.factor_strategy import FactorStrategy
from backtrader.research import ResearchSpec, load_dataset, evaluate_dataset

cerebro.addstrategy(
    FactorStrategy,
    research=ResearchSpec(
        grid=closed_bar_grid,          # UTC close_time 索引，含 open_time 列
        start=research_start, end=research_end,
        targets=("A", "B", "C"),    # 实际例子至少 20 个资产
        source_timezone="Asia/Shanghai",
        calendar_id="synthetic-weekday-v1", frequency="1session",
        feed_time_kind="close_time",  # Feed 已映射到真实收盘时刻
        snapshot_id="local-example-v1",
        price_basis="synthetic_unadjusted",
    ),
    factors={
        "close_ma": {
            "indicator": CloseMAFactor, "params": {"period": 20},
            "line": "factor", "direction": 1,
        },
        "roc": {
            "indicator": ROCFactor, "params": {"period": 20},
            "line": "factor", "direction": 1,
        },
        "kdj": {
            "indicator": KDJFactor,
            "params": {"period": 9, "period_dfast": 3, "period_dslow": 3},
            "line": "J", "direction": 1,
        },
    },
)
strategy = cerebro.run()[0]
dataset = strategy.get_dataset()
dataset.save("research-data")
result = strategy.evaluate(
    preprocess="cross_section_rank",
    combinations={"equal_weight": {"close_ma": 1, "roc": 1, "kdj": 1}},
    periods=(1, 5, 20), quantiles=5, min_assets=10,
    label="next_open_to_open",
)
result.export("research-report", charts=True)
# 相同评价入口；无需导入因子类、创建 Cerebro 或执行 Indicator。
result = evaluate_dataset(load_dataset("research-data"), periods=(1, 10))
```

单因子只保留 `factors` 的一个成员，省略 combinations；不是另一个策略类。示例省略的参数均使用下表默认值，`research` 不省略。数据/日历元数据不足时拒绝猜测；原计划只有 `factors` 的短示意需补齐 ResearchSpec 才是完整调用。

### 2.2 三类配置

| 配置 | 字段与约束 |
|---|---|
| FactorSpec | 唯一非空因子名；`indicator`是类而非已绑定实例；`execution="indicator"`为默认，params由实际构造函数校验、line必填、inputs默认`("target",)`；`execution="panel"`要求PanelFactorIndicator类及显式panel_mode：expression的params由build签名/声明校验；next的params走真实Indicator参数初始化，panel_line必填且指向每资产输出schema。两者使用field_bindings、classification_bindings与operator_profile，禁止普通line/inputs；expression禁止panel_line。direction为+1/-1且拒绝bool；最终结果统一为每time/asset一个标量 |
| 多输入 FactorSpec | 例如 `inputs=("target", "feed:BENCH")`，按顺序作为 Indicator 数据参数；BENCH 必须已加载且不在 targets 中；每目标资产单独构造一次实例，基准 Feed 可共享；普通indicator模式仍只支持目标加一个显式基准；全截面公式使用panel协议，不能把任意Feed列表塞入普通模式；pair输出不在范围 |
| ResearchSpec | 必需 `grid/start/end/targets/source_timezone/snapshot_id/price_basis/calendar_id/frequency/feed_time_kind`；`groups` 为资产→研究组的静态映射，缺省全部 `default`；`universe` 可为 `(time, asset)` 布尔 Series，缺省 targets 在研究区间内一直 eligible；若提供则须覆盖全部研究窗口 grid×targets，缺失成员为未知并记数，返回 DatasetError，不默认为 true 或 false |
| EvaluationSpec | 默认 `periods=(1,5,20)`、`label="next_open_to_open"`、`quantiles=5`、`min_assets=10`、`min_quantile_assets=1`、`preprocess="cross_section_rank"`、`max_loss=0.35`；combinations 默认空；分析收益默认原始简单收益；不新增评价阶段行业/市值回归中性化；公式内部行业去均值另见DS45-13 |
| EvaluationSpec 比较/分期 | `comparisons` 默认空，非空时为 comparison_id→基础因子或组合名称序列（至少两个）；每个组合另有默认自身比较族。`segments` 默认空，非空时为名称→`(start,end,role)`，UTC grid close_time 闭区间、互不重叠且在研究区间内；role 为 development/validation，名称和role都只是声明，非独立样本外证明。完整研究期结果保留，分期结果另列 segment_id |

EvaluationSpec 另含 `direction_overrides={}`（已存基础因子名→+1/-1，拒绝未知键及 bool）与 `precomputed_entry="next_open"`（只在 label=precomputed 生效，可选 signal_close；时序见 DS45-05）。价格模式下显式设置 precomputed_entry 非默认值视为无关配置并拒绝，避免以未生效字段改变身份。

周期是唯一的正整数集合，拒绝 bool；规范化排序供稳定输出。quantiles 是整数且 >=2，min_assets 是整数且 >=2，min_quantile_assets 是整数且 >=1。max_loss 必须是有限实数且 0<=max_loss<=1，拒绝 bool。初版不开放自定义分位边界、bins、zero-aware 或自动缺失重分权重。组合名称与因子名不得冲突，组合成员必须存在；显式零权重成员仍属于该组合的必需因子集合，删除成员应从配置中移除。

targets 及 `feed:BENCH` 使用 `cerebro.adddata(data, name="...")` 的显式名称解析到同次运行已加载 Feed；不按数据列表序号、CSV文件名或模糊匹配绑定。所有参与 Feed 必须有唯一非空显式名称，未知或重名拒绝；不额外引入第二套隐式命名规则。

名称校验必须遍历原始 `cerebro.datas`/策略 `datas` 列表，不能只查会覆盖同名键的 `datasbyname`。FactorSpec、ResearchSpec、EvaluationSpec 采用明确的不可变配置对象；factors 字典只作为 FactorSpec 的一次性便利转换。`evaluate(**kwargs)` 与 `evaluate_dataset(dataset, **kwargs)` 将关键字统一转换为同一个 EvaluationSpec；拒绝未知键，不设 spec+kwargs 双入口和静默优先级。评价配置规范化由 fincore 的公开校验器实现一次，Backtrader 直接调用。

ResearchSpec 的具体约束：grid 是 `pandas.DataFrame`，索引为名为 `close_time` 的 UTC DatetimeIndex，必需列 `open_time` 为 UTC datetime；start/end 是有时区的 Timestamp 或 ISO8601 字符串，转 UTC 后必须是 grid 内端点且 start<=end。targets 是非空唯一字符串序列；source_timezone 是有效 IANA 时区名称。snapshot_id、price_basis、calendar_id、frequency 均为非空字符串；price_basis 必须指向明确的币种/复权/换月说明，不能只填“默认”。feed_time_kind 只接受 `close_time`，Feed 须由调用方提前映射为真实收盘时刻。frequency 描述一个 bar 的语义（如1session/5min），不是自动生成历法的规则。

grid 由调用方依据声明日历提供，涵盖预热、研究窗口及尾部；模板不自动选择主 Feed，不对 Feed 日期取交集，也不从 weekday 推断真实交易所日历。Feed 实际 bar 必须落在 grid；重复、倒序或 grid 外数据拒绝。groups 若非空须恰好覆盖 targets，值为非空字符串；默认同组是调用方对可比性的显式接受，系统不按 ticker 猜市场。universe 的 MultiIndex 名为 `(time, asset)`，仅包含研究窗口×targets，值为无缺失 bool；此处universe是评价资格，窗口外不要求它。panel另有覆盖预热至研究end的formula_universe（DS45-12）；不能用只覆盖研究窗口的评价universe替代历史公式池。

方向可在离线评价时通过已记录的 EvaluationSpec 显式覆盖，但不能修改原始面板或原采集 FactorSpec。输出同时记录原始声明和本次覆盖。Indicator参数、输入绑定、输出线、面板公式图、operator_profile、formula_universe及历史分类不能通过离线评价改写；它们改变因子定义或计算环境，须建立新的计算数据集。纯评价改权重、标签h、比较池不得重算原始公式。

## DS45-03 数据模型与可复现性

| 数据对象 | 索引/字段 | 不变量 |
|---|---|---|
| grid | 严格递增、唯一、带 UTC 时区的 close_time 索引；open_time 列 | 每行一个研究 bar；open_time < close_time，后续 bar 不重叠；可有周末/午休等真实间隔，必须来自声明日历 |
| raw_factors | 唯一 `(evaluation_time, asset)`，每个因子一列 float64 | evaluation_time 是 grid 的 close_time；研究区间内 eligible 行保留缺失；无正负无穷参与计算 |
| prices（标签价格） | open/close 两个 time×asset 数值矩阵；不是完整公式输入，panel输入另见DS45-12 | 行按完整 grid；包含预热和价格尾部；缺行重建为 NaN，不删除网格行或填价格 |
| precomputed_returns（可选） | `(time,asset,horizon)` 的 value、entry_time、exit_time、label_id、单位与语义 | `label="precomputed"` 从该存储表取值；不依赖隐藏外部回调；缺所请求h则 DatasetError；价格模式不强制要求此表 |
| availability | `(time,asset,factor)`，ready、valid、reason、各输入实际时间、available_at | valid 意味着输入满足时钟/就绪且数值有限；NaN 不能兼作唯一诊断 |
| universe/groups | time×asset eligibility，静态 asset→research_group | 同一期同一资产只属于一个研究组；不按未来收益筛选成员 |
| provenance | schema、两仓提交、库版本、数据来源/快照、日历/时区/价格口径、因子定义/参数/输出/输入、研究范围 | 缺少 provenance 不宣称可复现；价格币种、复权、合约换月规则由输入方明确 |

本轮一次 run 只有一个可比研究 grid。不同交易日历/收盘时刻分开运行；可在共享 grid 内按静态研究组分别排名和评价，不自动合并美国收盘与亚洲同名日期。不输出跨组混合 IC 或跨币种实际组合收益。组的含义是研究可比性，不等于行业。panel公式在各研究组的formula_universe内计算，行业分类另存，不得以groups代替sector/industry/subindustry。

Backtrader Feed 时间常用内部 UTC 数值表示。适配应按其公开日期转换合同恢复 UTC；`source_timezone` 仅解释原始 naive 时间，不能给已是 UTC 的时间二次本地化。一个输入源不得混合 naive/aware。日线若以交易日期零点标记，输入方须按明确 session 日历预先映射为 close_time；不得以固定偏移猜测所有市场收盘。归一化后必须唯一且单调。

raw_factors 只含研究区间；prices/grid 含预热及尾部。正常运行完成后封存快照，评价不原地修改数据。中途异常的采集可保留诊断，但不能标作完成数据集交给正式 evaluate。

## DS45-04 时钟、就绪与多输入

1. 普通indicator模式下，FactorStrategy在`__init__`构造目标资产×因子实例；panel模式按DS45-11只编译声明一次、不构造普通Indicator实例；`prenext/nextstart/next` 调用同一公共采集路径。就绪检查使用每个实例的实际最小周期及输入状态，不把策略的全局最小周期当作所有资产门槛。
2. 初版仅接受离线历史、已闭合的规则 bar。Replay、live、tick、混合周期/resample 时钟未纳入支持，检测后返回 `UNSUPPORTED_CLOCK`，不得猜测当前 bar 已最终确认。runonce/runnext 两个普通历史执行路径必须一致。
3. 采集在该策略回调完成各 Indicator 本轮更新之后读取当前槽位。只有数据的实际当前 bar 对应本次 grid 时点才取值；缓存停在前一时点的资产记 `NO_CURRENT_BAR`。同一 bar 重复回调按键幂等，不追加样本；相同键不同值报冲突。
4. 评价截面在完成的原始因子快照上由离线fincore按`(time,group)`聚合；公式内部截面在PanelEngine每个完整grid步骤内按依赖顺序计算（DS45-11）。两者不能替代，均不得在某资产先到达时提前排名。缺失 grid 行在封存时补齐缺失记录，不补市场值；次要数据或首个 Feed 提前结束不能丢掉其他资产后续观测。
5. 普通单输入模式下，晚开始资产在自身预热后参与，其此前缺失不阻塞已就绪资产。单输入 Indicator 的 period 仍遵循其原有“该 Feed 已观察 bar 数”语义；停牌后一个 20-bar Indicator 不自动变成 20 个统一网格 bar。元数据与文档必须区分这个公式窗口和标签 h。
6. 普通indicator模式的目标+基准要求目标计算区间（含所需预热）内两输入位于相同、完整的 grid，允许基准有更早历史。缺基准、缺任一输入 bar 或时钟错位必须在前置校验/首次发现时拒绝整次运行，给 `MISSING_INPUT` 或 `UNSUPPORTED_CLOCK`，不产生可标为完整的数据集；不继续用缓存值，不承诺任意多输入缺口的状态恢复。这与单输入运行的局部缺bar处理是两个模式。其他目标可以有不同上市起点，只要各自的多输入计算区间满足合同。
7. 可用时间不得晚于 evaluation_time。行情之外的财务/外部特征由调用方提供真实可用时间和历史版本；本模板不会验证财报数据库的真实性。原始数据存在未来引用时，Indicator 继承关系不能使其自动变得无泄漏。

就绪与记录窗口分开：从 grid 中目标首个实际 bar 起计算全部已提供历史，使用实例最终解析的 minperiod；不按 universe 或研究 start 先裁掉预热。minperiod 满足不代表输出必然有限。基准须覆盖目标从首个实际 bar 到研究 end 的完整计算区间，不自动截短来掩盖缺口。保守合同可能使一个坏目标阻断整次多输入采集；可显式另开运行，但不同 grid/池的独立结果不能冒充同次公平比较。

本 fork 的 `Strategy._periodset()` / `_resolved_secondary_clock` 是非首 Feed Indicator 的时钟依赖，R1 必须用真实 Cerebro 验证。覆盖声明式 Line 运算、自定义 next-only（含 once_via_next 桥接）、显式 once、首 Feed 晚开始/提前结束、非首 Feed 因子，不只比较同步主 Feed。

**严格计算错误传播是 R1 前置交付。** 当前 `LinesOperation.next/once` 等兼容分支会捕获部分异常，另有非有限值转0的恢复逻辑；模板回调外的 try/except 无法恢复已吞掉的事实。因此研究运行须新增局部严格错误策略，只作用于该研究实例及其依赖图：在公式异常的源路径传播或记录并终止，禁止把异常/无穷恢复成有效0，退出时恢复原策略；普通回测默认不变。不能用扫描日志、全局猴子补丁或只包用户 next 代替。R1 盘点并覆盖可达 next/once/桥接/子运算恢复点；做不到就停在 R1，不封存“完整数据集”。合法显式 NaN 可记 NONFINITE_INPUT 缺失；正负无穷视为计算失败并抛 FactorComputationError，不能恢复0。用户自己捕获异常并返回有限值的内部行为不在框架可检测承诺内。

用未来数据扰动检验观察截止时点之前的 raw/transformed/composite 不变；保持时间戳/资产池不变、仅改变未来值。标签只在对应未来区间内变化。任何核心 clock/minperiod 修改都触发仓库规定的策略回归，不以改全局调度绕过采集问题。

## DS45-05 收益标签与分周期样本

grid 位置为 t，h 表示研究 bar 数，非自然日：

| label | 公式 | 边界 |
|---|---|---|
| close_to_close | `close[t+h] / close[t] - 1` | 统计标签，不意味着收盘信号能同价成交 |
| next_open_to_open（默认） | `open[t+1+h] / open[t+1] - 1` | 信号在 t 收盘可用；必须多备 h+1 个后续 bar |
| precomputed | 调用者的 `(time,asset,horizon)` 收益 | 同时提供 label_id、单位、入口/出口时点和价格语义；验证索引/时序，不保证外部公式正确 |

价格比值的分子/分母必须有限且严格为正；否则该标签缺失并记录原因。可能为负价的期货或需要乘数/换月/资金费的收益应提供有定义的 precomputed 标签；不强行用正价简单收益合同解释。预计算收益只要求有限，是否能小于 -1 由声明的收益语义决定，不与真实账户简单收益混称。

本轮 precomputed 的 horizon 同样是唯一正整数 bar，不支持任意自然日/duration 持有期。`precomputed_entry=signal_close` 要求 entry_time=grid.close_time[t]、exit_time=grid.close_time[t+h]；`next_open` 要求 entry_time=grid.open_time[t+1]、exit_time=grid.open_time[t+1+h]。一张数据集中的 label_id/单位/entry 模式须一致并记入元数据，评价配置必须匹配；若另有收益族须另建数据集。entry/exit 以实际时刻同时校验所属 bar，分段按所属 bar membership 判定，不能把首日开盘早于首日收盘误判为跨段。

在完整 grid 上 shift，不在各资产删去缺失的价格序列上 shift。h=20 的缺失只影响 h=20。分位归属由当期有限分数/资产池先计算，再把相同归属与各 h 的有效标签分别配对；不以未来是否有价格改变当期排名或分箱。

公开 horizon 用 `1bar/5bar/20bar` 及整数 bars 表示，另列 grid frequency/calendar。不得把 5 个交易 bar 假装 5 个自然日，或将分钟数据统一写成 `1D`。若现有 fincore 模型仅接受 duration 列名，在 fincore 增加保留 bar 身份的公开桥接；Backtrader 不伪造频率绕过校验。

时间分段通过显式 close_time 区间配置。每段评价要求信号及标签入口/出口所属的 grid bar 均在该段内（按bar membership，不按开盘时刻与首bar收盘边界直接比较），跨段尾部标签剔除并单列 `SEGMENT_BOUNDARY`；不能把测试段收益计入训练段评价。样本外段开始前的合法历史可以用于 Indicator 预热。配置/方向/权重须在样本外报告前冻结；本轮不训练、不自动择优，也不把事后命名为“样本外”当成独立验证。

## DS45-06 截面变换、组合与样本池

### 6.1 数值规则

同一 `(time,group)`，先确定仅依赖当期信息的池，再按方向变换原值，随后按列处理：

| 步骤 | 定义 |
|---|---|
| direction | `oriented = direction * raw`，方向是先验配置，不用全样本 IC 决定 |
| cross_section_rank | 有限值平均秩 r，n>=2 时 `2*(r-1)/(n-1)-1`；并列共享平均秩；常数且 n>=2 得全 0 并标记退化，n<2 不可变换 |
| cross_section_zscore | `(x-mean(x))/std(x,ddof=0)`；std=0 得全 0 并标记退化，n<2 不可变换 |
| fixed combination | 权重有限、非负、和>0，按因子名归一到和1；score 为转换列加权和；权重不是资产持仓 |

评价阶段只提供这两种preprocess，不新增winsorize、行业回归或缺失填补。Alpha101公式内部的rank/scale/行业去均值属于DS45-13，不能复用此处不同的数值口径。默认全部选定因子有效才生成组合分数；零权重成员也遵循显式成员合同。未就绪/无穷/NaN 不填 0，不按可用成员动态重分权重。常数因子变换成 0 可参与组合，但其贡献和退化必须记录；该单因子 IC 为缺失。

### 6.2 池与公平比较

| pool_id | 构造与用途 |
|---|---|
| own:<factor> | 当期 eligible 且该因子有限的资产；独立单因子 raw/oriented/transformed 报告 |
| own:<combination> | 当期 eligible 且该组合所有成员均有限的交集；在此重新变换后合成 |
| common:<comparison_id> | 一个比较集合涉及的所有基础因子之交集；比较中的每个基础因子/完整组合/消融组合都在此重新变换 |

单个组合默认生成自己的 comparison_id（完整成员池），包含基础因子、完整组合和逐个删除成员后的组合。多个成员集合不同的组合，若请求相互公平比较，comparison 配置显式列出它们，取成员并集所需的有效资产交集；不得把各组合 own 池直接拼表称为公平增量。

消融不扩大原完整组合池；剩余权重归一，若剩余正权重和为0则该消融 `INVALID_ABLATION`，不可悄悄等权替代。三因子等权例子必须有三个合法消融。组合配置可单独复评，多组权重不重新调用 Indicator。

同 h 的公平表使用相同资产标签掩码；若某信号因常数等原因没有合法 IC，表保留缺失。两个方案的 delta_IC 及均值差只使用双方均有合法 IC 的同一日期/组，报告 paired_period_count；不拿各自有效日期的无配对均值差宣称提升。

明确集合运算：令 M(s) 为信号 s 依赖的基础因子集合（基础因子自身为单元素集）；比较族 C 所需成员为 `M_C = union(M(s) for s in C)`，共同池为 `eligible(time,group) ∩ intersection(finite(f,time) for f in M_C)`。这里对“因子名”取并集，对“有效资产集合”取交集。形成池时不读取任何未来标签。

公式计算池与评价池严格分开：own/common/消融的“重算变换”仅指本节方向、排名或Z-score及组合。它们不能回写formula_universe，也不能重算Alpha公式内部任何历史rank、scale或行业去均值。要研究另一股票池下的Alpha，需显式修改计算配置生成新dataset_id。

### 6.3 分位归属

在对应池的有限分数上使用 fincore 的公开分位逻辑，固定为 pandas `qcut` 等频语义：线性分位边界、右闭、最低边界包含最小值，编号1..q。重复边界、空组或无法形成 q 个非空组时，该截面的分位指标不可用，记录 `QUANTILE_DEGENERATE`；不拆相同值，不 `rank(method="first")` 打散，不自动降低 q。

分位失败不删除本来可计算的 IC。每周期配对后总样本数须 >=min_assets 才计算 IC/分层收益；每个分位有效标签数还须 >=min_quantile_assets 才给该组均值，否则仅该组缺失，最高减最低差在任一端缺失时缺失。分位编号本身不按标签重新生成。

## DS45-07 绩效与现有 fincore 差异

| 结果 | 固定口径 |
|---|---|
| Pearson IC / Rank IC | 当期同组同池有限分数与对应 h 标签配对后的 Pearson / Spearman；同值用平均秩；样本不足、任一变量常数返回缺失及原因 |
| IC 汇总 | 每 signal/variant/pool/group/h 的有限 IC 等权时间均值、std(ddof=1)、ICIR=mean/std（不年化）、正值占比=count(IC>0)/count(finite IC)，0计入分母；0期均缺失，1期仅均值/正值比可用，std/IR缺失 |
| 分层收益 | 当期分位内资产等权简单收益均值，默认不 demean、不 group-adjust；最高组减最低组为研究收益差；跨日期汇总先算每期均值再等权平均，另报样本量 |
| 稳定性 | 月度/显式区间 IC 汇总；基于完整 grid 的因子秩自相关与分位成员换手，默认 lag=1bar，按配置可多 lag |
| rank autocorrelation | 各期各自在该池的平均秩，取 t 与 t-lag 共同资产作 Pearson；两期排名先分别计算，再求共同资产相关；至少 min_assets 且非常数，缺期不压缩日历 |
| quantile turnover | `cardinality(Q_t \ Q_(t-lag)) / cardinality(Q_t)`；分位集合取标签过滤前成员；任一期分位不存在/空组或前置期不足则缺失，不能把空白期跳过后与更早日期比较 |
| 因子相关性 | 每期/组计算 Spearman；own 视图按每对有限因子交集，common 视图按声明共同池；至少 min_assets，非常数；时间汇总对有效期等权平均，另报每对 n_assets 和 n_periods |
| 比较与推断 | 输出共同池及 paired delta_IC；IID t 检验若展示必须标注 IID/重叠限制，不宣称 HAC；不以未经多重试验控制的 p 值选方向/权重 |

基础因子的 raw、oriented、transformed 三个 variant 以及组合的 composite variant 均输出两种 IC；其他绩效表也显式带 variant，不以处理后的值冒充原始值。Rank IC 在严格单调变换下不变，而 Pearson 可以变化。只对因子 x 排名并不等于对收益 y 也排名，不能把 Pearson(transformed_x, y) 当作 Rank IC 的替代。

rank autocorrelation/quantile turnover 不依赖 h 的未来收益，不把同一序列复制后伪称多个独立证据。默认不生成累计收益净值；分层均值不可逐日复利重叠的 5/20-bar 标签。

## DS45-08 结果、损失与失败语义

通用结果拟称 `FactorResearchResult`，由 fincore 定义；Backtrader 可以附加采集来源，不能重算统计。最小结构如下：

| 成员 | 必需内容 |
|---|---|
| manifest | schema_version、dataset_id、evaluation_config_sha256、evaluation_id、fincore_algorithm_revision、规范化配置、库版本/源码提交、时间/单位、状态 |
| signals | `(time,asset,signal,variant,pool_id,group)` 的数值与当期分位；variant 明确 raw/oriented/transformed/composite；原始不覆盖 |
| ic / ic_summary | time或分期、signal、variant、pool、group、horizon、metric(pearson/spearman)、value、n_assets/n_periods、status/reason |
| quantile_returns / spread | time、signal、pool、group、horizon、quantile、value、n_assets；spread端点与收益调整方式 |
| stability / correlation / comparison | lag/因子对/比较方案、共同池、样本数、有效期及 paired_period_count |
| coverage / diagnostics | 每期及汇总的候选量、有限因子量、标签配对量、分位有效量、错误/退化原因、阈值；保留零行/空指标的解释 |

own 与 common 两种视图必须分别可识别，禁止只写一个“IC”列不带口径。JSON 数值缺失用 null，不输出 NaN/Infinity 字面量；CSV 缺失用空字段并由 schema 明确，索引/类别/计数类型可重建。

损失统计的分母是研究区间、该 group、已知 universe=true 的候选行数，分位/因子/标签剔除前确定；已知 false 单列为 excluded，未知成员计 unknown_universe_count 并使数据集校验失败，不进入正常统计。own 视图以声明目标池为候选，组合/common 池额外报告各成员有效交集的形成损失，不能通过先缩池隐藏它。按 signal/pool/group/h 独立报告：因子损失、标签损失（在有限信号上）、分位损失（另列、不得混淆 IC 可用性）。

`max_loss=0.35` 是 `(候选数-有限信号与该 h 标签配对数)/候选数` 的上限，比较 common 池时分母仍包含其形成前的 eligible 候选；严格大于任一请求序列的上限返回带诊断的 `DataQualityError`，不自动调高。分位损失另以有限配对数为分母报告，不重复计入该上限，但影响结果完整性。候选数0为不可评价而非除零；研究区间之前的预热不纳入分母，用户研究区间内的未预热样本纳入损失。分期单列边界损失，不默默排除它再美化覆盖率。

阈值边界固定：loss < max_loss 和 loss == max_loss 均不触发超限；loss > max_loss 抛错。一个请求范围好、另一个超限时整次 evaluate 抛 DataQualityError 并附分项诊断，不返回伪完整结果。segment 的分母仍是段内所有 eligible 行；跨段标签不进入该段指标，但必须计入该段边界损失。单列真实缺价/尾部不足与 SEGMENT_BOUNDARY，不把结构性边界从分母删除。

| 情形 | 对外行为 |
|---|---|
| 合法且请求指标均满足合同 | `OK`，仍保留正常缺失计数；配置要求的 lag 起始空值和空月不算功能失败 |
| 存在有效指标，但某请求序列/指标退化或不可用 | `PARTIAL`，逐项原因和覆盖；不能当成所有指标通过 |
| 无任何可计算的请求评价截面 | `UNEVALUABLE`，保留空表 schema 和诊断；若先触及 max_loss，优先 DataQualityError |
| 名称/参数/索引/时间/schema 非法、运行未完成 | 类型化 ConfigError / DatasetError，拒绝评价；不得被广泛 except 吞成空成功报告 |
| 缺研究依赖或版本/功能不匹配 | DependencyError，给出所需 Python/安装修订，不影响普通核心导入 |
| 公式异常 | 明确因子、资产、阶段并终止本次采集；正常 NaN 可记无效，意外异常不自动当缺失 |

异常是类型，reason/code 是机器可读字符串，不能混用。拟定 ConfigError 对应 `INVALID_CONFIG`/`UNSUPPORTED_CLOCK`，DatasetError 对应 `MISSING_INPUT`/`INVALID_DATASET`/`UNKNOWN_UNIVERSE`，DependencyError 对应 `DEPENDENCY_UNAVAILABLE`，DataQualityError 对应 `LOSS_LIMIT_EXCEEDED`。指标不可用原因至少区分 `INSUFFICIENT_ASSETS`、`CONSTANT_FACTOR`、`CONSTANT_RETURN`、`NONFINITE_INPUT`、`QUANTILE_DEGENERATE`、`MISSING_LABEL`、`NO_VALID_PERIODS`、`ZERO_IC_STD`、`SEGMENT_BOUNDARY`、`INVALID_ABLATION`；不可变换的n<2归INSUFFICIENT_ASSETS。小样本/无效配置与指标值差是不同问题。

panel补充`MISSING_FIELD`、`NOT_YET_AVAILABLE`、`UNKNOWN_CLASSIFICATION`、`FORMULA_INELIGIBLE`、`INCOMPLETE_WINDOW`、`DOMAIN_ERROR`；数学域无效按DS45-13显式诊断，源输入±inf及意外异常仍失败。

availability 原因独立列出：`READY`（ready且finite）、`NOT_READY`（预热不足）、`NO_CURRENT_BAR`（该grid无当前bar）、`NONFINITE_INPUT`（显式合法NaN；±inf按计算失败终止）。指标层使用上列原因，不把“没有当前bar”混称 IC 很差。只有一个有效资产时可保存采集面板，但 IC/分层截面不可计算；无其他有效请求指标时 UNEVALUABLE，仍遵守 max_loss 优先规则。

Backtrader 公开边界提供轻量 Python3.8 可导入的异常壳；fincore 新分析错误留在其 exceptions 域并与旧 FactorDataError 层次协调。映射顺序固定如下，保留原 cause 和结构化 report，不用错误文本猜分类：

| 来源 | Backtrader 对外类型/code |
|---|---|
| 新公开配置校验错误 | ConfigError / INVALID_CONFIG |
| FactorLossExceededError（必须先于基类判断） | DataQualityError / LOSS_LIMIT_EXCEEDED，保留 report；只有新损失口径生成的报告可走该路径 |
| EnhancedNonMatchingTimezoneError、旧兼容 NonMatchingTimezoneError | DatasetError / INVALID_DATASET |
| 其余已知 FactorDataError；受边界校验器明确产生的数据错误 | DatasetError / INVALID_DATASET |
| 旧 MaxLossExceededError | 兼容入口专用，本研究不调用旧清洗入口；误达则集成失败，不能把其含分箱损失的 report 当成新口径 |
| import/API/Python前提不满足 | DependencyError / DEPENDENCY_UNAVAILABLE |
| Indicator/Line 运算意外异常 | FactorComputationError / FACTOR_COMPUTATION_FAILED，附factor/asset/phase并拒绝完整数据集 |
| 未知内部异常、任意未分类ValueError | 保留异常并失败，不变成缺失或成功；示例退出1 |

fincore 新入口的配置错误应有具体可识别类型，不能让 adapter 将所有 ValueError 判作用户输入错。只给结果模型增加符合新合同的字段，不修改旧 FactorAnalysisModel 的含义或兼容序列化。

分析结果状态与命令退出码分开。示例 `0=PASS` 仅用于必需输出全部可用且校验通过；`1=FAIL` 用于计算/数据/断言错误及数据退化导致不满足示例验收；`2=BLOCKED` 用于缺依赖/输入等前置条件；`3=UNKNOWN` 用于中断等不能判定的运行。不可评价/空报告永远不返回0；库用户可读取 PARTIAL 继续研究。示例中的必需信号×variant×group×h及分期汇总表至少各有合法值；某些边界期被排除不要求逐期全有值。若必需项有退化/缺项则 PARTIAL并退出1；事前配置为可选的诊断字段不可用可保留PARTIAL、列明原因，只有全部必需断言成功才允许退出0。不得事后把失败项改成可选。

## DS45-09 持久化、依赖和安装

Backtrader 保存目录拟包含 `manifest.json`、`factors.csv`、`prices_open.csv`、`prices_close.csv`、`availability.csv`、`universe.csv`、`grid.csv`，静态组与因子声明在 manifest；使用预计算标签时增加 `precomputed_returns.csv`，原始价格可缺省但不能据此选择价格模式。实际文件名在 R1 固定；每文件记录类型/schema、行数、摘要用于一致性校验，使用 UTF-8 和 UTC ISO8601，float64 至少17位有效数字往返。加载校验索引、字段、版本、摘要与清单；未知 schema 拒绝，不动态 import/执行 manifest 中的类名，不使用 pickle。

dataset_id 标识不可变原始快照，evaluation_id 由 dataset_id、规范化评价配置和 fincore 算法修订共同决定。改权重/方向/周期会生成新 evaluation_id，合法加载旧快照；不与旧结果混用。只评价存储数值不要求当前安装原 Indicator 代码，但 manifest 保留当时公式出处/定义指纹，不能宣称它是后来修改公式的结果。缺所需价格字段报 DatasetError；尾部不足在相关 h 保留缺失和损失报告，不偷偷补数据。

身份规范分开实现，避免纯采集被迫依赖 fincore：

- dataset_id：Backtrader 用 stdlib SHA-256 对规范化清单计算。清单包括 schema、按逻辑文件名排序的各数据文件 SHA-256/行数/类型、采集配置/公式定义摘要和来源声明；不含自身ID、创建时间、输出路径。清单使用 UTF-8、键排序、紧凑JSON、禁止NaN；文件固定UTF-8/LF、UTC ISO8601、17位有效数字float64和空字段缺失。相同采集快照重复导出应同ID；它是内容身份，不承诺不同CSV实现字节也同ID。
- evaluation_config_sha256：fincore 展开全部默认值，periods去重/排序统一tuple，映射按名称排序，比较族成员按集合语义排序，segment按时间排序；所有允许list/tuple输入的序列字段在规范结构中统一tuple：comparisons成员排序后转tuple，segments的起止/role记录转tuple（时点统一UTC ISO8601）；采集配置的targets按集合语义排序，FactorSpec.inputs转tuple但保留输入顺序，不排序。只承诺这些声明等价的容器输入同身份，不合并任意不同类型值。未知键、bool充数、非有限权重拒绝；方向合并为有效方向；权重按排序后的因子名归一，零权重成员保留。只有明确等价的空配置才归一，null不是通用“缺省”。对该纯值规范配置复用公开 `models.fingerprint_value`，记录 `config_schema_version=1` 和指纹算法版本；不得直接hash原始kwargs。二进制浮点完全相同的规范权重才承诺相同身份，不用近似相等合并研究配置。
- fincore_algorithm_revision：记录实际已提交 fincore commit 与其构建产物/分析源摘要，不只记录 `0.5.1.dev0`。相同提交不同依赖环境还需记录完整依赖锁/运行版本，不宣称跨库版本数值必然位相等。
- evaluation_id：对 `dataset_id + evaluation_config_sha256 + fincore_algorithm_revision + result_schema_version` 的规范结构使用同一公开指纹函数。配置映射顺序/list-tuple等价性测试必须同ID；方向/权重/周期/比较族/分段/阈值/算法修订变化必须能区分。export的charts/路径不是分析配置，不改变evaluation_id。

因子定义摘要绑定采集时明确的模块/类/参数/输入/输出及源码或已安装产物来源；无法提供定义出处时不能宣称公式可复现。只保存数据值与元数据，不把对象反序列化为可执行类。

数据集/结果输出默认要求新目录，拒绝覆盖已有交付；文件全部写入并校验成功后最后写 `manifest.json`，其中 `complete=true` 是完成标记；加载时拒绝无manifest或complete不为true的目录。本轮不建立远端存储、数据库或自动缓存服务。

## DS45-11 面板声明与共享执行引擎


### 11.1 同一基类的两种面板写法与真实输出

保留普通`execution="indicator"`的生命周期与逐资产line采集。`execution="panel"`统一接受`PanelFactorIndicator(bt.Indicator)`，由类属性`panel_mode`显式选择以下两种模式；二者都使用同一个FactorStrategy，用户均不重写Strategy.next。此修订替代v0.4“所有panel子类禁止__init__/next”的限制；027现有代码仍只实现expression原型，本节不是已实现声明。

| panel_mode | 因子作者编写 | 构造与执行 | 输出 |
|---|---|---|---|
| `expression` | 类级`build(ctx, **params)`返回PanelExpr | 每定义调用一次build，不创建普通Indicator实例；共享DAG逐grid执行 | 一个表达式对应每time/asset一个标量 |
| `next` | `params`、`lines`、`__init__`、`next`，可按合同覆写`prenext/nextstart` | 真实初始化的Indicator实例；每定义/研究组一个实例，接收全组同步数据；私有panel owner管理依赖和逐grid生命周期 | 每资产一组输出线，经`self.outputs[data].factor[0]`写标量；FactorSpec.panel_line选择其中一条 |

不猜测执行模式；缺失/未知模式、expression覆写计算生命周期、next同时覆写build或自定义once批量入口均以ConfigError拒绝。`once`自动适配属于基类实现细节，不得让BT默认批量调度和panel逐格调度都执行同一个实例。不得用`object.__new__`、手工拼装self.datas或跳过初始化来伪造原生Indicator。R1冻结合同；R2验证next模式的params/lines初始化、OwnerContext、子指标归属、minperiod和回调；R11a再验证expression的build一次、不注册普通实例和共享节点，均非仅检查issubclass关系。

实施顺序固定为`next`先行：R2实现并验收真实实例、私有owner、逐资产输出和grid生命周期；R3补齐共享算子/PIT；R4完成20式手写。`expression`在R11a实现核心、R11b完成20式与next等价、R11c完成安装集成；R2不得因expression未实现而阻塞，R11不得用next已通过替代expression。R1只冻结两模式合同，不把任一模式标为已实现。

```python
# 拟议声明示意，不是已经存在的API或生产Alpha101库。
class Alpha003Capability(PanelFactorIndicator):
    panel_mode = "expression"

    @classmethod
    def build(cls, ctx):
        return -ctx.correlation(ctx.rank(ctx.open), ctx.rank(ctx.volume), 10)

# 普通因子与panel声明均使用同一个FactorStrategy，不写用户Strategy.next。
factors = {
    "alpha003_capability": {
        "indicator": Alpha003Capability, "execution": "panel",
        "operator_profile": "alpha101-v1",
        "field_bindings": {"open": "feedline:open", "volume": "feedline:volume"},
        "direction": 1,
    }
}
```

`ctx`仅暴露已校验字段与注册算子；没有Feed对象、未来标签或任意数组索引入口。expression支持范围是注册表达式图，拒绝任意Python运行时回调作为节点。`PanelExpr`不能与BT Line混算。


`self.datas`保留BT数据访问形式：`data.open[0]`、`data.volume[-1]`、历史get、`data0/data1`等，传入的是经字段/PIT校验、按显式grid逐格发布的BT兼容数据视图，**不是未经对齐的原始Feed对象**。全组资产固定映射到这些视图；`self.formula_members`为当前formula_universe有效成员，不以缺bar隐式删除成员。缺字段在当前槽位为NaN；asset身份、datetime及原因元数据随槽位发布。视图只保存截至当前grid已发布的历史，禁止正向索引和访问未来预加载值；先补缺格再发布下一真实bar，尾段补格同样调用生命周期。这不是针对任意Python代码的安全沙箱，第三方代码仍需审查及未来扰动测试。

`lines=("factor",)`在panel next模式声明每个资产输出线的schema。基类为每资产建立独立的BT数值线容器、维护游标和历史；每格先推进/清空，再让算法写`self.outputs[data].factor[0]`。一个float line不能存整张dict/Series；未指定资产的`self.lines.factor[0]`不能冒充整个截面输出，也不能静默取首资产。`panel_line`在next模式必填，在expression模式禁止；既有普通FactorSpec.line/inputs在两种panel模式均禁止。每格每输出必须写有限标量或NaN及DS45-08既有reason；遗漏/非法输出是计算错误，不能复用上格残留值。预热、formula_ineligible等确定状态由基类统一约束，算法补充窗口/数学域原因，不能将任何NaN一律解释成预热。

手写模式可在`__init__`中为各同步输入创建普通BT子指标，归属于同一私有panel owner，其依赖先于因子回调更新；它们不加入策略的普通指标调度树。须以真实SMA/ROC嵌套验收初始化、历史、预热与每grid一次推进，不能仅用自写deque声称兼容所有原生指标。尚未通过该调度合同的自定义指标以明确配置错误拒绝，不静默调用其once。现有普通因子与panel结果的跨调度树实时line依赖、expression对任意next输出的动态依赖仍不在本轮范围；两模式可作为独立因子并列研究、由fincore在采集后合成比较。

所有正式结果仍通过`strategy.get_dataset()`取得。手写模式的逐资产线是面板内部计算/采集接口，不自动等于交易策略可随时消费的原始Feed时钟线。公共实现按职责放入拟议`backtrader/research/factor_strategy.py`、`backtrader/research/panel_indicator.py`、`backtrader/research/panel_engine.py`，从`backtrader.research`导出；示例保留因子定义、配置及运行装配。不能仅将027的整个factor_strategy.py搬入库就视为R2完成。

### 11.2 grid屏障与依赖图

- `prenext/nextstart/next`共同调用模板的grid推进路径。在源Feed本事件已推进、常规指标更新后，按权威grid重建当前完整资产向量；只接受时间戳恰好等于该grid、且available_at不晚于它的字段。没有当前bar的资产标缺失，不能读取其陈旧槽位。
- 两种Cerebro模式都用同一`PanelEngine.advance(t)`：runnext在事件回调中推进；runonce在`_oncepost`事件回放时推进。屏障发布同步视图后，expression执行DAG，next模式由私有owner推进真实实例及其依赖，均每grid一次。即使Feed已preload，也不能直接把未来数组交给公式或手写代码。独立批量参考是验收oracle，不是第二套默认生产语义。
- 同一grid只推进一次。所有Feed均无事件的grid在下一事件前按时间顺序补“缺失”步骤；最后在stop补到研究end。重复相同事件幂等，冲突值失败；主Feed先结束不截断其他目标。数据集只能在stop完成这些步骤后封存，不声称提前有实时line输出。
- TS节点持有每资产固定grid历史；CS节点对该时点该研究组的公式资格池一次计算整个向量。严格按有向无环图拓扑执行，可包含TS→CS→TS→CS及嵌套行业去均值。环、未知节点、非法前向索引和跨profile隐式拼图拒绝。
- 结构相同的节点按算子版本、规范参数、输入节点、字段绑定、profile和计算组/池身份共享。同一节点每个grid仅求值一次，并保留可测试的计数；归约按规范资产ID顺序执行以避免输入重排改变浮点累加顺序；不能只用因子名称作为缓存键。不同运行不得共享可变状态。
- 上述DAG共享仅适用于expression。next是有状态算法实例，不能从任意Python代码自动推导DAG、合并状态或缓存为同一个实例；不同因子定义/运行的手写状态独立。其回调、子指标与每资产输出推进单独计数；并列混合采集不会改变任一因子算法。
- 计算只到研究end；标签尾部只保存价格，不进入最后一个信号的公式。全体目标及历史成员变化不会重新计算过去截面；新加入资产的TS输入可以使用已提供且当时可用的历史数据，但历史CS输出仍按当时池定义。

### 11.3 预热与错误

编译器计算每节点的历史跨度H（所需最早位置为`t-H`）：字段H=0；delay/delta追加floor(d)；滚动窗口追加floor(d)-1；逐元素、CS及条件节点取所有输入H的最大值；returns/ADV按DS45-12展开；至少需要H+1个grid。条件节点采用保守的两分支最大跨度，不能利用某次分支为常数提前缩短整个公式的结构预热。编译结果导出原始窗口、取整窗口、H及依赖链，由独立计算核对；不能以最长单个窗口冒充嵌套总跨度。

上述自动推导用于expression；next必须声明`formula_fields`、所需classification_bindings及可按参数求出的有限非负整数`lookback_h`（拒绝bool），包含嵌套子指标和手写状态的完整历史需求。H与params/代码版本一起冻结，验收独立核算；不能因使用手写算法而绕过字段/PIT/profile及历史覆盖要求。初版无法证明有限历史需求的手写定义须显式拒绝或另行设计，不虚报自动推导成功。

panel next基类的prenext/nextstart默认调用next，从第一个预热grid就积累横截面历史；每个grid只调用一个阶段。`addminperiod`保留指标声明形式，但不能等到第10格才首次计算#3的当日rank。输出是否可用由H、子依赖就绪、完整窗口、当期成员及原因共同确定；不是单靠主Feed长度或策略全局minperiod。允许用户覆写预热钩子，但其必须维护同一因果和逐格合同。R2必须以真实Cerebro检查这些保证及普通路径不回归。

公式历史资格和行业数据覆盖全部所需预热区间，不能只在研究start后才开始截面计算。原始市场历史即使当时不eligible也可供TS节点，CS节点只消费当期公式池；退出池不删除既有CS历史。停牌缺grid不压缩窗口。预热不足、字段缺失、已知数学域无效产生明确无效值；意外异常、源inf或未知算子使整次采集失败。所有节点的invalid mask、原因及可用时点随结果传播；where的分支规则见DS45-13。

## DS45-12 Alpha101输入与历史可用性

该profile针对同日历、同币种口径的股票日频数据；通用模板仍保持资产类别中立。没有市值/行业语义的市场不能填0或伪造分类后称为原式全覆盖。股票池、价格复权和数据供应商的真实性由调用方负责，框架验证形状、时序及声明一致性。

| 输入 | 规范与来源 |
|---|---|
| open/high/low/close/volume | 每target对应Feed的显式line映射；需同一日频grid与复权口径。volume为声明的股数单位，不能以成交额替代。缺bar无前值填充 |
| returns | 由上述同口径close构造close[t]/close[t-1]-1，跨度H=1；非正分母/缺价无效。不能注入未来收益标签代替 |
| vwap | 独立的真实日VWAP字段或明确的合成fixture字段；不能由OHLC平均近似。必须与价格、volume口径一致 |
| dollar_volume / advN | dollar_volume为每日美元成交额，advN为它在完整N个grid上的均值。可用直接字段；仅在单位/币种/复权及成交统计确实一致时显式选择vwap*volume派生，并记录来源。禁止静默close*volume或把平均股数volume冒充论文ADV |
| cap | 当时可用的美元市值；独立字段，不以未来公布股本重算历史，不以常数占位 |
| sector / industry / subindustry | 三个独立层级的历史分类；使用明确taxonomy版本和每时点可用的成员值，不能把静态research groups等同于行业；只要求所请求公式实际依赖的层级 |

扩展ResearchSpec：`formula_universe`是从本次计算首grid（含预热）到研究end的完整`(time,asset)`布尔矩阵；缺省表示显式固定targets全历史池并记录此假设，提供时未知成员拒绝。`universe`仍只控制研究窗口评价资格。两者都不能依赖标签是否可算；评价common池变化不能改变formula_universe。

ResearchSpec增加`formula_fields`（表名→数值外部表）和`classifications`（binding名→历史分类表），无此类输入时为空映射。FactorSpec的`classification_bindings`将公式分类别名映射到ResearchSpec已有binding；ctx.indclass(alias)返回已绑定分类节点。未知表名/别名拒绝；没有行业依赖的公式不要求分类输入。

`field_bindings`将直接逻辑字段映射到`feedline:<name>`或`table:<name>`；数值外部表采用完整`(time,asset)`索引，value/available_at及数据版本；行业表另含level、category、effective_at、available_at、taxonomy_version。外部表可以由上游as-of适配器生成，**本轮引擎不把最新分类向历史填充**，也不猜真实发布日期。每cell仅当effective_at（若适用）及available_at均<=t才可用；晚发布记录不污染此前结果。字段缺整列/必需层级/单位/绑定报MISSING_INPUT；合法的个别缺值或尚未可用cell记缺失及原因。来源时间缺失且不能声明该行情bar闭合可用时，拒绝猜测。

ADV来源采用显式互斥声明：直接来源示例`"adv20": "table:adv20"`；派生来源示例`"adv20": {"derive": "adv", "source": "dollar_volume", "window": 20}`，编译为完整20格的mean节点，N必须与advN名称一致。`dollar_volume`也须绑定直接字段，或显式声明`{"derive": "vwap_volume", "vwap": "vwap", "volume": "volume"}`并验证美元/股数/复权口径；不能只绑定美元成交额表就猜测ADV，不能同时声明两个来源。派生只允许上述注册规则；源缺失、循环、N不匹配或任意回调拒绝。直接ADV不再二次平均，其输入元数据必须声明美元口径、N、完整窗、源版本和可用时点；值的生产真实性由上游负责，不凭元数据声称已重算验证。

编译H表示本引擎所需输入历史：直接ADV是H=0的已计算字段，来源自身N-1的历史跨度单独记录为provenance，不能当作本引擎再次rolling；派生ADV按mean追加N-1。20个代表配方一律用派生路径，附件的H均据此给出。另在AC45-24用独立预计算ADV表和原始成交额构造对照，两路在相同可用区间结果一致，首个有效时点按各自available_at及完整窗处理。来源选择、直接/派生节点、原始窗口、单位、版本和来源跨度均进入图/数据集身份，不能切换来源后复用旧缓存。

论文#7等原式将美元ADV与股数volume直接比较。alpha101-v1保留原表达式，不以量纲不一致为由隐式换算、改成平均股数或拒绝该公式；输入单位仍如实保存，这不意味着比较项具有相同物理量纲。

行业节点使用命名`classification_binding`（taxonomy、level、table及版本），不能只硬编码三种全局分类。允许同一公式多次调用绑定不同taxonomy或同一level的不同分类；默认每个IndClass符号映射到显式声明的同一binding，若研究者指定不同映射须记录每节点绑定及新身份。原文未公开具体行业体系，因此默认映射是公开研究假设，不能宣称复现作者分类。

每组CS对`formula_universe=true`且该节点全部必需输入有限的资产计算；不把一个节点无关字段的缺失扩散到整池。行业节点进一步要求当期分类已知，未知分类资产无效，不塞入默认“其他”组。单成员组去均值得0但记人数；分类切换只从对应时点生效。最终输出若不在当期公式池则记FORMULA_INELIGIBLE；评价eligible但公式不eligible导致的缺失仍计入原评价候选分母。

数据集新增formula_inputs（所用字段与可用时点）、formula_universe、classifications及规范图说明/算法版本；仅标签prices不够重现输入。清单记录每逻辑表的schema/行数/摘要；不要求保存所有中间矩阵，可按请求导出节点诊断。保存最终raw值后评价无需重跑图；显式更改公式/profile/公式池/分类产生新dataset_id且必须重新计算，不能伪装为evaluate权重变化。加载图说明只作数据，不动态执行其中代码。

## DS45-13 alpha101-v1算子规范

依据[原论文Appendix A](https://arxiv.org/pdf/1601.00991)建立独立版本profile。论文没有唯一固定全部缩放、并列和数值域细节；下列是**本项目可测试的工程约定**，不宣称与作者未公开实现逐位相同。DS45-06的评价rank仍为[-1,1]，不得拿来替代本节公式rank。

| 算子 | alpha101-v1固定行为 |
|---|---|
| arithmetic / abs / sign / log | float64逐元素；sign(0)=0；log仅接受正数；除数0、无效对数、溢出等已知数学域问题返回NaN+DOMAIN_ERROR，不产生有效0或inf |
| comparison / logical / where | 比较支持<、<=、>、>=、==、!=；精确数值比较，不用epsilon打散ties。缺值比较为unknown；AND/OR/NOT用三值逻辑（false AND unknown=false，true OR unknown=true，其余unknown传播）。where仅选中支路决定有效性，未知条件无效；未选支路数学域无效不污染输出，意外异常仍失败。布尔结果进入任意数值算子（算术、rank、decay等TS）或输出时显式转换true=1/false=0，unknown保持缺失，不能使用Python bool(NaN) |
| ordinary power `^` | 映射实数幂而非Python XOR；负底数仅允许整数指数，0负幂无效，0^0=1；不偷偷改为signedpower |
| SignedPower | sign(x)*abs(x)^a；x=0且a>=0时0，x=0且a<0无效；指数可为当期表达式，明确包含#84所需情况 |
| rank(x) | 各time/research_group的当期公式池内，对有限x用平均秩r后取r/n；n=1时1，n=0无输出。常数值可得有限并列秩；不是评价[-1,1]变换 |
| scale(x,a=1) | 同截面a*x/sum(abs(x))，a须为有限正标量；分母0无效。分母只用该节点有效公式池，不跨research group |
| IndNeutralize(x,g) | 在当期公式池、对应历史行业层级内减去有限x等权均值；单成员为0；多次嵌套不删成一次 |
| delay / delta | 原d与floor(d)均入manifest；delay>=0，delta为x[t]-x[t-floor(d)]；按grid位移，不跳过缺bar |
| 所有滚动窗口 | d为有限非bool的正数标量声明，编译时向下取整，floor(d)>=1；整窗口包含当前grid且要求全部d个有效输入，不以min_periods=1、dropna或ffill改变定义。论文明确ts窗口取整；本profile将它一致扩展到correlation/decay/sum等的分数窗口，并公开这一约定 |
| sum / product / mean / stddev | 完整窗口；mean用于派生ADV等；stddev用ddof=0，d=1得到0；product溢出按DOMAIN_ERROR |
| correlation / covariance | 两输入完整相同窗口；Pearson相关，任一方零方差或d<2无效；covariance用ddof=0，d=1得到0。与跨资产IC统计分属不同层 |
| ts_min / ts_max | 完整窗口最小/最大值 |
| ts_argmin / ts_argmax | 位置编号最老=1、最新=d；并列取最早位置；不是当前向后数0起点 |
| ts_rank | 当前值在完整窗口中的平均秩/d，d=1得1；与跨资产rank的轴不同 |
| decay_linear | 最老到最新权重1..d，除以d(d+1)/2；缺一项则无效，不能重归一剩余项 |
| min/max双语法 | 右参数为纯数窗口时编译为ts_min/ts_max；两个表达式时编译为逐元素min/max（任一缺失则无效）；图中记录已消歧算子，不在运行时凭值类型猜测 |

数值域失效必须是上述已列规则产生，不能用广泛except捕获未知错误后返回NaN。源数值±inf在绑定时拒绝；纯算术已知overflow可诊断为DOMAIN_ERROR；普通Indicator仍遵守DS45-04严格错误规则。整个公式全NaN不得以“没有抛异常”通过能力验收。

R1先以论文Appendix A独立补齐101式完整静态输入、算子族及窗口常量登记，R3/AC45-23冻结其覆盖身份；当前附件的代表依赖不能当成已核验完整集合。算子覆盖同时从原文独立核算全局集合并与完整登记交叉核对，不只覆盖20个代表式，也不要求本轮构造101个生产DAG或计算其精确H。每个公开算子有独立手算正例和所需边界负例；列表未知算子不得默默降低覆盖率。独立参考实现不能导入生产算子或重用同一图求值器作为expected。后续若改profile语义，递增版本并使公式/数据集身份变化，旧结果保留原口径。
