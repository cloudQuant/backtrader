### 附带修复：日历 seed 的 Windows 行尾 bug（真实可移植性 bug）
- 现象：`install_package_seed` 报 `PACKAGE_SEED_DIGEST_MISMATCH`，4 个 layer 文件的 sha256 全部与 manifest 不符。
- 根因：`.gitattributes` 未覆盖 `trading_calendar_seed/**/*.json`，`core.autocrlf=true` 在检出时把 seed layer 的 LF 转成 CRLF；manifest 的 digest 是按 LF 计算的。验证：CRLF→LF 后 4 个 digest 全部匹配。
- 修复：`.gitattributes` 新增 `bt_api_py/trading_calendar_seed/**/*.json -text`（字节精确），并把工作区 5 个 json 规范化为 LF。`git status` 此前干净（非本地改动，是检出转换）。POSIX 零影响。
- 结果：seed 安装成功（INSTALLED/SEED_INSTALLED）。
