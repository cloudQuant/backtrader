## 4. gateway 策略 live 运行的真实阻塞（运营级，非代码故障）

修正密钥门后重跑 `sa_dual_ma_gateway --run-seconds 5`，逐级暴露以下前置，均属**运营部署输入**，不是代码缺陷：

1. `state_not_initialized: identity.json` —— 需要 `--first-init`（账户须完全空仓无挂单）。
2. `--first-init` 会连接 config 中的固定端点：Gateway `tcp://127.0.0.1:12345`(:12346)、Risk `:12355`、Execution `:12365`。harness 的五服务用**随机端口 + 合成 CURVE 身份**且启动后即退出，与这些固定端点不匹配。
3. config 全是**占位符/过期值**：`strategy_ref: replace-with-registered-strategy-uuid`、`grant_revision: replace-with-execution-grant-v1`、`delegation_id: replace-with-delegation-id`、过期交易日 `20260105`/`2026-01-05T15:00:00+08:00`，以及各 `state/keys/*.public|secret` CURVE 密钥文件。
4. 因此需要：真实常驻的 Gateway（带 SimNow 账户、匹配 CURVE 身份）+ Risk + Execution + Monitor + Runtime，端口与 config 对齐；注册的真实 strategy UUID/execution grant/delegation/build id；非过期的授权交易日；实际密钥文件。

结论：**在补齐这些运营输入前，11 个 gateway 策略无法 live 运行**。这是预期的设计（示例配置默认 fail-closed），不是本次改动引入的故障。
