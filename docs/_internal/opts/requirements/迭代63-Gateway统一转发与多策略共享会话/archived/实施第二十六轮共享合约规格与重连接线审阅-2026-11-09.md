## 行为证据与审阅修正

完整绑定 SPI 的独立 Gateway 进程合成用例覆盖 pending 期间同注册续租、其他状态调用前进、同 operation_id 只发一次请求、注册隔离及同 SPI 重登录的新旧来源。真实 profile 清理用例覆盖原 owner 上 cleanup=False、账户 guard 保留、竞争 profile 被拒和随后同句柄重试成功；该清理只涉及尚未发送 native 请求的本地句柄，不能扩大为所有在途原生请求已验证。

独立审阅促成 E053 句柄责任、E055 端口词汇、E056 取消响应预算、E057 平台等待溢出、E058 来源时效修正；T009 补足实际 profile 清理入口。E059 后续审阅修正新 generation 围栏顺序、稳定会话错误分类和可信有限认证重试来源。E060 的确定性红/绿用例证明规格 reader 可独立使用当前可信 TD 来源，账户/回报/行情旧检查未放宽。

结算 CONFIRMED 观察在 settlement_confirm 事务前后失效，使用专用 stale 类型并二次核对来源，保留不确定或已提交 marker，重新读取前不重发。同文案普通 ValueError、该路径的 SQLite 错误仍按致命异常处理。首次 settlement_begin 的 commit 不确定性属于既有 DirectWrite 合同，已有提交回执丢失及提交前回滚测试保护；不把新集成测试声称为亲自覆盖了所有首次结算窗口。审阅对此曾提出、后撤回错误归因，原产品未因此修改，见[最终审阅裁定](../evidence/round26-20261109/final-review-triage.json)。

通用 codec 的 max_quantity 可选与 CTP 原生限价上限必需分别约定；历史完成 QueryResult 允许幂等读取，Gateway reader 消费时仍核验当前来源。摘要及 ready 都不等同于交易授权，内存来源探测与 socket 发出也并非原子操作。
