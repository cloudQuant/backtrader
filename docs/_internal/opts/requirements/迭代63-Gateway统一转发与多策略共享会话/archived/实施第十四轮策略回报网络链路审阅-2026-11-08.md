# 迭代 63 第十四轮：策略回报网络链路审阅

日期：2026-11-08。整期状态：**IN_PROGRESS / 未验收**。本轮将 R13 同库策略事件接到现有独立 Gateway/ZMQ 服务与 SDK 客户端，未执行账户调用。BT 产品、CTP provider 和 ZMQ 产品本轮未修改。

## 实现与审阅

主代理冻结[合同 §17](../分轮合同冻结稿-2026-11-08.md#17-r14同库策略事件的认证网络读取与-ack)，分别委派 Base 公开 DTO、Gateway 同库事件元数据/ACK、SDK 服务装配、SDK 客户端、跨进程测试五条实现线；源码地图与两条独立只读审阅检查归属、授权、来源暴露、迁移和关闭。后续发现的旧测试只由独立文件 owner 修正，主代理检查差异并独立验收。

Gateway 内部事件在同一 SQLite 事务联结已归属事实与原命令，返回原请求键、预留号、命令摘要及命令主体。缺关联、策略/摘要/身份矛盾明确拒绝，不静默漏行。ACK 的完整回复预算在 UPDATE 前检查；false、异常或非 bool 不推进。没有新增数据库或 schema 迁移。关联查询使用 SQLite JSON 函数，本机验证不能外推所有目标构建。

Base 公开 DTO 有严格 schema/字段、数量、日期、摘要及范围校验。策略序号允许全账户序列中的间隔，has_more 真不能是空页。公开原生身份、强键及成交键只有确定性摘要，不转发可带任意来源字段的 identity.fields、原键或接收来源。摘要是关联标签，不是匿名化、抗枚举、账户权限或来源证明；原派发身份仍按既有 command_status 合同读取。

SDK 在 service.direct_write 上增加显式 direct.events.read_after/progress/ack；旧默认注册集合不扩权。Registry 的认证 principal、完整 scope、lease、静态策略 grant 和 operation grant 继续逐次检查。consumer 绑定身份与账户/策略，排除 run/registration；客户端不提交 consumer 或策略选择。事件只读恢复可选择 events-only，不夹带 release 写 claim。read_after/ack 同时进入 MIG03 cursor 写入栅栏，progress 不改变进度，也不授予下单权。

候选页先转为完整公开回复，在原 cursor 事务中检查包含 envelope 和传输封装的最小收包预算。首条超限不推进，能放部分时缩页。客户端复用现有 ThreadedServiceClientRuntime，接受其精确冻结容器并有界还原；校验 binding、consumer、epoch、页序号和 ACK。没有自动 ACK、重试、另建 cursor 库或 direct 回退；调用方仍须先持久保存本地投影和 cursor，再显式 ACK。回复丢失或 HANDLER_FAILED 保持 UNKNOWN，已提交结果可查进度/重放。

关闭首先永久关闭预留和 stream 入口；独立终止信号不会等待正在提交的 reservation fence。总预算内排空原准入锁、在途读取和 owner，超时保留 guard/session/句柄，可重试。已进入 fence 的原提交可完成，关闭未确认不表示已回滚；迟到维护结果不能重新开放门禁。关闭参数非法不改变状态，新增关闭入口在任何锁/事件前检查 PID。
