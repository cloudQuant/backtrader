Python 3.11.5（`C:/anaconda3/python.exe`）、Windows；公开 `tests/datas/XAUUSD_M15.csv` SHA-256 `d364dea806a6ef634277184d1edc71fb90216fadacf673f70ea9706c55a1f51f`，取前 30,000 根，单普通策略、16 条 SMA，周期 10 至 25。真实 Cerebro `runonce=False`、`preload=True`、`stdstats=False`；每个新进程先以 1,000 根预热，再计量 30,000 根的 `Cerebro.run`，不使用 cProfile。数据加载与预热在计时外，计时包含该次 run 的框架及指标计算。

每组各执行旧、安全、安全、旧、安全、旧、旧、安全（ABBA + BAAB），即旧／安全各 4 次，串行完成；先测公开 HEAD 组，再测两文件 WIP 组。机器非独占，可能受到其他任务、调度和缓存影响。下表负值表示安全版在该统计口径下更慢：
