# R71-100 上下文查找限定性能证据

2026-11-21，在 Windows、Python 3.11.5 上，对 `LineBuffer` 的因子严格上下文查找进行了配对测量。本记录只比较该查找函数，不构成整个 R71-100 的性能验收。

固定公开源码为 Backtrader Git 提交 `62d08b47d70d863ddc6853c13cebeb5c3f686a58`。每次运行使用同一份源码和同一进程，仅在内存中切换 `_factor_context_for_line`：修后使用该提交中的函数；修前函数从提交 `8db4b49b0d2a9424a518e9deef5a56d611121253` 的 `backtrader/linebuffer.py` 按 AST 提取，运行时其余模块和全局对象均使用固定源码。这不是两个完整历史版本之间的端到端比较，也不包含工作区中未提交的候选。

每个场景为 5,000 根合成行情、五组交错执行的配对；普通策略读取 16 条表达式，因子场景运行真实 `FactorStrategy`，各自覆盖逐根和批量模式。下表为各版本五次耗时的中位数，括号为修前中位数除以修后中位数。原始顺序和每次耗时保存在结果 JSON 中。

| 场景 | 修前 | 修后 | 比值 |
| --- | ---: | ---: | ---: |
| 普通策略逐根 | 1.7180 秒 | 1.6465 秒 | 1.043× |
| 普通策略批量 | 1.5704 秒 | 1.4295 秒 | 1.099× |
| 因子策略逐根 | 1.1148 秒 | 1.2039 秒 | 0.926× |
| 因子策略批量 | 0.9309 秒 | 0.8913 秒 | 1.044× |

普通策略每次输出 80,000 个值，因子策略每次输出 5,000 个值；各配对的完整输出 SHA-256 一致，并与不调用 Backtrader 的独立公式计算结果一致。时间测量发生在共享机器上，样本数量有限；因子逐根结果波动明显，不能仅凭两个中位数断定性能退化或收益，也不能外推至其他策略、数据量或环境。独立复核另以非计时探针确认四个场景均实际执行了被切换的函数。
