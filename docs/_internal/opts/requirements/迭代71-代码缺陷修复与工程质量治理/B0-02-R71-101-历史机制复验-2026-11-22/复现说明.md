## 机制红绿

`instrument.py` 在两版各启动一个独立子进程，运行 200 根合成 bar、16 个不同周期 SMA 的真实 Cerebro。只在该轮包装 `LineSeries.__getattr__`，统计两个目标属性查找实际抛出的 `AttributeError`：修前 `_once_called` 为 3201 次、`_resolved_secondary_clock` 为 6400 次，修后均为 0。每版均产生 176 次策略回调，16 线逐回调值摘要及最终数组摘要相同。

`check_count.py` 读取保存的 `instrument.json`，分别以两个计数都为零为断言；旧版退出 1，新版退出 0。这里是**已记录计数上的机制断言红绿**，不是数据错误或交易风险红绿；包装访问器本身会影响性能，不使用该轮时间作性能结论。`old.check.txt` 和 `fixed.check.txt` 是原先 `.log` 文件的原字节副本，仅更改了归档文件名。

## 无插桩交替性能

`bench.py` 不启用上述属性插桩，以 30000 根、16 SMA 交替运行三对独立 Python 进程，顺序为 old/fixed、fixed/old、old/fixed。计时在子进程内包围 `Cerebro.run()`，包含合成 Feed 加载和策略逐回调编码，不包含进程启动。

- 修前分别为 9.8618、8.2643、7.5940 秒，中位数 8.2643 秒；修后为 2.3061、2.5398、2.0024 秒，中位数 2.3061 秒，约 3.58 倍。
- 六次均有 29976 次策略回调；每次 16 个指标逐回调值的 SHA-256 为 `c847339367693d425db463f66d5073bef9aa62e4076164b3242671bc2d2c3460`，最终数组摘要为 `c72c89f633cb85f81955356b188f4605eb95940bc8a53e13ca5a055034928937`。摘要编码规则见 `worker.py`。
- 仅三对本机样本，未隔离并行负载，不保证其他设备、数据、Feed 或拓扑达到同样收益。无下单或交易事件。`benchmark.json` 中 `instrumented=false` 对应的零计数字段是**未开启插桩**，不能用作异常计数证据。`bench.py` 聚合了各子进程 stdout 的 JSON 值但未另保存每次 stderr，因此不声称基准阶段没有警告。

## 排除范围与 audit 边界

使用历史包的 `BACKTRADER_LIGHT_IMPORT=1`；由于该版本即使轻量导入也会主动导入 stores，脚本预装了空的 `backtrader.stores` namespace。此替身只用于避免加载不在范围内的组件，因而结果不能代表默认包完整装配。脚本的 MetaPath 拦截禁止 `bt_api_py`、`bt_api_base`、`bt_api_`、`backtrader.stores.*`、BtApiBroker/BtApiFeed 及列出的 BT 执行/服务模块；具体前缀见 `worker.py`。两版报告的禁止导入尝试均为空。另行对两版各一次 200 根运行检查已载入模块名，未见 BtApi、SDK、Gateway、Monitor、Risk 或相关服务模块；该附加检查不是全环境证明。

子进程在 Python 和少量标准库启动之后、产品源码导入之前安装 audit hook，限制独立快照、解释器和 System32 外的文件打开，拒绝列出的敏感文件名、socket 连接/绑定/DNS 与子进程。`instrument.json` 和 `benchmark.json` 记载的被拒绝操作均为空；hook 不覆盖其安装前的解释器启动，不是全进程或系统沙箱。不读取私密输入、不使用账户、Gateway 或 provider。

## 在新临时目录复现

下面命令仅供复现，归档时没有重复运行。脚本会在其目录写输出；请先复制四个脚本到新目录，不要覆盖本归档。

```powershell
$caseRoot = Join-Path $env:TEMP ('r71-101-history-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $caseRoot, "$caseRoot\old", "$caseRoot\fixed" | Out-Null
Copy-Item -LiteralPath '<本归档目录>\worker.py','<本归档目录>\bench.py','<本归档目录>\instrument.py','<本归档目录>\check_count.py' -Destination $caseRoot
git -C D:/source_code/backtrader -c core.autocrlf=false archive --format=tar --output="$caseRoot\old.tar" ccdc9faad603d8f3d3d6716ed4c50bde0fdc2edc backtrader
git -C D:/source_code/backtrader -c core.autocrlf=false archive --format=tar --output="$caseRoot\fixed.tar" 995edc92e0dfe74f65be34af25fd67e6cceb6ad1 backtrader
tar -xf "$caseRoot\old.tar" -C "$caseRoot\old"
tar -xf "$caseRoot\fixed.tar" -C "$caseRoot\fixed"
Push-Location $caseRoot
C:/anaconda3/python.exe -B instrument.py
C:/anaconda3/python.exe -B check_count.py old
C:/anaconda3/python.exe -B check_count.py fixed
C:/anaconda3/python.exe -B bench.py
Pop-Location
```

旧版计数断言预期退出 1，新版预期退出 0；逐项检查其他命令退出码。当前 R71-101 的性能和动态合同仍按 TODO 保持开放。
