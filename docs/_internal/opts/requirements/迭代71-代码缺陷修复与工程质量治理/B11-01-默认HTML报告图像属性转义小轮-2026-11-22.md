## 问题和修复

默认模板的三个图像 `src` 原使用 Jinja `safe` 过滤器。`generate_html` 接受额外模板变量，而这些变量可覆盖内部图像字段；如果调用方将不可信普通字符串传入对应字段，字符串中的引号可以结束 `src` 并注入 HTML 属性。在报告被他人打开的场景下，这形成 HTML 注入风险。本轮未执行 JavaScript，也未证明实际浏览器利用。

本轮只移除默认模板 `equity_curve_img`、`return_bars_img` 和 `drawdown_img` 的 `safe`，由既有自动转义处理普通字符串。正常生成的图像仍通过 data URI 传给模板。实际安全影响取决于调用方是否让不可信内容进入这些参数以及报告的分发方式。
