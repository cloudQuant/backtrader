合成场所成交归属后，两策略分别持有多 2 / 空 2；同切本地净额对比可显示 MATCH、MISMATCH 或 UNAVAILABLE，但 MATCH 只是给定测试输入的算术比较，不能证明账户毛仓、今昨、实时性或轧差已执行。两个母单的数量检查与各策略独立可平检查分别生效；已预约和 UNKNOWN 数量仍计占用，另一策略的剩余额度按各自账本读取。交易日变化但合成日切证明缺失时不可用；提供合成证明后才观察到昨仓。未归属的合成外部事实先使依赖账本不可用，经合成来源/排除证明后记录为 external，失去来源或同切证明时重新不可用。

这些观察中的 provider 来源、日历、账户切点、目标和许可均为测试声明，并非真实授权或账户事实。当前账本重放的是场所成交，不提供双腿非场所转移、策略虚拟仓/映射或稳定 transfer 身份；CTP 当前 `transfer_completed=0` 不能作为启用轧差后的完成量证明。内部转移/真实抵消、实际价格新鲜度、实仓今昨/占用一致切点、原子双腿与恢复仍为 **GAP/NOT_RUN**；账户允许时不能额外强制双方策略或逐单同意。SDK `iter65@9f3b3c91` 已更新 Gateway 指针。
