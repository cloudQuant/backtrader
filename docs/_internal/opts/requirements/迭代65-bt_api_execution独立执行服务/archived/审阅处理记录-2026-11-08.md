## 本轮用户已决定

- 确定未发送且旧请求不可生效时，按账户配置次数使用新子单身份重试，用尽冻结母单；结果未知不换身份重发。
- Execution 离线时，策略主动撤母单后由 Gateway 冻结母单并尝试撤其活动子单，逐笔报告实际结果；Execution 崩溃本身不自动撤单。
- 内部转移默认不收额外内部费用，记经政策证明的零和来源；与真实成交费用分开，未知不当作零。
- 母单先由 BT 经 SDK 交 Execution，选用 Risk 时先做母单风控，再由 Execution 向 Gateway 登记母单范围；Gateway 持有权威数量边界，登记不向场所下单。初始身份分配与跨库事务细节仍由 63/64/65.01 冻结。
- 普通子单撤单已经权威确认、成交对齐且可用量确证释放后，原母单仍有效的剩余量允许重新参与反向匹配，须重新核验双方授权、价格、数量和原期限；未知/未确认及已撤销母单不能复活。
