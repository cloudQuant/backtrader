原 SimNow 场景（65.11，合并后统一验收参考；需用户授权，结果只说明 SimNow 行为）：

1. 63 的 Gateway 已就绪；启动 execution（exec-a）、策略 A（rb2701，路由到 TWAP）和策略 B（rb2701，全部直通）。
2. A 下 3 手 TWAP 母单（3 片，`cross`，不越母单限价）：BT 看到一笔订单分次成交；Gateway 账本 A 为 3 手，B 不变；账户对账 BALANCED。
3. A 再下一笔远价 SLICE 母单，第一片挂出后 `kill -9` execution：母单冻结，挂单保留；A 主动撤母单后，Gateway 按 D65-06 尝试撤其活动子单，逐笔记录受理、在途、撤成或 UNKNOWN；仅在相应终态与累计成交对齐后投影结果。未获授权或未执行时记 NOT_RUN。
4. 重启 execution：日志恢复，已结束的母单不恢复；新母单正常执行。
5. 整个过程中 B 正常直通下单与撤单，不受影响。
6. 停掉 execution：A 命中路由的订单被拒，不降级直通；未命中的订单照常。
7. 会话数证据同 63.09。
