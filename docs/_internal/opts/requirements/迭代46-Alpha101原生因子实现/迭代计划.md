版本：**v0.4**；更新：**2026-10-22**。状态：**迭代46进行中；L0与AC46-01已通过，L1–L4及AC46-02–06尚未完成。** 本计划交付范围是将20式提升为生产实现并补齐其余81式，形成101/101 native库。前置迭代45已经完成，30项AC及最终两例配对均PASS；该前置完成不代表46已经启动或通过。权威进度见[迭代45验收结果](../迭代45-Indicator因子研究与多因子合成/验收结果.md)、[迭代45开发与验收记录](../迭代45-Indicator因子研究与多因子合成/开发与验收记录.md)及[最终wheel验证](../迭代45-Indicator因子研究与多因子合成/evidence/iteration45-installed-20261022/backtrader/b2697f13/install-record.json)。

## 1. 定位与依赖

迭代46在Backtrader原生Indicator、Lines、clock、minperiod与once_via_next生命周期上形成**全101个Alpha的native生产库**。迭代45的20个代表式源码与双模式38/38测试已交付，45整体退出门也已满足；本计划以其已验收基线逐项做生产提升、注册、独立参考和全量回归，只有通过本计划的逐式门槛后才计入101个生产因子。保留可用算法并做最小适配，不为满足类数量重写它们。

所有 AlphaNative 类统一继承 `FactorIndicator`，由 `FactorStrategy` 模板装配并采集；Cerebro原生Indicator调度是唯一推进路径，不由FactorStrategy再次推进因子。纯时序公式也使用同一研究生命周期的 `panel_mode="next"` 编写方式，不通过 `FactorSpec.execution` 选择另一研究入口。时序公式内部优先组合普通 Backtrader `Indicator`/`Lines`，复用 clock、minperiod 与 `once_via_next`；不为满足研究入口而人为添加 CS rank，也不另造数学核。真正需要截面同步的公式在同一入口内执行截面步骤。普通 Indicator/Lines 是子指标构件或非研究回归对象，不是第三种 Alpha 研究入口。`panel_mode="expression"` 是同一 FactorIndicator 入口在迭代47增加的另一种编写方式，不是独立研究模式。本迭代只建设 native，不实现 build/expression。

native算子实现必须复用迭代45设计DS45-13的固定数值profile，包括RollingCovariance的Fraction精确总体协方差，以及RollingCorrelation对实际binary64输入的Fraction精确矩累积、120位Decimal sqrt/ratio和最终一次float转换。常量输入/数学域错误继续输出NaN+DOMAIN_ERROR，rank并列只按binary64精确相等判定；不得添加epsilon或按因子改变精度。该合同复用不改变本迭代独立oracle和AC46验收要求。

## 2. 目标与范围

### 2.1 必须交付

1. 全101式冻结目录、ID、完整原式、窗口、`operator_profile`、字段/分类绑定、formula-universe/PIT 与逐式依赖；20个诊断配方和81个新增配方均须有明确的生产提升/实现记录。
2. 全101个可发现、可运行的 native 生产因子类及注册。不得把配方、测试辅助函数、027 expression 原型或占位类当作生产实现；已有20式算法可保留，经生产边界适配即可。
3. 每式独立参考、有限正向结果、边界/错误区分、独立计算并声明的 H、PIT 与缺失原因检查；参考不得调用被测生产实现、生产 PanelEngine 或 DAG。
4. 每式在有效 fixture 上至少有一个有限、非全 NaN 的预期结果。输入确实缺失时，按合同验证完整缺失 mask 与原因；全 NaN 或跳过不得作为有效公式通过。
5. 全101 native 回归：runonce/runnext、资产重排、未来扰动、缺 bar/停牌、公式池 PIT、行业层级、ADV 嵌套窗口、长预热、尾段；已提交安装产物上的研究回归、fincore 最小集成和025/026回归。

### 2.2 明确不做

- 不实现 `panel_mode="expression"`、`build(ctx, **params)` 或共享 DAG；这些属于迭代47。
- 不私建第二套算子、PIT、grid 或评价合同。实施当前 Alpha 小批时发现的共享路径缺口，先用最小复现归入该小批、加回归并随本轮修复/提交；不得把它当作跳过当前验收、重开已关闭45/E2循环或继续扩张范围的理由。只有证据表明共享合同本身错误时，才按项目治理单独调整合同。
- 所有 AlphaNative 生产类必须通过 FactorIndicator 统一基类和 FactorStrategy；普通 Indicator/Lines 只能作为其内部子指标，或用于不属于 Alpha 研究入口的回归，不另开独立研究模式。
- native 路径没有 build DAG 编译器；H 由公式、输入窗口与预热定义独立推导、审查并声明，不得声称由 native DAG 自动编译得到。
- 不承诺原论文收益，不把“全101类已注册”当作所有公式的市场绩效成立。
- 不用20式验收替代81式验收，不把“20+101”重复计为121。
- 不触碰账户、私有配置、实盘进程或 CTP/live 边界。

### 2.3 “全101”口径

“全101”指论文 Appendix A 的全部101式。迭代46的101/101 = 20个经本计划正式提升为生产类的既有配方 + 本迭代实现的其余81式。45的20个诊断配方在提升前不计作生产公式；提升时优先保留并包装已验证算法，补齐公开类/注册/参考/边界与全库回归。未完成提升或验收的公式不得用名称存在、占位类、全 NaN、skip 或其他公式替代。

## 3. 全101台账与复用边界

L1 先冻结逐式台账，再进入实现。台账每行至少包含：

- 论文 ID、完整原式、原文窗口和 `alpha101-v1` 取整/并列/数值域说明；
- 直接字段、派生输入、行业层级、`formula_universe` 和 PIT 成员语义；
- 依赖算子、嵌套窗口、独立核算/声明的 H、`operator_profile` 和缺失/退化规则；
- 独立参考来源、有限正向值、边界输入和错误实现区分方式；
- 公式/输入身份（ID、方程、窗口、profile、字段/类别绑定、formula-universe 与 PIT、H）和实现身份（类/模块、注册版本、代码版本/提交）分列记录；实现重构不得改变公式/输入身份。
- 实现状态、生产提升状态、逐式验收状态及提交定位；登记公式内部复用的 `bt.Indicator`/`Lines` 子指标与必要的截面步骤。

H 是公式层的 lookback/warm-up 声明：按原式依赖、窗口和本迭代输入定义独立推导，再与实际 Lines/minperiod 行为对照。FactorIndicator 或共享执行器不得把内部调度结果当作 H 的权威来源。

20个代表式以[代表验收案例](../迭代45-Indicator因子研究与多因子合成/Alpha101代表验收案例.md)固定：#1、#2、#3、#4、#7、#9、#13、#29、#48、#56、#58、#62、#63、#67、#81、#84、#92、#96、#100、#101。它们覆盖简单基线、截面/时序交错、历史数据与分组、布尔/幂/复杂分支；其余81式仍须逐式独立参考。

## 5. 验收与退出

同时满足才可关闭迭代46：

1. AC46-01–06 全部通过，且逐项证据与本轮 commit 对应；每个公式的生产类、独立 oracle、有效输出、边界/错误区分及其批次均可追溯。
2. 20个诊断配方已正式提升，另81式全部完成；每个有效 fixture 至少一个有限非全 NaN 输出，缺失/退化路径具有真实原因和完整 mask/reason。
3. 所有 AlphaNative 均经 FactorIndicator/FactorStrategy 研究入口；普通 Indicator/Lines 仅作内部子指标或非研究回归，H 独立声明且不依赖 build DAG。
4. 全部场景和已安装产物通过。fincore 只消费原始面板，不重算公式内部 rank/行业中性化。
5. 不产生 build/expression PASS。迭代47只有在本退出门满足后才可开始实施，并须另行证明 build 算法，而不是把 native 类包装当作 DSL 正确性。

若某项因真实能力缺口未完成，保持 `FAIL` 或 `BLOCKED` 并回到对应小批修复；不得用20式通过、静态映射或“类已注册”替代101/101 native 验收。
