## 三、注入式复验（用于评估 F1 以外的其余能力）

### 3.1 为什么需要注入

用例集没有任何 `position_mode` 入口（`grep -rn position_mode hongyuan_penetration/` 无命中），
而出厂 net 模式在该账户上必失败。为不修改仓库代码，用**临时驱动脚本**（位于系统临时目录，
不在仓库内）在子进程启动时做两处注入：

1. `common.config.create_config()` 的返回值补 `position_mode="dual_side"`
   （使 `BtApiStore.supports_position_mode("dual_side")` 为 True）；
2. `BtApiBroker` 的类参数默认值改为 `dual_side`（子类覆写 `params`），
   避免用例里 `BtApiBroker(store=store)` 退回 net 模式。

驱动脚本（临时文件，验收后即废弃）：

```python
import runpy, sys
suite_dir, case_file, rest = sys.argv[1], sys.argv[2], sys.argv[3:]
sys.path.insert(0, suite_dir)

import backtrader.brokers.btapibroker as _bmod
from common import config as cfg

_ORIG = cfg.create_config
def _patched(env_key=None):
    conf = _ORIG(env_key)
    conf.setdefault("position_mode", "dual_side")
    return conf
cfg.create_config = _patched

class _DualSideBtApiBroker(_bmod.BtApiBroker):
    params = (("position_mode", "dual_side"),)

_bmod.BtApiBroker = _DualSideBtApiBroker
sys.argv = [case_file] + rest
runpy.run_path(case_file, run_name="__main__")
```
