# 迭代47 — 因子 build 简洁模式与算子增强实施计划

版本：**v0.1**；更新：**2026-10-21**。状态：**未开始；E1–E4 全部 NOT_RUN。** 本计划只负责迭代47，依赖迭代45已验收的原生引擎和迭代46的 native 对照库。本文不是执行报告，不表示 `panel_mode="expression"` 或共享 DAG 已经存在。

## 1. 定位与依赖

迭代47在迭代45的原生引擎和迭代46的 native 库之上，实现用户要求的 `build` 简洁模式：因子作者只写 `build(ctx, **params)` 声明，算法交给底层 PanelEngine 和已注册算子。API 上该模式名为 `panel_mode="expression"`，本文以下“build/expression 模式”同义；它只是同一引擎的声明前端，不是第二套执行器。

**相关算子优先加到对应的 Indicator 类/共享指标基类上**，由 native 和 build 共同调用；不建立只供 build 使用的第二套算子实现，也不把算法复制进每个因子声明。

## 2. 目标与范围

### 2.1 必须交付

1. `panel_mode="expression"` 完整实现：`build` 每定义调用一次、不注册普通实例、共享 DAG、节点缓存、H 编译、`ConfigError`、字段/PIT/profile 校验和每 grid 一次执行。
2. 算子增强：按迭代45/46依赖盘点，把缺失算子加到相应 Indicator/共享指标类；native 路径和 build 路径共用同一实现、同一数值合同和同一测试黄金值。
3. 20个代表式的 build 实现；每式同时有独立参考和迭代45/46的 next 结果对照。
4. 两模式等价：完整面板、NaN mask、缺失/退化原因、时间/资产索引、公式池和边界一致；允许浮点容差按 DS45-13 冻结。
5. 混合装配：build 因子与普通 Indicator、next 因子在同一 FactorStrategy/Cerebro 中并列采集，不互相抢占 grid，不产生第二次回调。
6. 已安装 Backtrader/fincore 产物上的20式集成、迁移说明和 #3 build 原型收口。

### 2.2 明确不做

- 不实现全101 build 库；20式等价不能替代全101验收。
- 不允许 expression 绕过字段/PIT/profile/H 合同，也不允许 build 节点执行任意 Python 回调。
- 不建立 build 专用第二套算子、第二套调度或第二套结果模型。
- 不重写迭代45/46已验证的 native 算法；等价验收必须两边各自对独立参考，不能只做 next/build 互相一致。
- 不承诺原论文收益，不触碰账户、私有配置、实盘进程或 CTP/live 边界。

### 2.3 模式边界

`panel_mode="expression"` 是声明前端：作者只实现 `build(ctx, **params)`，算法交给共享 DAG 和已注册算子执行；不创建普通实例，不逐因子重写 `Strategy.next`。两种模式共用同一 grid 屏障、同一字段/PIT/profile/H 校验、同一 PanelEngine 和同一 `get_dataset()`。正式结果只经 `get_dataset()` 返回 time×asset 原始因子面板；`self.outputs[data]` 是 panel 内部采集接口。

## 4. 等价与混合装配合同

- **独立参考**：每个代表式先写不调用生产算子/求值器的参考实现，分别验证 next 和 build；next/build 结果对照只作为额外门槛。
- **完整面板**：时间索引、资产索引、有效/缺失位置和 NaN mask 必须一致；不能只比较非空交集。
- **原因与退化**：缺失输入、零分母、分类缺失、分位退化等按 DS45-13 记录并一致；不允许一边静默补值。
- **公式池与 PIT**：两种模式使用同一 `formula_universe`、同一 PIT 成员和同一行业层级；build 不得绕过成员校验。
- **混合装配**：普通 Indicator、next 因子、build 因子可并列；每 grid 只推进一次，不产生第二次回调或重复写入。
- **容差**：浮点差异按 DS45-13 冻结；差异超出容差必须定位实现问题，不得放宽阈值结案。

## 5. 验收与退出

同时满足才可关闭迭代47：

1. `panel_mode="expression"` 可用：`build` 一次、共享 DAG、节点缓存、H 编译、字段/PIT/profile/H 拒绝和每 grid 一次执行均通过；不创建普通 Indicator 实例。
2. 相关算子已加到对应 Indicator/共享指标类，native/build 共用同一实现；101依赖清单无未解决算子缺口。
3. 20/20代表式 build 有独立参考，并与 next 结果在完整面板、NaN mask、原因、时间/资产索引上等价；混合装配每 grid 一次。
4. 已安装 Backtrader/fincore 产物上的20式集成和 #3 主路径通过；AC45-25/27/28的 expression 部分和 AC45-29 完成，AC45-20 按 AC45-01–30 的实际子断言收口。
5. 不实现、不宣称全101 build 库；迭代48才做81式新增和全101 build 验收。

若 E1/E2 未稳定，迭代48不得开工全101 build；迭代47仍可保留20式 source 诊断，但不得把 source 测试、027原型或 next 已通过当作 expression 通过。
