## Known limitation and safety boundary

The candidate preserves a concrete residual: a custom injected API can hide CTP `exchange_kwargs` through `__getattribute__` when the Store snapshot is empty, leaving the route unobservable and allowing a local fake direct sink. P3 reproduced this; the patch must not be described as closing arbitrary same-process or hidden-metadata paths. No secrets/private configuration were copied. Only local guarded/fake test subsets and static inventory checks are reported; no full Runtime, real SDK/native, provider, credential, external-network, order, or cancel acceptance is claimed.
