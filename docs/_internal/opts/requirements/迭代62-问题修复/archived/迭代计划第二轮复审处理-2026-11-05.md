# 迭代 62 第二轮复审处理记录（2026-11-05）

## 补充发现

- 当前 `BtApiBroker` 的 `flatten_on_stop=True` 和停止时发平仓路径，与已确认的停止撤单、不自动平仓有冲突；纳入 62.05/07 和验收。正常停止不能撤销别的策略或手工订单。
- SDK 的派发前持久化合同应使用中立宿主身份；只有 BT 宿主使用策略 UUID，结算等非订单操作不能强制伪造 BT 订单身份。
- CTP 当前来源时间无效时有回退本机时间的路径，原生毫秒缺失可能被补零，不能当成来源时间或真实精度；当前接收时点在回调处理过程中。SDK 的中立时钟投影也需改造，不能只修改 provider 并宣称链路完整。
- 上述为静态分析和目标设计，实际 provider、发行包、账户授权、时钟误差、跨会话查询和真实交易效果均待分层验证。
