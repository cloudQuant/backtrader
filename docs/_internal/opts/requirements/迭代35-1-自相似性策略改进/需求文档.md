## 1. 目标与边界

以 FNN 自编码器对 XAUUSD 1 分钟特征窗口做非线性编码，在**全历史滑动窗口向量库**中以余弦
相似度检索 Top-N 最相似历史样本，统计其后续 `horizon_bars` 根 bar 的方向调整收益，通过
统计置信门与成本门后开仓；到期退出并带 ATR/点差下限的 OCO 保护。交付独立示例目录
`examples/017_fnn_embedding/`，支持单次回测详细日志与受预算约束的参数优化两种模式。

迭代35 的四项结构性缺陷必须被本需求显式修复：候选池过小（W1）、度量相位零容忍（W2）、
小样本点估计门（W5）、期望门无成本意识（W6）。

**范围边界**：不接入 BtApiStore/CTP/SimNow；不新建 examples 公共层；数据仅用
`tests/datas/XAUUSD_M1.csv`（2021-08-12 ~ 2026-03-24，约 163 万行）；`examples/016_self_similarity/`
保留不动作为对照基线。

## 3. 术语与口径

- **样本（窗口）**：以某根 bar 的终点为窗口终点、向前 `window_bars`（默认 75）根同交易日且
  time-of-day 连续的 M1 bar；有效性条件同迭代35 FR35-02（缺口/跨日 → 无样本）。
- **特征向量 x**：窗口的 12 维统计特征（设计 D351-03 冻结清单）。
- **归一化**：逐特征 z-score，均值/方差只用该样本决策时点之前最近 `norm_window`（默认 2000）
  个历史样本估计。
- **embedding**：`v = encoder(x)`，`embed_dim`（默认 4）维；库内向量与当前向量均在同一
  次训练的编码器版本下产生。
- **余弦相似度**：`sim = v·v' / (‖v‖‖v'‖ + ε)`。
- **exclusion zone**：库中窗口终点与当前窗口任一 bar 重叠（时间距离 < window_bars）的样本
  剔除；Top-N 去相关：贪心取样，入选样本两两时间距离 ≥ `dedup_gap`（默认 window_bars/2）。
- **后续收益标签 fr**：与执行口径一致：`fr = ln(Open[t_end+1+H] / Open[t_end+1])`，
  H = horizon_bars；样本标签在其完全实现（决策时点 ≥ t_end + H + 1）前不得入检索库。
- **方向调整收益**：`adj = sign(sim − 0.5) × fr`；余弦相似度 >0.5 视为正相关跟随、<0.5 视为
  镜像（设计 D351-07 论证：余弦值域 [−1,1]，以 0.5 为正/负相关的中性带默认边界，参数化）。
- **成本**：`round_trip_cost = 2×commission_pct + spread_cost_pct`（默认 0.0002×2 + 0.00015）。
- **Wilson 下界**：`p_low = (p̂ + z²/2n − z√(p̂(1−p̂)/n + z²/4n²)) / (1 + z²/n)`，z=1.96，n=Top-N 实际样本数。

## 4. 功能需求

所有 FR 均为 P0（除标注 P1）。验收 ID 在[验收文档](验收文档.md)逐项展开。

| ID | 必须满足的需求 | 通过标志 |
|---|---|---|
| FR351-01 | 经 `load_mt5_csv` 加载数据并做启动校验（行数/时间范围/单调性/OHLC 合法）；fromdate/todate 切片 | 非法数据在回测前拒绝并给原因码 DATA_INVALID |
| FR351-02 | 特征引擎（纯函数）：有效窗口 → 12 维特征向量；特征清单与公式冻结于设计 D351-03；窗口无效返回 NO_WINDOW | 特征 oracle 数值表通过（容差 1e-10） |
| FR351-03 | 滚动 z-score 归一化：均值/方差只用决策时点前 `norm_window` 个历史样本；norm_window 不足时样本拒绝 | 归一化无前视用例：篡改未来数据不改变历史归一化值 |
| FR351-04 | FNN 自编码器：encoder/decoder 结构、`embed_dim`、epoch、lr、batch、早停等全部超参数化；AE 损失为重构 MSE | 超参快照入 config 与结果 JSON；无隐藏常量 |
| FR351-05 | 滚动训练：每 `retrain_freq`（默认 20）交易日、仅用决策时点前样本重训；torch 种子与线程数固定；模型权重+归一化参数+时间戳落盘缓存；回测一律加载缓存模型 | 同种子两次训练权重逐位一致；缓存命中时不重训 |
| FR351-06 | 训练质量报告：重构误差曲线、邻域保持率（原始空间 kNN 与 embedding 空间 kNN 的 Jaccard 均值）、重训间 embedding 漂移（Procrustes 距离） | 报告落盘；邻域保持率显著高于随机基线（>0.15）方视为编码有效 |
| FR351-07 | 历史向量库：全历史滑动窗口（`stride` 默认 1）；库样本特征向量与 embedding 在当前编码器版本下批量预编码；标签延迟入库（G351-02②） | 库大小、入库时点可审计；不存在标签未实现样本 |
| FR351-08 | 余弦检索：exclusion zone 剔除；Top-N 去相关贪心取样（两两时间距离 ≥ dedup_gap）；相似度门 `sim_threshold` | 检索 oracle（迷你库已知答案）通过；Top-N 时间距离断言通过 |
| FR351-09 | 相似度门与样本门：入选样本（sim ≥ sim_threshold 且去相关后）数量 < `min_matches`（默认 10）→ 拒绝 | 边界（恰等于阈值、n=min_matches−1）行为明确 |
| FR351-10 | 统计决策双门：`p_low ≥ prob_threshold`（默认 0.75）开仓方向侧；`expected_return ≥ k_cost × round_trip_cost`（k_cost 默认 1.5）期望门；任一不满足拒绝并给原因码 | Wilson oracle 数值表通过；成本门边界用例通过 |
| FR351-11 | 方向映射：adj>0 占优（p_low 过门）→ 做多；adj<0 占优 → 做空；由 `sign(sim−0.5)×fr` 统一实现 | 四象限映射 oracle 通过 |
| FR351-12 | 执行模型：信号 bar 收盘判定、次 bar 开盘市价成交；持有 horizon_bars 到期平仓；OCO 止损止盈距离 = exit_multiple×er 且 **下限 max(ATR 门, 点差门)**（设计 D351-08 公式）；末端强平 | 到期/止损/强平的 bar 时序与价格 oracle 通过 |
| FR351-13 | 单仓约束：持仓期间不判定新信号（记录 POSITION_OPEN） | 持仓期间开仓订单数为 0 |
| FR351-14 | 无前视三重防线：①训练集只含决策时点前样本 ②标签延迟入库 ③归一化滚动估计（与 FR351-03/05/07 联动） | 篡改 t_cut 后数据，t_cut 前的决策序列（含 embedding 检索结果）逐条一致 |
| FR351-15 | 参数化：窗口/持有/Top-N/sim_threshold/prob_threshold/min_matches/k_cost/exit_multiple/retrain_freq/embed_dim/stride/norm_window 等全部进策略 params 与 config.yaml，未知键拒绝 | 参数表与 config schema 一一对应 |
| FR351-16 | 单次回测装配 TradeLogger（MySQL 关、逐 bar 流关）与 signals.jsonl（扩展：Top-N 相似度分布、库大小、编码器版本号） | 日志文件存在且字段完整可解析 |
| FR351-17 | 优化模式：仅交易层参数进网格（FNN 超参与 retrain_freq 不进网格）；总组合数 ≤ 试验预算 24；并行 8 进程与串行一致；优化模式不产生任何 per-trade/per-bar 日志 | 结果行数=组合数且 ≤24；日志产物为零 |
| FR351-18 | 标准结果 backtest_result.json：字段对齐迭代35（FR35-15）并扩展策略专属字段（avg_sim、库命中率、编码器重训次数、邻域保持率摘要） | schema 校验通过；独立重算一致 |
