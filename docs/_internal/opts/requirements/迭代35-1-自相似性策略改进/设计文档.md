## D351-03 特征引擎（12 维，冻结清单）

以窗口（W=window_bars 根 bar，收盘价 c_i、开 o_i、高 h_i、低 l_i、tickvol v_i，
i=1..W 按时间升序）为输入，输出 12 维特征（全部无量纲化前为原始统计量）：

| # | 特征 | 公式 | 备注 |
|---|---|---|---|
| f1 | 前段累计收益 | ln(c_W/2 ÷ c_1) | 前 1/3 与中 1/3 交界 |
| f2 | 中段累计收益 | ln(c_{2W/3} ÷ c_{W/2}) | |
| f3 | 末段累计收益 | ln(c_W ÷ c_{2W/3}) | 三段拼接近似全窗收益 |
| f4 | 已实现波动 | std(ln(c_i/c_{i-1})) × √(W−1) | 标准化到窗口尺度 |
| f5 | RSI | RSI(14) 以窗口末端计 | Wilder 平滑，窗口内自包含计算 |
| f6 | 动量 | c_W/c_1 − 1 | 与 f1~f3 冗余度低（价格比非对数）保留 |
| f7 | 区间位置 | (c_W − min l_i)/(max h_i − min l_i + ε) | 收盘处于窗口高低区间的位置 |
| f8 | 实体占比 | mean(\|c_i−o_i\|/(h_i−l_i+ε)) | K 线结构 |
| f9 | 上影占比 | mean((h_i−max(o_i,c_i))/(h_i−l_i+ε)) | |
| f10 | 下影占比 | mean((min(o_i,c_i)−l_i)/(h_i−l_i+ε)) | |
| f11 | 量能水平 | mean(ln(v_i+1)) | TICKVOL 对数均值 |
| f12 | 量能趋势 | mean(ln(v_i+1))[后半] ÷ (mean(ln(v_i+1))[前半] + ε) | 换手变化 |

实现为纯函数 `window_features(rows, arrays) -> np.ndarray(12)`；窗口有效性条件同迭代35
（同交易日、time-of-day 连续、长度足够，否则 `NO_WINDOW`）。W=75 时 W/2、2W/3 取整向下。

**滚动归一化**：`x_norm = (x − μ_j)/σ_j`，μ_j/σ_j 为特征 j 在该样本决策时点前最近
`norm_window`（默认 2000）个有效样本上的均值/标准差（σ_j ≤ 1e-12 时特征置 0 并计数告警）；
历史不足 `norm_min`（默认 500）时样本拒绝（`NO_NORM`）。归一化统计随样本推进在线维护
（增量计数器），O(1)/样本。

**特征 oracle**：构造 5 根合成 bar（W=5）手算 12 维（验收 AC351-02 数值表，容差 1e-10）；
合成数据固定于单测内，不依赖真实文件。

## D351-04 FNN 自编码器（PyTorch）

```text
encoder: Linear(n_feat=12 → 32) ReLU Linear(32 → 16) ReLU Linear(16 → embed_dim)
decoder: Linear(embed_dim → 16) ReLU Linear(16 → 32) ReLU Linear(32 → 12)
损失: MSE(x_norm, decoder(encoder(x_norm)))；Adam lr=1e-3，batch=512
epoch=100，早停: 重构损失 10 epoch 无改善(容差 1e-6)终止
embed_dim 默认 4（保守起步，见计划 §6 风险表）；训练样本每次最多 max_train_samples=50000
（超出时按时间倒序等距抽样至 50000）
```

确定性措施（NFR351-02 的实现基础）：
`torch.manual_seed(42)`、`torch.use_deterministic_algorithms(True)`、
`torch.set_num_threads(1)`、DataLoader 打乱用固定生成器；输入为 float32 numpy（避免
pandas dtype 漂移）；训练完成后 `state_dict` 与归一化统计、训练时间戳、训练样本量
落盘 `models/step{idx}.pt + step{idx}.json`。

**AE oracle**（AC351-04）：固定合成数据 + 种子，两次独立训练后 `state_dict` 逐位一致；
同一权重对同输入两次前向输出一致（容差 1e-7）。

## D351-05 滚动训练器

1. **节奏**：交易日推进计数，每 `retrain_freq`（默认 20）个交易日触发一次重训；训练集 =
   该时点库中已实现标签的全部样本（上界 max_train_samples）。回测从 `models/` 加载
   `--use-cache` 指定版本；无缓存或 `--retrain` 时现场训练（现场训练仅在开发/复现流程用，
   正式回测一律用缓存保证确定性，见风险表）。
2. **编码同步**：每次重训后，库内全部样本立即以新编码器批量重编码（向量库与编码器版本
   严格绑定，`encoder_version = step{idx}`）；跨版本比较无意义。
3. **训练质量报告**：`reports/train_report.jsonl` 每行一次重训：
   `{step, train_samples, final_loss, epochs_run, neighborhood_retention, drift_procustes}`。
   - 邻域保持率：随机抽 200 个训练样本，原始 12 维空间 kNN(k=10) 与 embedding 空间
     kNN(k=10) 的 Jaccard 均值；随机基线期望 ≈ 10/(2×2000)≈0.0025 量级，≥0.15 视为编码有效
     （FR351-06 的量化门）。
   - Procrustes 漂移：相邻两次编码器对同一组 1000 个锚样本的 embedding 做最优旋转对齐后
     的残差范数（监控空间突变）。

## D351-06 向量库与余弦检索

1. **库构建**：全历史有效窗口按 `stride`（默认 1）滑动生成；每条记录
   `{t_end, features(12), label_fr, encoder_version, embedding(embed_dim)}`。
   **标签延迟入库**：`label_fr` 在 t_end+H+1 之后才可计算——入库分两步：窗口特征先入"待定池"，
   标签实现后转入"可检索库"；检索只针对可检索库（G351-02②的机制化）。
2. **检索**（决策时点 t0，空仓时）：
   - 当前窗口特征 → 归一化 → encoder → `v_now`；
   - exclusion zone：库中 `t_end` 满足 `t0 − t_end < window_bars + horizon_bars`（含当前窗口
     重叠与其后标签未实现者）的样本剔除（后者已被延迟入库天然保证，前者显式剔除）；
   - 相似度：`sim = (E @ v_now)/(‖E‖_row × ‖v_now‖ + ε)`，E 为库 embedding 矩阵（float32，
     每 bar 决策一次矩阵乘，160 万 × 4 维 ≈ 640 万 flop，向量化 <1ms）；
   - **去相关 Top-N**：按 sim 降序贪心遍历，入选样本与已选样本的 `t_end` 差 ≥ `dedup_gap`
     （默认 window_bars/2 = 37 bar，跨日按日历分钟数计算），直至取满 `top_n`（默认 30）或
     遍历完 sim ≥ sim_threshold 的样本；
   - 命中数 n = 实际入选数。
3. **启动前置诊断**（吸取迭代35 E1/E2 教训，实施第一步执行）：全库对若干探测时点跑相似度
   分布，输出分位数表（P50/P90/P99/P99.9/max）；若默认 `sim_threshold=0.8` 命中率 <0.1%，
   按"探测分布 P99"校准默认值并写入实施记录（等价于迭代35 D35-09 的实测修订流程）。

**检索 oracle**（AC351-06）：构造 6 样本迷你库（embedding 手工指定：[1,0,0]、[0,1,0]、
[1,1,0]/√2、[−1,0,0]、[0.5,0.5,0.5]×√(4/3)、[1,0,0]），v_now=[1,0,0]，window/去相关参数
构造时间上满足距离约束：断言 Top 顺序 = {[1,0,0], [1,0,0], [1,1,0]/√2}（前两个互为同向
不同时间的合法样本），sim 依次 1.0、1.0、0.70711（容差 1e-7）；[0,1,0] 的 sim=0 被门剔除。

## D351-07 统计决策链

判定顺序（每根 bar 收盘、空仓时）：

```text
窗口有效? ─否→ NO_WINDOW
归一化统计充足? ─否→ NO_NORM
库非空(exclusion 后)? ─否→ NO_SAMPLES
n ≥ min_matches? ─否→ INSUFFICIENT
expected_return ≥ k_cost × round_trip_cost? ─否→ COST_BELOW   （先成本后概率，理由：成本门独立于方向统计，先拒绝零成本可行性问题）
p_low ≥ prob_threshold? ─是→ LONG
p_low ≤ 1 − prob_threshold? ─是→ SHORT
否则 → PROB_BELOW
```

- `adj = sign(sim_i − sim_neutral) × fr_i`，`sim_neutral` 默认 0.5（余弦中性带边界，参数化；
  需求 §3 口径）。`p̂ = mean(adj > 0)`，`expected_return = mean(adj)`，`p_low` 为 Wilson 下界。
- **Wilson oracle**（AC351-09，z=1.96）：
  - n=20、p̂=0.80 → `p_low = (0.8+0.09604−1.96×0.10198)/(1.19208) = 0.5840`（容差 1e-4）→
    低于 0.75 → PROB_BELOW；
  - n=50、p̂=0.90 → `p_low = (0.9+0.038416−1.96×0.046733)/(1.076832) = 0.7864` → 通过 → LONG；
  - 边界：n=30、p̂=0.8（p_low=0.6269，PROB_BELOW）；n=30、p̂=0.9（p_low=0.7438，恰好不过
    0.75，断言拒绝路径——该组用于验证"接近阈值"的边界行为）。
- **成本门 oracle**：round_trip_cost=0.00055、k_cost=1.5 → 门 = 8.25e-4；er=8.24e-4 →
  COST_BELOW；er=8.25e-4 → 通过（等号含于通过侧，与 FR351-10 ≥ 语义一致）。
- **方向映射四象限 oracle**（AC351-11）：全 sim>0.5 + 多数 fr>0 → LONG；全 sim>0.5 + 多数
  fr<0 → SHORT；全 sim<0.5 + 多数 fr>0 → SHORT（镜像）；全 sim<0.5 + 多数 fr<0 → LONG。

## D351-08 执行模型与退出

1. **成交时序**：完全继承迭代35 D35-07——信号 bar t0 收盘判定 → 次 bar 开盘市价成交 →
   持有 horizon_bars（默认 15）→ t0+15 收盘 `close()` → t0+16 开盘平仓；与标签口径
   `fr = ln(Open[t_end+1+H]/Open[t_end+1])` 精确一致。末端强平标记 `forced_liquidation`。
2. **OCO 止损止盈（含下限，治 W9）**：对数距离
   `m_log = max(exit_multiple × expected_return, m_stop_floor)`，其中
   `m_stop_floor = ln(1 + max(atr_floor × ATR_fast, spread_floor × spread_dollar/entry))`：
   - `ATR_fast`：最近 14 根 M1 的平均真实波幅（bar 级，非年化）；
   - `atr_floor` 默认 1.0（ATR 单位）；`spread_floor` 默认 1.5；
   - `spread_dollar`：`entry × spread_cost_pct`（与成本门同源）。
   止盈距离对称取 `max(3×er, m_log)`。挂单价 = entry×e^{±m}，其余 OCO 机制（oco= 互连、
   到期撤两腿、触发即撤另一腿）与迭代35 D35-07.3 相同。
   **价格 oracle**（AC351-12）：entry=2000.00、er=1e-4、exit_multiple=3 → 名义 3×er=3e-4；
   构造 ATR_fast=0.80 美元、spread_cost_pct=0.00015（spread_dollar=2000×0.00015=0.30）→
   floor 金额 = max(atr_floor×ATR, spread_floor×spread_dollar) = max(1.0×0.80, 1.5×0.30)
   = 0.80 美元 → m = ln(2000.80/2000) = 3.9992e-4 > 3e-4（下限生效）→ 止盈价
   2000×e^{3.9992e-4} = 2000.80、止损价 2000×e^{−3.9992e-4} = 1999.20（相对容差 1e-8）。
   断言下限生效路径；另构造 ATR_fast=0.05 组验证下限不生效时回退 3×er。
3. **成本撮合**：commission_pct 双边 + `spread_cost_pct` 进入期望门（D351-07）；撮合侧仍用
   commission 参数（SPREAD 列不参与撮合——局限声明 D351-15.1，与迭代35 同边界）。

## D351-09 参数体系与 config schema

策略/引擎参数（与 config `params` 一一对应；带*者可进优化网格）：

| 参数 | 默认 | 含义 | 约束 | 网格 |
|---|---|---|---|---|
| window_bars* | 75 | 特征窗口 bar 数 | ≥5 | [60, 75, 90] |
| horizon_bars* | 15 | 持有/标签期 | ≥1 | [10, 15, 30] |
| top_n* | 30 | 去相关后 Top-N | ≥min_matches | [20, 30, 50] |
| sim_threshold* | 0.8 | 相似度门 | (−1,1] | 按启动诊断校准后 ±0.02 |
| prob_threshold* | 0.75 | Wilson 下界方向门 | (0.5,1) | [0.70, 0.75] |
| min_matches* | 10 | 最小入选样本 | ≥5 | 固定 |
| k_cost* | 1.5 | 期望成本安全系数 | >0 | 固定 |
| exit_multiple | 3.0 | OCO 倍数 | >0 | 固定 |
| embed_dim | 4 | 隐向量维度 | 2~16 | 不进网格 |
| retrain_freq | 20 | 重训间隔（交易日） | ≥5 | 不进网格 |
| stride | 1 | 库滑动步长 | ≥1 | 不进网格 |
| norm_window | 2000 | 归一化回看样本 | ≥norm_min | 不进网格 |
| norm_min | 500 | 归一化最少样本 | ≥100 | 不进网格 |
| sim_neutral | 0.5 | 正/负相关中性带 | (0,1) | 不进网格 |
| dedup_gap | window/2 | Top-N 去相关距离 | ≥10 | 派生 |
| atr_floor | 1.0 | 止损 ATR 下限系数 | >0 | 固定 |
| spread_floor | 1.5 | 止损点差下限系数 | >1 | 固定 |

训练超参（epoch/lr/batch/早停/seed/max_train_samples）在 `training:` 段，不进网格。

config.yaml 结构对齐迭代35（schema_version/strategy_id= `fnn_embedding_017`/mode/data/params/
training/backtest/logging/optimize/outputs），未知键启动拒绝。

## D351-12 性能预算

| 项 | 估算 | 预算 |
|---|---|---|
| 数据加载+索引 | O(N)，N≈163 万 | <20s |
| 特征全库计算 | 163 万窗口 × 12 维（RSI/滚动统计向量化） | <3min |

| 逐 bar 决策 | 空仓 bar × (12 维特征增量 + 检索矩阵乘 + AE 前向) | <3min |
| 优化 18 组（缓存模型） | 18 × 回测/8 进程 | <30min |

缓解顺序（超预算时）：先降 max_train_samples/epoch → 再降 retrain_freq（20→40）→ 最后
stride（1→2，库减半）——正确性语义不变项优先。

## D351-15 已知局限（显式声明）
