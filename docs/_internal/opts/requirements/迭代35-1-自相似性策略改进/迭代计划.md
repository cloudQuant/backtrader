## 1. 背景与问题边界

初始需求判定"迭代35 的逻辑有点问题"，要求按**方案 A** 重写：FNN（前馈神经网络）自编码器
把时序特征窗口压缩为低维隐向量，用余弦相似度在历史向量库中检索与当前市场状态最相似的
Top-N 样本，统计其后续涨跌方向决定多空，相似度过低不交易。

迭代35 的实测证伪结论（证据编号沿用[复盘分析](../迭代36-自相似策略改进/迭代35复盘分析.md)）：
E1 默认阈值零交易；E2 max|corr| 中位 0.259、≥0.6 命中 0%；E3 27 组参数全亏；E4 候选池
仅 60 个同时刻窗口、入选中位 1.5~2.3 个；E5 信号期望 ~0.007% vs 成本 ≥0.04%；E6 点差/
滑点未建模。方案 A 相对迭代35 的结构性差异，恰好对应证伪根因：

| 迭代35 根因（复盘 W*） | 方案 A 的对应改善 | 对应方向 |
|---|---|---|
| W1 候选池被时刻对齐压缩 4 个数量级 | 全历史滑动窗口向量库（"所有历史向量"） | D36-021 |
| W2 Pearson 对时间轴错位零容忍 | FNN embedding 学习鲁棒表征（训练目标驱动，非手工度量） | D36-010 |
| W3 单一收益序列、单一切面 | 特征向量：收益率/波动率/RSI/动量多维 | D36-018 |
| W5 小样本方向概率点估计 | Top-N 统计 + 置信下界门（N 扩大后统计才成立） | D36-031/032 |
| W6 期望门无成本意识 | 期望门计入双边成本硬约束 | D36-038 |
| W13 无过拟合量化 | 噪声对照 + DSR/PBO + 试验预算 | D36-081/083 |

**边界**：本地研究型示例迭代；仅离线回测；不接实盘/仿真链路；不修改 backtrader 核心
公共 API；数据仍用 `tests/datas/XAUUSD_M1.csv`；新示例目录 `examples/017_fnn_embedding/`
（016 已被迭代35 占用），复用迭代35 的工程骨架（run.py 组合根、TradeLogger、
backtest_result.json schema、signals.jsonl 诊断流）而不复制其匹配逻辑。

## 2. 歧义裁决（初始需求模糊点的规格化）

| 歧义点 | 裁决 | 理由与回退 |
|---|---|---|
| "之后 N 日涨跌幅"的时间尺度 | **后续 N 根 M1 bar**（`horizon_bars` 参数化，默认 15 继承迭代35 以保持可比） | 唯一可用数据为 M1；"N 日"按上下文理解为"N 个周期"。回退：若日线研究成为目标，需另接日线数据源，另立迭代 |
| "每一段历史 K 线"的窗口长度 | `window_bars` 参数化，默认 75（与迭代35 可比）；特征按窗口统计 | 消融实验覆盖 [30, 240] |
| 特征集构成 | 最小特征集起步：窗口分段收益率(3 段)、已实现波动率、RSI(14)、动量、区间位置、K 线实体占比等 8~12 维；最终清单在设计文档冻结 | 初始需求列举"收益率、波动率、RSI、动量等"；维度过大加剧过拟合 |
| FNN 实现载体 | PyTorch（执行环境已确认 torch 2.13.0）；sklearn MLP 仅作对照基线 | 环境事实；手写 numpy 版仅当 torch 确定性无法满足时启用 |
| 训练目标 | 自编码器 AE（输入=输出重构），初始需求明示 | — |
| 历史向量库范围 | **全历史滑动窗口**（步长 stride 参数化，默认 1 bar），非同时刻对齐；含防泄漏护栏（见 G351-03） | 吸收 W1；"所有历史向量"逐字落实 |
| 训练数据切分 | 滚动训练（walk-forward）：任何决策时点的 FNN 与归一化参数只用该时点之前数据 | 防前视的硬约束（见 G351-02） |
| "相似度过低不交易" | Top-N 的最低余弦相似度门 `sim_threshold` 参数化 + Top-N 内部去相关（重叠窗口合并） | 防止 Top-N 全为同一行情的平移 |
| 统计开仓门 | 方向概率 Wilson 95% 下界 ≥ `prob_threshold` 且成本调整期望 > 0（双门） | 吸收 W5/W6 |
| 止损/退出 | 到期退出继承迭代35；止损止盈距离以 ATR 尺度为下限（不允许小于点差） | 吸收 W9；完整退出重设计留待后续迭代 |

## 3. 目标与不变量

| ID | 目标 | 不变式 |
|---|---|---|
| G351-01 | 完整实现方案 A 四步逻辑（特征→FNN 编码→余弦检索→Top-N 统计交易），全部逻辑参数化 | 行为与需求文档 FR 表一一对应，无硬编码魔数 |
| G351-02 | **无前视（三重防线）**：① FNN 训练集只含决策时点前样本；② 向量库样本的后续收益标签必须已实现（样本窗口终点早于决策时点−horizon_bars）；③ 特征归一化参数（均值/方差）只用滚动历史估计 | 未来 bar 篡改审计：修改 t_cut 后数据不改变 t_cut 前的 embedding/检索/决策序列 |
| G351-03 | 检索去相关：与当前窗口时间重叠的库样本剔除（exclusion zone ±window_bars）；Top-N 内部互斥取样（相邻样本合并为一个"事件"） | Top-N 样本两两时间距离 ≥ window_bars/2，可审计 |
| G351-04 | 统计严谨门：方向概率用 Wilson 下界；期望门计入双边成本（commission+点差估计）；Top-N < `min_matches` 拒绝 | 拒绝信号携带原因码；成本参数敏感性入报告 |

| G351-07 | 工程复用：复用迭代35 的 TradeLogger/结果 schema/run.py 组合根模式；新目录独立可运行，不依赖其他 examples | 导入图审计；核心零修改 |

## 4. 工作包

依赖关系：A → B → C → D 顺序依赖；E 依赖 A/B/C；F 贯穿。

### WP351-A：特征工程与样本库（P0）

1. 特征函数组（纯函数、独立单测）：窗口 → 8~12 维特征向量；含 z-score 滚动归一化。
2. 样本库构造：全历史滑动窗口的 (特征向量, 窗口终点时间) 表；标签（后续 horizon_bars
   对数收益）按 G351-02 ②延迟入库。
3. 特征缓存落盘（parquet/npy），供训练与检索共享。

### WP351-B：FNN 自编码器训练管线（P0）

1. 模型：encoder（特征维度→…→`embed_dim` 默认 8）+ decoder（对称重构）；PyTorch，参数
   （层数/宽度/embed_dim/epoch/lr）全部进 config。
2. 滚动训练器：按 `retrain_freq`（默认每 20 交易日）用截至当时的库样本重训；种子固定、
   线程数固定；模型权重+归一化参数+训练时间戳落盘。
3. 训练质量报告：重构误差、embedding 空间的邻域保持率（kNN 一致性：原始空间近邻在
   embedding 空间仍近邻的比例）。

### WP351-C：余弦检索与统计决策（P0）

1. 推理：当前窗口特征 → encoder → `v_now`；库内向量余弦相似度（向量化/FAISS 可选）。
2. 检索：exclusion zone 剔除（G351-03）→ Top-N 去相关取样 → 相似度门 `sim_threshold`。
3. 统计：Top-N 样本标签的 Wilson 下界方向概率、均值/中位期望、成本调整双门判定
   （G351-04）；原因码枚举（NO_SAMPLES/LOW_SIM/INSUFFICIENT/PROB_BELOW/NEGATIVE_ER/...）。
4. signals.jsonl 诊断流扩展：记录每次检索的 Top-N 相似度分布、embedding 范数、库大小。

### WP351-D：执行、风控与优化模式（P0）

1. 执行模型继承迭代35（次 bar 开盘成交、到期平仓、OCO 止损止盈）；止损距离下限
   max(3×er, 1×ATR, 点差×1.5)。
2. 成本：commission_pct + `spread_cost_pct` 估计值计入期望门与撮合（保守取值）。
3. `--mode optimize`：FNN 结构/训练超参 **不进网格**（训练成本高且过拟合风险大）；网格
   只覆盖交易层参数（window/horizon/Top-N/阈值类），试验次数预算 ≤ 24 组合。

### WP351-E：测试与审计（P0）

1. 单元 oracle：特征计算数值表、AE 重构收敛、embedding 确定性（同输入两次前向一致）、
   余弦检索正确性（构造已知答案的迷你库）。
2. 无前视审计（G351-02 的三重防线各设用例）：篡改 t_cut 后数据，断言 t_cut 前决策序列
   逐条一致——**含 FNN 权重**（重训时训练集不含被篡改未来段的验证）。
3. 去相关审计：Top-N 样本时间距离断言（G351-03）。
4. 功能回归：小样本端到端（2021-09~2021-10），冻结指标断言。

### WP351-F：稳定性评估与文档（P1）

1. 三分评估（训练/验证/OOS 继承迭代35 切分），OOS 预注册一次评估。
2. 噪声对照（G351-06）：块打乱收益与相位随机化 surrogate 两种对照数据上重跑全流程。
3. 信号级诊断（吸收 D36-084/085）：IC/ICIR、事件研究（信号后 CAR 曲线）。
4. 五件套文档族收口：需求/设计/验收/任务按本计划展开后逐项执行回填。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **FNN 学到噪声**（embedding 无判别力，检索退化为随机） | 策略零信息 | WP-B 邻域保持率指标；噪声对照实验（G351-06）必须先于任何参数搜索执行；embedding 维度从 4 起步保守 |
| **滑动窗口样本高度重叠** → Top-N 全为同段行情平移，统计虚高 | 伪显著信号 | G351-03 exclusion zone + 去相关取样 + Wilson 下界（重叠样本等效样本量远小于 N） |
| 训练-推理不一致（滚动重训后 embedding 空间漂移，新旧向量不可比） | 检索失效 | 重训时全库向量同步重编码；记录每次重训的 embedding 空间漂移度量（Procrustes 距离）入报告 |
| torch 训练非确定性 | 不可复现（违反 G351-05） | 种子+单线程+确定性算法开关；权重落盘缓存，回测一律加载缓存模型不现场重训 |
| 训练成本（滚动×全库）过高 | 迭代不可用 | 特征缓存（WP-A3）；retrain_freq 默认 20 交易日；必要时 stride 加大（库抽样）；性能预算见 M2 准出 |
| 过参数化（特征维+网络超参+交易参数组合爆炸） | 过拟合 | FNN 超参不进网格（D 包）；总试验预算 ≤24 并登记；DSR/PBO 报告收口 |
| 期望低于成本（迭代35 同型死因） | 经济性必然 FAIL | G351-04 成本硬门从第一天生效；若门导致零交易，结论如实记录"成本不可行"而非放宽门 |
| torch 依赖与运行环境漂移 | 环境不可用 | 版本锁定写入 README 与验收记录（torch 2.13.0 / sklearn 1.6.1 / numpy 1.26.4 已确认） |
