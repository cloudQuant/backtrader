### 方案 A：FNN 做特征编码，余弦相似度做模式匹配（最常用）

1. 构造样本：每一段历史 K 线 / 因子序列，转成特征向量（收益率、波动率、RSI、动量等）。
2. 训练 FNN 编码器：输入一段时序特征，FNN 把它压缩到低维隐向量（embedding）。
   - 训练目标可以是自编码器 AE：输入 = 输出，让 FNN 学会把相似市场模式映射到相近向量。
3. 推理阶段：
   - 把**当前市场状态**送入 FNN，得到当前向量 \(\boldsymbol{v}_{now}\)。
   - 在历史向量库中，计算 \(\boldsymbol{v}_{now}\) 和所有历史向量的**余弦相似度**。
4. 交易规则：
   - 相似度最高的 Top-N 历史样本，统计它们之后 N 日涨跌幅；
   - 如果历史样本后续上涨概率高 → 开多；下跌概率高 → 开空；相似度过低 → 不交易。

> 
> 本质：FNN 负责把原始因子转换成更好的向量表征；余弦相似度负责检索 “历史上和现在最像的行情”，属于**基于案例的相似性回测策略**。
