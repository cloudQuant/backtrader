## 1. 定义、类型与术语规范

### 1.1 定义

跨期套利（Calendar Spread Arbitrage，商品市场亦称**月差套利**）是指在同一期货品种、**同一交易所**的不同到期月份合约上，同时建立数量相等、方向相反的头寸，在两合约价差偏离均衡水平时入场，待价差回归常态（或按交割逻辑收敛）时平仓获利的交易方式。

### 1.2 基本类型

| 类型 | 操作 | 别名 | 适用场景 |
|------|------|------|----------|
| 牛市套利 | 买近月、卖远月 | 正套（产业口径）、做多价差（近-远） | 预期近月相对走强：现货紧张、去库存、近月贴水待修复 |
| 熊市套利 | 卖近月、买远月 | 反套（产业口径）、做空价差（近-远） | 预期近月相对走弱：仓单压力、高库存、远月升水过大 |
| 蝶式套利 | 买两翼（近月+远月）、卖中间×2，或反向 | — | 对中间合约相对定价偏差下注，捕捉期限结构**凸性**变化，对冲曲线斜率风险 |

股指期货蝶式价差常定义为 `(ln F3 − ln F2) − (ln F2 − ln F1)`（新世纪期货）。商品蝶式价差常用 `BF = P_近 + P_远 − 2×P_中`。

### 1.3 术语规范（设计文档必读）

- **正套/反套的两种口径**：产业口径下正套 = 买近卖远（符合商品正常流向、以交割为底线）；基差口径下正套 = 做多基差/做多（近-远）价差（tipdm；申宝策略）。两套口径方向一致但表述不同，且**不同文献对"牛市/熊市套利"的方向叫法相反**（如新世纪期货把"卖近买远赌价差扩大"称牛市套利）——设计文档必须先统一定义再引用外部结论。
- **价差方向约定**：商品研报多用"近-远"（如动力煤 01-05）；股指研报多用"远-近"（如次月-当月）。本文各处沿用原文献约定并显式标注。
- **月差/基差/展期收益**：月差 = 近月-远月（或远-近，按约定）；基差 = 现货-期货；展期收益 = 多头移仓的现金流，三者相关但不同。

## 2. 理论基础：定价与经济逻辑

### 2.1 持有成本定价与合约间平价模型

**金融期货（股指）**：设现货价格 `S`、无风险利率 `r`、股息率 `d`：

```
F(T) = S · e^((r − d)·(T−t))
```

近月（到期 `t`）与远月（到期 `T`）之间的**平价关系**（李璁）：

```
F_T = F_t · e^(r·(T−t)) + ΔB        （ΔB 为均衡价差）
```

对数形式（JoinQuant）：`ln F2 − ln F1 = (r − q)(T2 − T1)`，无成本时 `(r−q)(T2−T1)` 即对数价差平衡点。远月理论价值的简化利率换算（优宽量化）：`F_far = F_near × (1 + Rf × month/12)`。

**商品期货**：加入仓储成本 `u` 与便利收益 `y`：

```
F(T) = S · e^((r + u − y)·(T−t))
```

`y` 是持有实物带来的隐性收益（Kaldor 1939 提出），是解释 Backwardation 与跨期套利空间的核心变量（详见 §2.4）。

**国债期货**：`F ≈ (P − Carry − O)/CF`，其中 `P` 为 CTD 全价、`Carry` 为净持有收益（票息−融资成本）、`O` 为交割期权价值、`CF` 为转换因子（华泰证券）。

### 2.2 无套利区间

**成本加成式**（李璁；瑞达期货）：设合约乘数 `M`、买卖手续费 `C_FS`/`C_FL`，无套利价差区间：

```
[ΔB − 2(C_FS + C_FL)/M ,  ΔB + 2(C_FS + C_FL)/M]
```

价差低于下界 → 买远卖近（赌扩大）；高于上界 → 卖远买近（赌收缩）。瑞达实务版把保证金资金成本、冲击成本纳入上下界。实证（李璁，IF1104/IF1106，2011）：ΔB = 449.2 点、成本合计 195.54 元 → 区间 [448.5, 449.9]。

**均衡价差 ΔB 的估计**：价差单向变动取算术均值（均值法）；双向变动取"均值符号 + 绝对偏差均值"（绝对偏差均值法）。股指期货因**不同月份分红率差异显著**，应使用**历史同期（同月份组合）数据**，而非连续价差均值（长城伟业，恒指各月平均价差比证据）。

### 2.3 期限结构与展期收益

- **Contango（正向市场）**：远月 > 近月，价差 ≈ 持有成本，常态结构；
- **Backwardation（反向市场）**：近月 > 远月，现货紧张、便利收益超过持有成本所致；
- **展期收益（Roll Yield）**：Backwardation 下多头移仓产生正现金流，Contango 下为移仓成本：

```
Roll Yield ≈ (F(t,T1) − F(t,T2)) / F(t,T1) × 365/(T2−T1)
```

- 期限结构斜率本身是可交易、可预测的变量：展期收益变化率与**库存消费比**显著负相关（原油市场约 −0.72，人人文库报告，数字供参考）；期限结构由深度 Contango 转平时常预示去库存加速，构成"多近空远"信号；
- Keynes 正常贴水理论与 Samuelson 假设（临近到期波动率上升）构成期限结构动态的理论背景。

### 2.4 库存理论与风险溢价（月差的经济锚）

**供给储存理论（Theory of Storage）谱系**：

- Kaldor (1939) 提出便利收益；Working (1949)、Brennan (1958) 完善：**便利收益是库存水平的递减（凸）函数**——库存越低、缺货（stock-out）风险越高、持有现货的便利越值钱、近月相对远月越强；
- Fama & French (1988) 实证：月差/基差包含预期现货价格变动与风险溢价两部分信息；
- Deaton-Laroque (1992) 与 Routledge-Seppi-Spatt (2000) 均衡模型：库存是吸收供需冲击的缓冲池，低库存时现货价格波动率上升，期货曲线形状反映库存状态与波动率预期；
- **Gorton, Hayashi & Rouwenhorst (2012, ROF/NBER w13249)**：31 种商品 1969-2006 系统实证——便利收益是库存的**递减非线性函数**；低库存 → Backwardation + 高风险溢价；现货/期货动量与 Backwardation 策略的超额收益，部分来自"在低库存时选中了商品"；**拒绝凯恩斯对冲压力假说**（持仓不是溢价主因，库存才是）；重要理论纠正：**Contango 下同样可以存在正风险溢价**——"正 roll yield 是多头盈利必要条件"的从业者观点在理论上不成立（正溢价来自为空头套保者提供保险的补偿，与曲线形状可分离）。

**对跨期套利的含义**：月差不是纯统计量，而是库存状态的价格化映射——库存数据（交易所显性库存、社会库存、港口库存、仓单）是月差策略最直接的基本面输入。

### 2.5 期限结构因子模型（曲线建模的学术主线）

把整条期货曲线作为对象建模，是跨期价差定价的高阶方法：

| 模型 | 状态变量 | 特点 |
|------|----------|------|
| 单因子（Schwartz 1997 模型一） | 对数现货价（均值回复） | 无法刻画曲线形态切换，铜/油拟合差 |
| **两因子（Gibson-Schwartz 1990；Schwartz 1997 模型二）** | 现货价 + 瞬时便利收益（均值回复） | 期货价有闭式解（对数正态）；能拟合曲线与波动率期限结构 |
| 三因子（Schwartz 1997 模型三；Miltersen-Schwartz 1998） | + 随机利率 | 拟合进一步改善，参数更多 |
| Schwartz (2000) 单因子近似 | 一个变量 | 用两因子结果校准，长期项目估值下近似等价 |
| **Cortazar-Naranjo (2006) N 因子仿射模型** | N 个潜在因子（随机游走 + 均值回复组合） | 用全部挂牌合约（而非仅主力）估计；状态空间 + Kalman 滤波 QMLE |
| Bollinger & Kind (2015) | 三因子 | 从曲线提取月度便利收益序列，再做资产定价分析 |

**估计方法**：状态空间形式 + Kalman 滤波（拟极大似然）是标准做法（Schwartz 1997 原文即用；Duffee-Stanton 2004 证明 QMLE 有限样本性质优于 EMM/SML）；R 语言有现成包 `schwartz97`（含参数估计、期货定价、曲线生成）。

**对跨期套利的含义**：(1) 曲线模型给出每个到期日的"理论价"，任何两腿的**理论月差**与实际月差之差即套利信号（本质是成本法的高阶版）；(2) 模型隐含的便利收益状态量可与库存数据交叉验证；(3) Power & Turvey (2008) 发现 2005 年后玉米/小麦/大豆曲线更像随机游走（生物燃料需求冲击后），**曲线可预测性本身随市场环境变化**——因子模型需要定期重估与失效检验。

### 2.6 移仓换月效应与错误定价

- Aitken & Frino (2002, JFM)：近月到期前，移仓盘显著放大价差错误定价，与近月持仓下降、远月持仓上升同步——**移仓窗口是套利机会与风险并存的高发期**；
- 华泰期货：T 合约最后交易日前 30 个交易日（移仓加速期）至到期，30 个历史到期合约中 14 个价差收窄——理论"当季净基差收敛→价差走阔"在移仓期常被移仓行为反向压制；
- 合约**上市首日**与**退市前一周**亦为错误定价高发窗口（曲传菊、杨皎平）。

### 2.7 均值回复的统计基础

- **协整**（Engle & Granger 1987）：同品种不同到期合约价格通常同阶单整且协整，价差/回归残差 I(0)；
- **OU 过程**：`dX = κ(μ − X)dt + σdW`；κ 决定回复速度与机会频率；**半衰期** `t½ = ln2/κ` 可作 z-score 滚动窗口长度的选择依据（QuantInsti）；
- **Hurst 指数**：H<0.5 均值回复、H=0.5 随机游走、H>0.5 趋势——事前过滤"伪均值回复"；
- **方差比检验**：检验价差均值回复的另一标准工具（股指跨期硕士论文）。

## 3. 分市场深度解析

### 3.1 股指期货（IF/IC/IH/IM）

#### 3.1.1 市场结构

- 挂牌当月、下月、当季、下季四份合约，**只有当月与次月流动性好**（上期所 GARCH 论文）；非主力合约流动性断崖——交割周前 3 天当月合约成交量可从几千手骤降至个位数，1 分钟 K 线出现跳变是流动性枯竭噪音而非信号（SegmentFault 连续合约研究）；
- 跨期价差 2015 年股灾前为正、股灾后转负、2016 上半年继续走低、2018 V 型——**价差中枢随贴水结构结构性漂移**（新世纪期货）；两合约到期日相距越远价差波动越大。

#### 3.1.2 长期贴水的形成机制（理解股指跨期价差的前提）

贴水不是单一原因，而是**结构性多空失衡 + 套利收敛机制受阻**的产物：

**基差分解**（广州期货，中国证券业协会转载）：

```
基差 =（市价 − 理论价）+ 理论基差
理论基差由 r、分红、距到期时间决定；前一部分由市场情绪与机构交易行为决定（影响更大）
```

为剔除分红与时间影响，可构造**综合基差** = 各合约剔除分红后基差按持仓量加权 + 平滑。

**空头力量（贴水来源）**：
1. **量化中性策略对冲**：2017 年起规模快速扩张，是长期贴水主因；因中小盘因子有效性更高，对冲集中在 IC → IC 贴水深于 IF/IH；2022.7 IM 上市后贴水率迅速超过 IC（广州期货；海富通；CSDN IC 贴水研究）；
2. **雪球产品对冲**：券商卖出雪球（相当于买看跌）后做 Delta 中性，正常区间"高抛低吸"（平滑基差）；**临近敲入时 Delta 暴增、被迫快速平掉多头**，基差剧烈波动；2021.12 雪球对冲持仓占 IC 总持仓约 14%（广州期货测算）；中金公司统计雪球对冲需求最高占 IC 空头持仓**三成**（CSDN 引述）；雪球主导期基差与行情呈负相关；
3. **指数增强裸多头**：多头端力量。

**多头/收敛力量为何失效**（IC 贴水长期不收敛的制度根源，CSDN IC 贴水研究）：
- 反向套利（买期货 + 卖现货）需融券：**融券保证金约 50%**、券源有限、成本高；
- 中证 500 成分股流动性不足，卖现货冲击成本大，系统性风险时流动性快速枯竭；
- 现货 T+1 vs 期货 T+0 的交易制度错配限制套利匹配效率；
- 套利资金因此偏好 IF/IH，IC 贴水的收敛动力被制度性削弱。

**对跨期套利的直接含义**：股指跨期价差中枢由"贴水结构 × 到期时间差"决定；贴水深度的结构性变化（中性策略扩张/萎缩、雪球发行节奏、监管政策）会**平移跨期价差中枢**——纯统计参数必须叠加贴水结构判断。另：**远季合约贴水通常浅于近月**（套保需求集中于近月），这本身构成跨期价差的系统性形态。

#### 3.1.3 分红季节性（最重要的日历变量）

- 指数对成分股除息不修正 → 分红集中月（6-7 月，即 7 月合约存续期内）合约理论价系统性偏低；A 股分红集中于 5-8 月（某年度该区间分红公司占全部 A 股约 63%，海富通）；
- **多 04/05/06、空 09 的"做空期限结构"可赚取分红收敛收益**；引入**校正价差 = 实际价差 + 区间分红点位**：IF 的 9-4/9-5/9-6 校正价差连续性很强（分红几乎是唯一驱动），IH 校正价差连续性差（对冲盘/情绪蚕食）（华泰期货《分红对股指期货及套利策略的影响》）；
- 实证（2019）：IF 从 04 主力期开始做空期限结构，至 06 到期累计 31.6 点，与已实现分红 31.01 点吻合；股息率 IH(≈3.27%) > IF > IC(≈1.31%)，分红套利空间 IH 最大；
- 分红点位需提前估算（预案/历史分红率），估算误差是主要模型风险。

#### 3.1.4 滚贴水策略（贴水结构交易的镜像）

国联期货《深度贴水下股指期货交易策略研究》：贴水（剔除分红）状态下长期滚动持有期货多头，收割贴水收敛 Alpha——2015.4 以来滚动持有 IC 当月累计 **142.5%** vs 中证500 指数 −27.8%（几何超额 235.7%）；用 **ETF 期权合成标的升贴水**（`F = C + K − P`，天然剔除分红）做择时后，IC 当月策略年化 6.9% → 19.05%、最大回撤 36.56% → 17.83%。这是"期限结构斜率作为收益来源"在股指上的完整实证，与跨期套利共享贴水定价基础。

#### 3.1.5 政策冲击实证

JoinQuant 股指跨期协整套利（详见 §4.5）：2010.5-2016.12 回测有效，但 **2015 年 9 月中金所收紧政策后（平今仓手续费提高约 100 倍、单账户限仓 10 手）套利空间基本消失**——跨期套利对交易成本与持仓限制的政策敏感性有完整实证。

### 3.2 国债期货（TS/TF/T/TL）

#### 3.2.1 跨期价差三因子定价

由期货定价公式直接推导（方正证券；建行期货；华泰期货三因子模型对价差走势解释力约 **87%**，23 个月份中 20 个方向可解释）：

```
跨期价差 = F_近 − F_远 = CTD券净价之差 − 净基差之差 − 持有收益之差
（若近远月 CTD 同券，后两项主导：价差 ≈ 净基差之差 + Carry 之差）
```

**分品种驱动差异**（方正证券 2026 专题）：

| 品种 | 核心驱动 | 机制 |
|------|----------|------|
| TL（30年） | CTD 券净价之差（绝对主导） | CTD 集中特定久期老券、可交割券久期差距大，近远月交割券范围差异 → CTD 切换主导 |
| T（10年） | 净基差之差（相关系数全品种最高） | 交割期权价值 + 市场情绪主导 |
| TF（5年） | 净基差之差（强负相关） | 同 T，资金面影响更直接 |
| TS（2年） | CTD 券净价之差 | 票息有限、交割期权影响弱 |

**Carry 的方向性结论**（华泰证券）：只要 CTD 票息高于融资成本，远月比近月多一个季月正 Carry → 远月理论价更低 → **近减远常态为正**；融资成本上行收窄 Carry 推动价差下行（资金成本上行 10bp 对 TL 跨期价差静态影响约 0.03 元，解释力有限——Carry 是中枢锚而非波动源）。

#### 3.2.2 移仓博弈（核心交易逻辑）

- 移仓时点多在**交割月前一个月中旬**，以持仓/成交量变化为切换信号（方正证券）；
- **多头主导移仓 → 价差先缩小后走阔；空头主导移仓 → 先走阔后缩小**（建行期货）；
- 移仓主导方判断——**IRR 法**：当季 IRR 高（>1.5%）→ 空头交割有利润不急移仓 → 多头主导；IRR 低/负 → 多头反套交割意愿强 → 空头主导。T1603 以来 28 个跨期价差样本验证准确率约 **60%**，须结合环境（建行期货）；
- 华泰期货从基差交易视角：当季净基差显著为负 → 多头倾向移仓 → 价差下降；显著为正 → 空头倾向移仓 → 价差上升；
- 次季合约净基差与**利率预期**相关：债市极度悲观 → 空头在次季建仓 → 次季净基差扩大 → 价差走阔（T1612、T2006 均现于牛熊拐点）；
- 结构演变：2022 前空头主导（价差走阔）→ 2023-2024 多头主导（收敛）→ 2025 后 CTD 规律变化（久期越短越易成 CTD），主力与远季 CTD 不一致使**远季升水成为常态**（国泰君安期货）；
- 操作纪律（华泰证券 TL 案例）：负价差本身不构成止跌条件（TL2506-T2509 曾从 0.24 继续压至 0.72）；应结合远月持仓占比（如 12.5% vs 历史中位 21%）、CTD 稳定性确认后，按 **CTD DV01 配比**（而非手数）入场。

#### 3.2.3 交割期权视角

净基差近似等于交割期权价值（空头选择最便宜券交割的权利）：长久期券基差类似利率看跌期权、短久期类似看涨、中久期类似跨式（建行期货）——利率波动率上升时远季交割期权价值上升更快，跨期价差承压。这是把 §2.5 的"波动率期限结构"逻辑落到国债月差的通道。

### 3.3 商品期货

#### 3.3.1 持仓成本与交割成本（成本法的锚）

```
持仓成本 = 仓储费 + 过户费（部分品种） + 交易/交割手续费 + 资金占用成本 + 增值税
```

铁矿石 I2001-I2005 模拟交割成本实测（股票学习网）：交割手续费 1 + 出入库 40 + 仓储 60（120 天×0.5）+ 手续费 0.13 + 资金成本 5.28 + 增值税 4.43 ≈ **111 元/吨**——价差超此值正向交割套利才有安全边际（历史满足条件的机会稀少：2016.12、2019.8 两次短暂窗口）。各品种仓储费差异巨大（棉花内地库 18 元/吨·月、大豆分季节 4-18、铜库房 12，MBA 智库）；**增值税**按交割结算价差计税、事前不可精确估计，且各品种交割结算价口径不同（加权均价/配对日结算/最后交易日结算）。

#### 3.3.2 库存-仓单-月差实战框架

- **低库存 + 仓单稀少 → 近月溢价乃至逼仓**：纯苯港口库存同比 −75% 且无仓单可交割、乙二醇港口库存历史新低叠加近月持仓异常偏高时，"期货只能向现货靠拢"（中信期货、天富期货、叩富网能化系列）；液体化工品（乙二醇/甲醇/纯苯/苯乙烯）储存成本高、库存天然低，对库存极度敏感，月差弹性大（中信期货）；
- **高库存 + 巨量仓单 → 近月受压**：Contango 加深，正套逻辑；
- 标准研究配置：基差、月差、仓单、库存（工厂/港口分列）、开工率、进出口、成本利润（国泰君安甲醇周报范式）；

#### 3.3.3 季节性与合约组合选择——动力煤完整案例（七禾网）

动力煤主力合约为 1/5/9：**1 月为冬季旺季合约、5/9 为淡季合约**，淡旺季结构造就价差规律：
- 01-05 价差（近-远口径）：1501-1505、1701-1705 最终均由小至大（旺季合约临近交割走强）；价差中值随供给格局上移（5.1 → 11.0 → 28.6）——**统计规律要放在供给周期背景中解读**；
- 05-09 同处淡季，价差无序波动，须细分驱动力；
- 风险清单（原文直接给出）：近月逼仓风险（持相反头寸损失大）、合约流动性差异（部分合约丧失资金关注）、驱动力改变应及时止损、**交割型跨期的品质变化风险（动力煤"掉卡"——热值衰减）**，无解决方案时不建议参与交割型套利。

#### 3.3.4 规则细节（价差的制度性扭曲源）

- **仓单有效期**：橡胶、塑料等品种仓单有有效期，有效期前后合约价差被制度性扭曲（宽客在线）；
- 交割基准地调整、质量标准变更使规则生效时点前后价差结构性跳变；
- 交割月前保证金阶梯上调、个人客户不得进入交割月 → 投机头寸强制了结/移仓（中国期货网）。

## 4. 策略方法体系

### 4.1 成本法 / 正向交割模式（模拟交割法）

以完整交割成本为锚，价差（远-近）> 持仓成本时买近卖远持有至交割：`套利利润 = 远近价差 − 持仓成本`。
- 优点：产业客户（可接货、可开票）接近无风险；棉花 505/507（价差 455 元）、大豆 a0705/a0707（113 元）案例年化保守 10%+（MBA 智库）；
- 缺点：机会稀少；占用资金大（全额货款+保证金）；增值税不确定；投机客户无法交割，"无风险"不成立（tipdm 明确批驳"套利无风险"误区）。

### 4.2 价差趋势模式

价差趋势一旦形成不易反转，顺势交易突破（宽客在线四模式之二）。适合结构性趋势市（去库存周期中持续 Backwardation 化），与回归型策略互补。

### 4.3 固定/统计价差法（标准距离法）

历史分布 μ±kσ 反向开仓。**致命弱点：价差分布不稳定、依赖统计区间**——上期所经典例证：统计 2010 年 4-9 月认为价差超 50 点已极高，后期实际超 100 点。长城伟业历史模拟法实证：119 交易日仅 10 笔交易（止盈 2、止损 6、到期 2），四倍杠杆约 6%——固定参数对样本极其敏感。

### 4.4 移动均值回归模型（布林带类）

N 期滚动均值±mσ 动态阈值。新世纪期货实证（IF/IC/IH，2015-12~2018，15 分钟，N=30，±2σ，隔夜，单边费万二）：

| 组合 | IF | IC | IH |
|------|-----|-----|-----|
| 次月-当月 年化/回撤/胜率 | 13.35% / 0.54% / 91% | 14.98% / 0.98% / 89% | 15.06% / 1.19% / 92% |
| 下季蝶式 | 10.89% / 1.09% / 89% | ≈同上 | 13.72% / 0.83% / 87% |

次月-当月全面优于季月组合（流动性），蝶式略逊。

### 4.5 协整与误差修正模型

交易**回归残差**而非原始价差。参数体系：对冲比率（回归系数）、开仓 a / 止盈 b / 止损 c（国外常用 0.75/0.1/2，须按品种优化——上期所：同一沪铜跨市组合不同参数 +18.28% ↔ −10 万元）。

**完整可复现规则**（JoinQuant 股指跨期套利，分钟级）：
1. 取过去 240 分钟近/远月收盘价对数化，ADF 检验同阶单整；OLS 回归 `ln F2 = A + B·ln F1 + resid1`，resid1 通过 ADF（如 t=−4.32, p=0.0004）确认协整；
2. 交易期实时计算 `resid2 = ln F2 − B·ln F1 − A`，标准化 `resid3 = resid2 / std(resid1)`；
3. 规则：`1 < |resid3| < 2` 开仓（价差偏离但协整未破坏）；回归至 0 平仓；`|resid3| > 2` 止损（视为协整关系已破坏）；
4. 成交量限制为下一分钟两合约成交量的 1/10（控制冲击）；
5. 结果：2010.5-2016.12 有效，2012 年成熟期机会减少+高频手续费致回撤，2012-2015 三年最大回撤 18%，**2015.9 政策收紧（平今手续费×100、限仓 10 手）后套利空间消失**。

### 4.6 变结构协整（方兆本等 2015）

普通协整"对变结构价差缺乏解释能力"→ 引入虚拟变量 `D_tτ` 刻画结构突变点 τ，模型族覆盖常数漂移/常数+趋势/常数+趋势+系数漂移三类；以残差白噪声性质设 aσ/bσ/cσ 阈值。实证：30 组对比中 27 组交易更多、30 组年化收益全部更高、26/30 组夏普更高——**全面优于普通协整**。

### 4.7 GARCH 波动率自适应（上期所）

价差/残差存在 ARCH 效应（波动聚集）→ GARCH(1,1) 时变条件方差标准化：`z_t = ε_t/σ_t`；开仓 |z|>2、平仓 |z|<0.5、止损 |z|>3。优点：平稳期灵敏、剧烈期阈值自动放宽。工程细节：每日重估；ARCH/GARCH 系数越界（<0 或和>1）时舍弃本次估计沿用上期。与布林对比：GARCH 有向前预测性，布林只回溯。

### 4.8 Kalman 滤波动态对冲 + OU 半衰期（QuantInsti；中高频硕士论文）

Kalman 回归动态估计对冲比率 β_t（无窗口长度、更权重近期）→ 价差 = Y − β_t·X → ADF/Hurst 验证 → 价差对自身滞后回归估**半衰期** → 以半衰期为窗口计算 z-score → ±2σ 开仓、0 平仓。实证（中国期货组合）：样本内总收益 16%、日夏普 4.39；样本外 2.8%、夏普 2.38（未计滑点手续费，为最大局限）。

### 4.9 随机控制最优阈值（固定阈值的"理论最优"替代）★

Leung & Li（2015, IJTAF；2016 专著《Optimal Mean Reversion Trading》）把"何时进、何时出、何时止损"表述为**最优双重停时问题**，OU 价差下得到解析解：

- **入场区域是有界区间 [a\*, d\*]，严格高于止损位 L**——若当前价虽低但太接近 L，最优选择是**等待**（入场离止损太近意味着大概率止损离场）；等待区域因而不连通；
- **止损位越高，最优止盈位越低**（强制止损的存在使投资者自愿更早获利了结）；止损位高于临界值 `L* = (μθ+rc)/(μ+r)` 时，等待区消失、任何价位立即平仓；
- 交易成本越高，入出场阈值区间越宽（Leung-Li-Wang 2015，XOU 模型）；
- 有限期限版本（Leung & Kitapbayev 2017）：三种策略（先多后空/先空后多/自由选择），最优边界为 **Volterra 型非线性积分方程**的唯一解，需数值求解；
- 相关工作：Elliott et al. (2005) 首次穿越时间入场；Bertram (2010) 最大化单位时间期望收益；Song & Zhang (2013) 最优 switching；Tourin & Yan (2013) HJB 闭式解（协整对动态交易）；Cartea-Jaimungal-Penalva《Algorithmic and High-Frequency Trading》系统教材。

**对工程的含义**：实务常用的"±2σ 开、0 平、±3σ 止损"是 ad hoc 规则；给定 OU 参数（κ、μ、σ）与成本后，Leung-Li 框架可算出**最优**阈值组合，且其结构性结论（止损位抬高应主动下调止盈位、价差接近止损位时不入场）可直接作为规则引擎的约束。

### 4.10 期限结构因子模型套利（曲线偏离交易）★

用 §2.5 的因子模型（Schwartz 两/三因子或 Cortazar-Naranjo N 因子）拟合全曲线，交易"两腿实际月差 − 模型理论月差"：
- 本质是成本法的高阶版：不再假设确定性的 r/u/y，而是让便利收益、利率成为随机状态变量由曲线本身+Kalman 滤波估计；
- 优点：可用全部挂牌合约信息（避免只用主力的拼接偏差）；隐含便利收益可与库存数据交叉验证，形成"模型信号 + 基本面信号"双确认；
- 风险：模型设定误差；曲线可预测性随市场环境变化（Power & Turvey：2005 后农产品曲线更像随机游走）；参数需滚动重估。

### 4.12 蝶式与曲线凸性交易

对曲线**凸性**下注：预期 Contango→Backwardation 切换或中部凸起变平时，买近+买远、卖 2×中间（中国期货网）。风险低于两腿（对冲斜率），但三腿执行复杂。

### 4.13 展期优化与分红/移仓专项

- **分红期限结构套利**（股指）：多 04/05/06、空 09，随近月到期展期（IF 实证 31.6 点/季，§3.1.3）；
- **移仓博弈套利**（国债）：IRR/净基差/持仓迁移判断移仓主导方，最后交易日前 30~15 日窗口做价差（IRR 法准确率 60%，须叠加环境判断，§3.2.2）；
- **滚贴水**（股指）：贴水结构下滚动持有近月多头收割收敛 Alpha（IC 当月 2015-2025 累计 142.5%，§3.1.4）——与跨期套利共享贴水定价基础，但承担单边敞口；
- **展期收益增强**（商品）：Backwardation 中持近月多头滚动移仓（与 GHR 风险溢价理论对应）。

### 4.14 高频/日内跨期

- 豆粕主力-次主力 10 秒 OU 策略（何诚颖）：2010-2013 年 704 交易日 41,235 次交易、累计 980.5%、年化夏普 13.8、回撤 −6.8%、胜率 71%、日均 58 次（万分之一成本、日内不留仓；**10 秒频率实盘可达性存疑，数字代表理论上限**）；
- 关键观察：**价差微观结构随市场成熟变化**——螺纹钢价差 2010 年双峰分布（σ 11.20）→ 2013 年单峰（σ 2.52）：套利者增加使价差波动系统性收窄，**策略 alpha 存在结构性衰减**；
- 日内跨期为宽客在线四模式之四：高速统计确立合约强弱、收盘前强制了结。

### 4.15 执行层：价差指令与保证金制度（国内外对照）★

**CME**：国债日历价差是**单一打包合约**——最小价差 1/32 点的 1/4，两腿分开执行累计价差成本最多省 75%；价差订单簿流动性可超直接合约，大额移仓一价成交（CME 教育材料）。

**国内交易所制度**（网易/叩富网/信易科技/MBA 智库指令说明书综合）：

| 交易所 | 跨期套利指令 | 跨品种指令 | 保证金优惠机制 |
|--------|--------------|------------|----------------|
| 大商所 | **SP**（如 `SP m1809&m1901`） | SPC | 套利指令下单**盘中实时**只收大边；普通下单盘后结算时自动判定单边；组合优先级：对锁 > 跨期 > 跨品种 > 备兑 > 期权组合 |
| 郑商所 | **SPD**（如 `SPD CF809&CF901`） | IPS | 套利指令盘中实时优惠；普通下单需通过期货公司申请（约 14:00 前提交）；郑商所《跨期套利管理办法》：跨期套利持仓**单边收取保证金**；一般月份不限仓，交割月前一月+交割月（套利+投机）≤ 限仓 3 倍 |
| 上期所/上期能源 | 无套利指令 | — | **单向大边保证金**：同品种同客户双向持仓自动取大边，盘中即时生效、无需申请；**最后交易日前第 5 个交易日收盘后不再实行**（风控关键点）；仅限跨期（同品种） |
| 中金所 | 无套利指令 | — | 单向大边保证金（同上） |
| 广期所 | — | — | 支持客户端组合申请、实时释放保证金（信易科技） |

**套利指令机制细节**（大商所/郑商所指令说明书）：
- 以**价差形式**报入（只需报 A−B 价差，无需分别报价）；按**价差优先、时间优先、远近月份同时成交**撮合；成分合约成交价差**不劣于**报入价差；
- 开仓/平仓均可；任一成分合约无持仓不能报平仓套利指令；
- **开盘集合竞价期间不能申报**，连续交易期间可申报；限价指令其他规定适用；
- 有效报价范围 = [A 跌停价 − B 涨停价, A 涨停价 − B 跌停价]；单笔上限按品种（如玉米跨期 2000 手、豆粕类 1000 手）；
- **可用于移仓/展期**：一单完成"近月平仓 + 远月开仓"（卖平展期/买平展期），成交价差优于或等于指定价差——这是跨期套利与移仓执行的原生工具。

**结论**：国内并非"无打包价差指令"——大商所/郑商所有原生跨期组合指令（SP/SPD），上期所/中金所以单向大边制度实现资金效率等效；策略实现应**优先使用交易所套利指令**（同时成交、盘中保证金优惠），CTP 双腿自组腿仅作为上期所/中金所及指令未覆盖组合的替代方案。

## 6. 优势

1. **方向中性、风险低**：价差波动远小于价格波动；Kawaller-Koch-Liu (2002) 证明价差组合方差与 delta 敞口显著低于单腿；arXiv 2026 图学习研究解析证明 CS 策略可比 long-only 实现更高信息比率与更低方差/delta。
2. **胜率与盈亏比特征好**：移动均值类实证胜率 89%~92%、回撤 <2%；产业正套（交割兜底）接近无风险。
3. **机会层次丰富**：从事件驱动（分红、移仓、交割、上市/退市）到统计回归（协整、GARCH、Kalman）到模型定价（因子曲线、随机控制）到高频微观，形成完整频谱，可多组合并行。
4. **理论支撑强且可分层**：平价模型（解析锚）→ 库存理论（经济锚，GHR 非线性关系）→ 因子模型（曲线锚）→ 随机控制（最优阈值），每层都有成熟文献。
5. **基本面可验证**：国债三因子解释力 87%；展期收益与库存消费比相关约 −0.72；分红点位可提前估算；月差是"最可建模的价格变量"之一。
6. **制度红利**：大商所/郑商所原生套利指令（同时成交+盘中单边保证金）；上期所/中金所单向大边；CME 打包价差成本降 75%。
7. **组合分散价值**：与单边策略相关性低甚至为负，尾部风险控制工具（EMD 论文）。
8. **资金效率高**：T+0、杠杆、组合保证金 → 风险调整后收益往往更高。

## 7. 劣势与风险（含极端案例研究）

### 7.1 一般性风险

1. **无收敛制度保证（核心）**：两腿都是期货，价差不必然回归，**必须止损**（上期所："任何跨期套利策略必须要有止损措施"）；国债负价差本身不构成止跌条件（华泰证券）。
2. **价差结构漂移与结构突变**：股指 2015 前后正转负；国债移仓主导方反转致价差与行情相关性由正转负；贴水结构受中性/雪球/政策驱动（§3.1.2）；政策/规则变化使价差制度性跳变；普通协整对变结构无解释力（方兆本）。
3. **波动聚集（ARCH 效应）**：固定阈值在持续高位报无效信号、持续低位空转（上期所）。
4. **流动性风险**：非主力合约盘口稀薄、冲击成本高——远月组合收益系统性差于近月组合；交割周前当月合约流动性断崖产生假信号（SegmentFault）。
5. **单腿成交风险（Legging）**：双腿先后执行，一腿成交另一腿未成交即裸头寸。
6. **移仓与到期风险**：交割月前保证金阶梯上调、流动性枯竭；移仓窗口错误定价高发（Aitken-Frino）；国债 30 合约中 14 个最后 30 日价差收窄与理论反向（华泰期货）。
7. **单笔利润薄、成本敏感**：手续费（平今/平昨）、滑点、冲击成本、保证金利息侵蚀占比大；**2015.9 股指政策（平今×100、限仓 10 手）直接消灭套利空间**（JoinQuant）——政策是成本的突变项。
8. **增值税与交割细节**（交割型）：按交割结算价差计税、事前不可估；出入库/检验/仓单打印隐性成本多；动力煤"掉卡"品质风险（七禾网）。
9. **策略容量有限与 alpha 衰减**：何诚颖：螺纹钢价差 σ 从 11.20 → 2.52、机会系统性减少；QuantInsti 样本外收益为样本内 1/6。
10. **参数敏感与过拟合**：同一协整组合不同参数从盈利到亏损；遍历寻优与 ML 尤甚。
11. **模型风险**：因子模型设定误差、曲线可预测性变化（Power-Turvey）；随机控制方法依赖 OU 假设（真实价差厚尾、跳变）。
12. **逼仓/挤仓极端风险**（详见 §7.2）：近月持仓异常 + 仓单枯竭 + 基差异常时，价差与历史规律完全脱钩。

### 7.2 极端案例研究（逼仓/挤仓事件库）

逼空的四个必要条件（华尔街见闻《LME 市场上，那些逼空的故事》）：**库存/仓单低 + 持仓量大（虚实盘比高）+ 空头集中 + 基本面支持**。对跨期套利的意义：**任何"近月-远月"统计规律在逼仓条件下失效**，反套（空近月）头寸可能承受数倍于历史的损失。

**LME 镍 2022（青山事件）**：
- 时间线：俄乌战争（2.24）→ 俄镍流通受阻 + 低库存 + 空头持仓巨大且集中（青山 20 万吨空头，产品为高冰镍与 LME Class I 交割品**错配**）→ 3.7 镍价收 50,300 美元/吨 → 3.8 盘中 101,365（两日涨幅约 4 倍）→ LME 暂停交易并**取消 3.8 00:00 后全部成交**（名义约 39 亿美元，145 年首次）→ 交割递延、引入涨跌停（5%→8%→12%）→ 青山与银团静默协议、3.16 重开后连日跌停（S&P Global/路透/LME 公告序列，见 InCosmos 事件全记录；环球时报/北京日报报道）；
- 沪伦联动：3.7 沪伦价差倒挂 16,913 美元/吨（腾讯新闻引述）——跨市场价差同样彻底失效；
- 教训：交割品错配（生产的产品≠可交割品）+ 超额空头 + 低库存是逼空温床；交易所规则（取消交易、递延交割）本身就是极端情形下的不确定因素。

**住友铜 1994-1996（滨中泰男/"锤子先生"）**：通过现货操控与仓单集中（最高控制 LME 铜**仓单 90%**）、现货升水多次触及 300 美元；LME/CFTC 干预后铜价一个多月 2,720 → 1,700 美元崩盘，住友损失 40 亿美元（华尔街见闻）。

**LME 铜 2021.10（托克挤仓）**：低库存下贸易商集中提货，LME 铜注册仓单从逾 15 万吨骤降至 14,150 吨（1998 年来最低）→ 铜价破万、现货升水飙至**史无前例的 1,103.5 美元**；LME 被迫修改 Lending Rule、对 T-N 现货溢价设限、引入延期交付机制（华尔街见闻）——近月/现货月价差被制度性干预。

**苹果期货两案例（郑商所）**：
- AP1810（2018）：寒流减产 50%+ 游资产地调研后锁仓买涨，价格 6,500 → 9,235（+38.75%）；空头因不熟悉交割规则（误以为山西纸加膜苹果可交割）被"割韭菜"——**交割规则理解偏差本身就是价差错误定价的来源**（界面新闻）；
- 2023.2：抄底多头在空头（敦和资管）选择交割后**被迫接货 1,500 吨苹果**，"想平仓也平不掉了"——接货后还面临现货销售压力（微信店铺 88 元/箱卖"交割果"）（证券时报 e 公司/腾讯新闻）——**近月流动性枯竭时无法平仓的风险实证**。

**WTI 原油 2020.4.20**：疫情需求崩塌 + 库欣库容耗尽，近月合约结算价跌至 **−37.63 美元/桶**；Contango 极端化、近月展期踩踏（"原油宝"事件）——近月合约的尾部风险可远超历史分布的任何分位。

**动力煤 2021（背景案例）**：供给约束下价格脱离成本区间数月，政策强力干预（限价、增产）后快速回落——**政策市中价差结构被外生力量重塑**，与 2026 能化系列报告描述的"低库存+近月持仓异常→近月逼仓"机制（中信期货/天富期货）同属结构性风险。

### 7.3 制度与政策风险清单

- 交易成本突变：2015.9 中金所平今手续费×100、限仓 10 手（JoinQuant 实证失效）；
- 交易所干预：LME 式取消交易/递延交割/涨跌停引入；国内涨跌停与保证金调整、强制减仓；
- 规则变更：交割基准地/质量标准/仓单有效期调整 → 价差制度性跳变（宽客在线）；
- 单向大边/套利指令规则的边界：上期所单向大边**最后交易日前第 5 个交易日收盘后不实行**——临近交割的保证金占用会阶跃上升，资金管理必须前置。

## 8. 实务要点：制度、工程与风控

### 8.1 交易所制度对照（实现前必查）

见 §4.15 对照表。要点：优先用大商所 SP / 郑商所 SPD 原生指令（同时成交+盘中单边保证金）；上期所/中金所用单向大边（注意最后 5 个交易日失效）；套利指令不能在集合竞价申报；郑商所普通下单需当日 14:00 前通过期货公司申请组合；大商所组合优先级（对锁>跨期>跨品种）影响自动组合结果。

### 8.2 信号与参数工程

1. **完整阈值体系**：开仓 a / 止盈 b / 止损 c / 时间止损 / 交割月前强制减仓，缺一不可；可先用统计规则（±2σ/0/±3σ）上线，再向 Leung-Li 最优阈值迁移；
2. **动态参数 + 结构检测**：滚动窗口均值/标准差；GARCH 每日重估并处理参数越界；变结构协整/CUSUM 突变检测为高阶选项；协整关系定期复检（残差 ADF），失效即停机；
3. **季节对齐**：股指用历史同期（同月份组合）样本；商品按品种季节周期（动力煤 1/5/9 淡旺季）分组统计；
4. **信号过滤**：换月跳空/涨跌停/流动性枯竭跳变不作为信号（SegmentFault 噪音识别）；INE 式"跳变不开仓"规则。

### 8.3 分市场建模要点

- **股指**：校正价差（加回分红点位）后统计交易；跟踪贴水结构（综合基差、中性/雪球规模、IM>IC>IF>IH 梯度）；远季贴水浅于近月的系统性形态；
- **国债**：三因子分解定位当前主导因子（TL/T/TF/TS 各异）；IRR + 净基差 + 持仓迁移三证据判断移仓主导方；**按 CTD DV01 而非手数配比**；Carry 决定中枢、净基差决定波动；
- **商品**：交割成本表（仓储/出入库/增值税）作安全边际锚；库存（港口/工厂）、仓单、虚实盘比作逼仓预警；液体化工与农产品纳入季节变量。

### 8.4 执行工程（CTP）

双腿同时报单、以流动性差的腿为锚；一腿成交后另一腿追单（chase）；部分成交状态机；优先映射交易所套利指令（SP/SPD）与移仓指令（卖平展期/买平展期）；参考 CTP 任务队列模式（优宽量化）。逼仓特征识别（近月持仓异常 + 仓单枯竭 + 基差异常）触发时禁止逆势接刀。

### 8.5 回测工程（数据与陷阱）★

1. **主力/次主力识别**：按成交量（或持仓量）排序动态识别，两指标标准不同须显式声明（SegmentFault）；
2. **连续合约拼接**：切换规则 = 时间窗口（交割周前 5 天）+ 成交量阈值（如次主力连续 3 日 > 主力 60%）联合判断，切太早丢数据、切太晚吃到流动性枯竭；切换点用**前复权因子**抹平换月跳空——**拼接方式不当可使年化收益高估数个百分点**；
3. **价差对齐**：跨期回测不应直接用拼接序列相减（两次拼接误差叠加），应以具体合约对（如 rb2510&rb2601）的原生价格计算价差；合约乘数、最小变动价位对齐；
4. **成本模型**：手续费区分开平/平今（中金所平今费率差异巨大）、滑点、冲击成本、保证金利息全部入回测；政策时段（如 2015.9-2017 股指限制期）显式标注；
5. **保证金**：backtrader 默认逐腿计保证金，无法自动体现单向大边/组合优惠——要么外挂组合保证金计算，要么按大边近似并在报告中注明保守/激进口径；
6. **幸存者与数据质量**：退市合约的尾部数据（流动性枯竭段）要么剔除要么单独标注，避免把枯竭噪音计入绩效。

### 8.6 资金与容量管理

单组合价差亏损 > nσ 强平；单组合仓位上限、总杠杆上限；临近交割的保证金阶跃（上期所单向大边失效、交割月保证金上调）提前 X 日腾挪资金；逼仓情景压力测试（价差扩大至历史 3~5 倍分位 + 一腿停板无法成交）。

### 8.7 风控红线

交割月前 X 日强制了结（个人客户严禁进入交割月）；止损 |z|>3 或等价规则硬编码；事件日历（分红季 5-8 月、国债移仓 3/6/9/12 月中旬、上市/退市日、政策生效日）作为停机开关；单腿失败应急流（立即补腿/对冲/平仓）预演练。
