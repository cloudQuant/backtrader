## 计划检查（当前全部 NOT_RUN）

- 以隔离替身验证 Risk、Execution、Monitor 的未安装、已安装未选择、单选和组合；核对 Risk 失败不绕过、每笔派发绑定、唯一派发 owner、普通监控故障有界且可观察、声明必需的监控门槛生效。跨进程和重启后不双发、不重复更新账本，组件本身不因替身而视为已实现。

- 覆盖崩溃前后 ACK、日志过期、尾消息缺失、断线、重复、滞后成交、费用修正、重连和部分状态持久化。
- 验证切换不双写、不丢失绑定/游标/预留，不可证明时拒绝接管；多进程 direct 缺共享协调明确拒绝。
- 分别记录源码/fake/隔离 wheel/性能及经授权来源的结果，所有 NOT_RUN 不得升级为已通过；未完成即不宣称迭代交付。

## 审阅与证据

- 先交付范围、仓库/分支/commit、引用及差异、检查结果、兼容性和未决项；用户明确审阅后方可开始下一步。
- 每步先完成实现及必要检查，再将变更、证据和未决问题交用户审阅；阻塞或未运行记 NOT_RUN/阻塞，不声称通过；必需检查未完成不得标记完成。
- 区分静态、隔离模拟、安装包、性能与真实来源证据；真实账户读写须另有有效授权。

## 可执行验收矩阵（全部 NOT_RUN）

| ID | 场景 | 可检查预期及证据 |
| --- | --- | --- |
| A10-01 | ACK 前、状态提交后 ACK 前、ACK 后分别崩溃 | 一致游标继续或安全重放去重，无部分提交；保存故障点、事务和 ACK 日志。 |
| A10-02 | 缓冲溢出、尾丢失、水位缺口、日志过期、epoch 变化 | 标不完整并停止推进；证明后才恢复，否则不可用；记录切点、水位和状态转换。 |
| A10-03 | direct → Gateway → direct，旧 owner 与 provider 会话已证明失效，或实际派发出口由可验证 fence 强制约束 | 不双派发、不双写；身份、绑定、账本、预留、去重、游标和审计保留，对账后恢复；记录派发出口及存储 fence 和失效证据。仅存储 fence 不足以通过。 |
| A10-04 | 旧 owner 无法确认、fence 失效或独立 direct 进程无共享协调 | 拒绝接管或相关交易；记录拒绝及无新派发证据。 |
| A10-05 | 超时、部分成交、迟到成交、费用修正、撤单及重复 | 原身份查询、幂等记账；UNKNOWN 不重派，预留正确；记录订单与账本轨迹。 |
| A10-06 | 单账户 10 策略同合约、并发平仓和预算预留，两模式对照 | 一次兼容上游订阅，归属隔离、可平量不超额，同输入账本及 BT 投影一致；记录逐策略结果。 |
| A10-07 | 不完整快照、外部成交、未归属、非原子查询和差异 | 未知不视为零，暂停相关能力；记录差异和可审计恢复依据。 |
| A10-08 | 隔离 wheel、缺可选包、断线和认证失败 | direct 无 Gateway/ZMQ/codec 强制依赖，显式 Gateway 失败无回退；保存环境及调用记录。 |
| A10-09 | 冻结负载下多轮基线与候选 | 保存样本 hash、机器、版本、预热、轮次、预定阈值及全部指标和丢失；不可比较标 NOT_COMPARABLE。 |
| A10-10 | 旧 owner 的账本写入被存储 fence 拒绝，但仍持有可派发的 provider 会话 | 禁止新 owner 自动接管；仅在派发出口实际强制 fence 或旧会话失效可证明、并完成对账后恢复。 |

分别记录源码、fake、安装包、真实行情、获授权模拟账户及真实账户的适用结果、版本和证据。必需项未运行、失败或阻塞，综合验收不能通过；账户写入及历史受限调用须另有有效授权。
