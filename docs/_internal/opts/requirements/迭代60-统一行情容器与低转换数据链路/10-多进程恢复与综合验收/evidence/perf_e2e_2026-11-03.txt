Conclusions
  * Loss, RSS and direct-path thresholds pass in every configuration.
  * Codec: v3 MessagePack is ~11% faster than v2 JSON at equal validation ONLY with the msgpack C
    extension; with the pure-Python msgpack shipped in the shared anaconda env it is 2.7x slower.
    Deployments must check bt_api_base.wire_codec_v1.codec_backend() == "c".
  * Gateway end-to-end p99 <= 5 ms is NOT met on this machine for either encoding; the tail is the
    same order for JSON and MessagePack (v3-C 64 ms vs JSON 77 ms), so it is not caused by the codec
    (max ~0.6 s in every run, consistent with start-up/scheduling, not investigated further).
  * Per INV-12 no end-to-end speed-up is claimed; only the codec-level result with the C extension.
