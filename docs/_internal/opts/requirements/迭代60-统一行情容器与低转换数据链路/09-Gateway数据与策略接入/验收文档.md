## 计划检查（当前全部 NOT_RUN）

- 验证 10 策略单合约共享订阅、退出互不影响、不同授权/频道不错误合并及消费者缺口。

- 测试缺包、认证失败及连接中断不回退；不将模拟网关当作真实 provider 或账户验收。

| ID | 场景 | 可检查预期 |
| --- | --- | --- |

| A09-02 | 不同频道、粒度及不兼容授权 | 不错误合并；未授权订阅、账户/策略读写拒绝且不泄露。 |

| A09-05 | 状态/游标持久化成功及失败 | 成功后一致 ACK；失败不前移 ACK，重复重放不重复记账。 |
| A09-06 | 同 ID 同/不同内容、认证失败和命令超时 | 冲突拒绝；认证失败无派发；未决为 UNKNOWN 并按原身份查询，无自动新派发。 |

| A09-09 | 缺包、认证失败、断线、安装但未选择 | 显式 Gateway 失败不可用且无 direct 回退；未选择时 direct 无需可选包。 |
| A09-10 | 无权客户端尝试订阅其他授权范围的行情、撤权后继续订阅或重连 | 发布端隔离或认证点对点流阻止其收到或解密无权数据；不得仅检查客户端的 topic 过滤。 |

| A09-13 | 相同命令 ID 分别重复相同和不同内容，或实际派发后响应丢失 | 相同内容只返回原有状态，不同内容拒绝；已派发可能性不明时保留 UNKNOWN 并按原身份查询，不重复派发。 |
