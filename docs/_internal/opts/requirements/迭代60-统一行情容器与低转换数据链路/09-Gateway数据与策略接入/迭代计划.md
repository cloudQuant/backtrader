4. **09-D 账户与命令**：宿主组合身份、SDK 单一账本及准入，完成一致切点、账户事件日志、重放、ACK、命令绑定、UNKNOWN 的最低闭环并接入 Broker 策略视图；说明存储、事务和状态 owner。
