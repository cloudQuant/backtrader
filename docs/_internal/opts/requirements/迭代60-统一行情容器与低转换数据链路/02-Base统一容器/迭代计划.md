## 工作顺序

1. 核对 Base 工作区、现有容器/DTO、公开构造器和调用者；确认字段、精度、时间、未知和单位。
2. 冻结发布后所有权、扩展冲突、来源证明分离与兼容策略；列破坏变更和待决 owner。
3. 实现已审定合同及必要适配，保持原生解析和来源绑定独立；不加载 Gateway、ZMQ、codec、execution。
4. 执行隔离合同、变异/并发、旧接口及构建/版本矩阵，登记实际结果和未运行项。
5. 汇总跨仓影响及风险交用户审阅；必需检查缺失记 `BLOCKED/NOT_RUN`，明确同意后才进入 03。

本步不证明场所来源、账户或交易能力。
