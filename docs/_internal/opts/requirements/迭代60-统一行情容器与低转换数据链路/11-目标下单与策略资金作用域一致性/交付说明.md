# 60.11 目标下单与策略资金作用域一致性——交付说明

状态：**实施完成（现货模型；工作树未提交）；单元验证已执行；用户审阅 PENDING**。[总计划](../迭代计划.md) · [需求](需求规划.md) · [设计](设计文档.md) · [验收](验收文档.md) · [验收报告回应](../验收报告回应-2026-11-03.md)

## 1. 实现

- **估值合同** `value_strategy_book()`（`backtrader/service/service_strategy_account_book.py`），政策 `strategy_spot_equity.v1`：权益 = 资金币种现金 + Σ 现货多头 × 行情价 × 乘数。只用**同一份**已对账快照（一次调用只读一次）。
- **输入资格**：快照财务可用且成本完整；单一现金币种（其他币种非零即 `STRATEGY_FX_UNAVAILABLE`）；持仓条款由 SDK `InstrumentTerms.from_version()` 精确解析，BT 佣金模型乘数必须相等（否则 `STRATEGY_INSTRUMENT_TERMS_CONFLICT`）；行情价取对应 feed 当前收盘价，有限且为正，各价 bar 时间差不超过 `Strategy.strategy_mark_max_age`（默认 0）。
- **`order_target_value` / `order_target_percent`**：绑定账本时使用本策略持仓价值与权益；零目标只平本策略持仓、不需估值；任何输入缺失或冲突都在创建订单前抛出带原因码的 `ValueError`。
- **Sizer**：现金型 Sizer（`PercentSizer`、`AllInSizer` 及 Int 版本、自定义）绑定后收到本策略现金；不读现金的 Sizer（`uses_account_cash = False`，如 `FixedSize`）不受影响；Sizer 仅为建议，账本准入原子约束现金。
- **未绑定策略**：保持原账户语义（回测兼容）。

## 3. 兼容变化与残留

- 绑定账本时，原先“静默用账户价值/现金”或“一律拒绝”变为“用策略范围数据，不可用即拒绝”。自定义 Sizer 的 `cash` 参数含义变为本策略现金。
