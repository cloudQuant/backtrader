# 60.11 目标下单与策略资金作用域一致性——验收文档

逐项记录 commit、dirty、Python/依赖、输入、预期、实际、证据等级和复现命令；区分 UNIT/FAKE、INTEGRATION_SIM、PACKAGE 与真实账户。真实账户和已消费调用不得擅自执行或重放。

| 编号 | 输入/场景 | 断言 |
| --- | --- | --- |
| 60.11-A1 | 同账户同一现货：A 多 2、B 多 3，单位价格 100；A 目标价值 300 | 在策略估值输入完整、手续费和数量规则已固定的支持模型下，A 买 1，而非根据账户价值错误卖 2；检查实际订单方向、数量和归属。 |
| 60.11-A2 | 零目标：A 空仓/B 有仓、A 有仓；目标数量 API | A 空仓不平 B；A 有仓只按合法可平量处理；安全零目标是否需权益按冻结合同验证；目标数量行为不意外改变。 |
| 60.11-A3 | 账户权益 100 万，已证明 A 策略权益 20 万、A 标的价值 1 万；目标 10% | 在支持的完整估值模型下，目标为 2 万、差额 1 万，不用账户级 10 万目标。20 万是已证明权益，不是预算。 |
| 60.11-A4 | 账户现金 100 万，A 已证明可用资金 10 万、现货价格 100、Sizer 20% | 建议 200 单位而非账户级 2000；覆盖 `PercentSizer`、`AllInSizer`、整数类及取整，分别按各自百分比配置核算。 |
| 60.11-A5 | 价格、持仓、权益、现金、币种、乘数、费用、时效或完整性缺失；NaN/无穷、身份不符 | 需要该输入的接口明确失败/不可用，验证未调用 buy/sell 和下游提交；不回退 Broker 资金或价值。 |
| 60.11-A6 | 策略 `getvalue()` 不可用、多币种缺 FX、预算存在但权益未知 | 目标百分比明确不可用，预算不冒充权益；若没有任何真实可用的策略估值，则列能力 GAP，不能宣称功能完整。 |
| 60.11-A7 | 缺策略现金、币种不明确；A/B 不同资金；Sizer 子类 | 各子类使用所属策略资金或明确失败；不能自动适配的自定义 Sizer 给出迁移清单。 |
| 60.11-A8 | 现货/期货、空头、多空、乘数、保证金、费用及精度 | 支持项按独立可手算结果核对，不支持项拒绝；不能以现货例子证明期货能力。 |
| 60.11-A9 | direct 与已支持的 service/Gateway，相同事实和政策 | 分别验证范围、结果和错误合同；选择组件缺失或失败不得回退。替身不冒称真实 Gateway。 |
| 60.11-A10 | 策略/账户不匹配、快照版本变化、账本不完整、对账不可用 | 不越权读取、不混合版本，订单提交前失败并可观察原因。 |
| 60.11-A11 | 未绑定单策略及普通多策略回测、显式 Broker getter | 对照修改前行为、订单及数值；Broker 保持账户范围，不声称多策略回测已隔离。 |
| 60.11-A12 | 全部目标下单与内置/自定义 Sizer 调用者 | 清单记录范围、已修复/不适用/GAP 和迁移；现有 `StrategyAccountBookPercentSizer` 的限制不被虚假扩大。 |
| 60.11-A13 | 多策略争用账户资金、连续订单及 UNKNOWN | Sizer 只建议；验证策略和账户准入、预留及未知状态不被绕过。真实组合不可运行时记 BLOCKED。 |
| 60.11-A14 | Analyzer、Observer 和其他资金/价值消费者 | 盘点调用及作用域，未修项列 GAP；不能凭持仓测试通过宣称全部财务消费者通过。 |

需求 R1–R8 逐条关联设计、测试及 PASS/FAIL/GAP/NOT_RUN。关键作用域混用或缺失输入时仍提交订单为 FAIL；必要条件不满足时为 INCOMPLETE/NO-GO。策略权益不可用时，安全拒绝通过不等于目标百分比已完整实现。交付须给出支持矩阵、direct/service 与发行覆盖、兼容变更及未验收项；模拟通过不证明真实账户或生产就绪。
