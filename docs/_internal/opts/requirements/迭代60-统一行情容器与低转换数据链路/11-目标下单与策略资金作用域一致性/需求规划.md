# 60.11 目标下单与策略资金作用域一致性——需求规划

状态：**实施完成（现货模型，工作树未提交）；单元验证已执行，见[交付说明](交付说明.md)；用户审阅 PENDING**。[总计划](../迭代计划.md) · [本步计划](迭代计划.md) · [设计](设计文档.md) · [验收](验收文档.md)

| 编号 | 需求 | 验收编号 |
| --- | --- | --- |
| 60.11-R1 | 绑定策略账本时，目标价值使用本策略、同标的且计价一致的持仓价值，不用账户总持仓价值。 | A1、A2、A5 |
| 60.11-R2 | 目标百分比的分母为明确政策下的本策略权益；预算、现金或账户权益不能直接充当策略权益；缺乏完整估值时明确不可用。 | A3、A5、A6 |
| 60.11-R3 | 普通百分比 Sizer 及受影响继承类使用策略范围的合格资金及明确币种；不可用时提交前拒绝，不回退账户现金。 | A4、A5、A7 |
| 60.11-R4 | 明确资金、预算、权益、估值、价格、币种、乘数、保证金和费用的语义及支持矩阵；不支持的场景明确拒绝。 | A5、A6、A8 |
| 60.11-R5 | direct 与已支持的 service/Gateway 使用一致的消费者合同；快照校验账户、策略、版本及完整性；已选组件故障不静默切换。 | A9、A10 |
| 60.11-R6 | Broker 账户级 getter 保持账户语义，未绑定策略按基线兼容；记录异常、公共 API 和自定义 Sizer 迁移影响。 | A11、A12 |
| 60.11-R7 | Sizer 是建议，不替代账户与策略执行前原子准入；未决和 UNKNOWN 的预留遵循现有合同。 | A13 |
| 60.11-R8 | 盘点目标数量、零目标平仓、其他 Sizer、Analyzer/Observer 等资金及价值消费者；未修项列为 GAP。 | A2、A12、A14 |

策略现金、可用预算和权益是不同概念，分别记录币种、来源、时点、政策、完整性和预留情况。现有 `StrategyAccountBookPercentSizer` 仅是有限现货式建议计算，不自动覆盖期货乘数、保证金、费用、汇率或空头；不能据其存在认定普通 Sizer 已修复。迭代 70 负责未来的回测多策略账本，本步验证未绑定回测兼容及已绑定策略消费者合同。
