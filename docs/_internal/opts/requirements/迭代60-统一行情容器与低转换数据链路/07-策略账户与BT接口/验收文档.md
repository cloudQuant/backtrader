## 计划检查（当前全部 NOT_RUN）

- A/B 预算与账户可用资金独立；覆盖追加/划回、并发预留、部分成交、终态、迟到费用和恢复。
- 验证策略 getposition/close、资金及相关观察者不会读到其他策略结果；账户级 API 不静默变义。
- 单策略和回测兼容单独验证；估值缺失、多币种、逐日结算和未分配费用不能伪造精确权益。
