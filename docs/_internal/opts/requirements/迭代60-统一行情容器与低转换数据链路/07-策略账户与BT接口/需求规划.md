## 范围与需求

- 提供策略范围的持仓、预算、费用和盈亏视图；真实账户资金与持仓为独立且受权限约束的视图。
- 明确 getposition、close、目标仓位、资金/权益以及 Sizer、Analyzer、Observer 的策略作用域和现有单策略兼容。
- 初始分配、调拨和可用预算为内部政策，不把真实账户余额复制给每个策略。

## 完成边界

- 仅交付本步涉及的合同、源码或盘点及引用清单；跨入下一步的能力不得提前声称完成。
- 形成本步交付、兼容/破坏性变化、未决事项和可审阅证据；用户审阅并明确同意后才进入下一步。

## 可追踪需求

| 编号 | 要求 | 验证依据 |
| --- | --- | --- |
| 07-R1 | SDK 基于 06 唯一账本及显式预算/估值政策生成策略视图 | 字段标注账户、策略、币种/合约、版本、水位、来源、时间、完整性及未知原因。 |
| 07-R2 | 内部分配、追加、划回和预留具有稳定操作 ID、权限、审计和原子协调 | 策略预算不是交易所余额；真实账户是独立受权视图。 |
| 07-R3 | 盈亏、费用、权益和可用预算有版本化公式及依赖 | 缺价格、乘数、费用、汇率或结算依据时未知/过期，不填零。 |
| 07-R4 | 框架可信绑定策略和账户上下文 | getposition、close、目标仓位、提交、资金/权益及 Sizer/Analyzer/Observer 作用域一致，无上下文不退回总账户。 |
| 07-R5 | 按 01 决策处理回测、单策略和账户级 API | 列迁移及破坏性变化，账户级查询名称和权限明确。 |
