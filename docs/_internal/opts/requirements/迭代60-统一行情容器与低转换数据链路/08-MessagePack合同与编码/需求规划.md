## 范围与需求

- 设计并实现跨进程标准容器的版本化 MessagePack schema 与可选 codec；原生归一化只做一次。
- 覆盖 Tick、Bar、Order、Fill、Position、账户和策略视图及必要的命令/事件元数据。
- direct 未启用 Gateway 时不要求安装 MessagePack/ZMQ，且其路径不强制加载或执行这些可选组件；预先安装组件不改变模式选择。

## 输入、输出与职责

| 输入 | 输出 | 责任 |
| --- | --- | --- |
| 02–07 审阅的稳定容器、扩展和来源元数据 | 按版本编码的跨进程消息 | Base 管语义和 schema，provider 管原生解析和扩展，可选共享 codec 管编码。 |
| 消息字节及静态注册表 | 标准容器或明确错误 | SDK/Gateway 共用 codec；不以消息字段证明身份、授权或来源。 |

M08-1：覆盖 Tick、Bar、订单观察、单笔成交、持仓、账户/策略视图、命令和结果，分别登记字段、单位、时间、缺失和身份作用域。M08-2：价格、数量、费用用规范十进制字符串；缺失、null 和零不同。M08-3：major 不兼容拒绝；minor 新增字段按关键性表保留、忽略或拒绝，影响业务、身份及权限的未知内容不得静默忽略。M08-4：限制字节、深度、集合、字符串及数值范围，不使用 pickle 或由消息指定的类路径。M08-5：direct 未选择 Gateway 时无需安装、导入或执行 Gateway、ZMQ 和 codec；安装本身不改变路径。跨进程不共享对象引用，接收进程内共享须满足容器所有权合同。
