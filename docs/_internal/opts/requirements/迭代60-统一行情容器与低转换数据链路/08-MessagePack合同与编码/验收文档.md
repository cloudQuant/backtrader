## 计划检查（当前全部 NOT_RUN）

- 固定样本往返检查精度、扩展、字段及时间；截断、超限、未知版本/关键字段明确拒绝。
- 核验编码后接收端直接构造允许的标准对象，记录实际中间对象；跨进程不要求 Python 对象 identity。
- Base/SDK/provider/codec 各自版本和 wheel 矩阵独立验证；未解决的 Python 依赖冲突列为阻塞。
- 分别验证可选组件未安装和已安装但未选择时，direct 均不依赖或执行相应编解码与传输。
