# 分阶段目录查询预算（2026-10-28）

Backtrader `dev` 分阶段 CTP 目录采集原先把剩余时间平均分给各品种；前面的品种响应稍慢时，可能即使总期限足以容纳完整采集，也被单请求限额提前截断。本轮将品种请求上限改为当时的全局剩余时间，保持同一绝对期限、最多 5 秒无进展等待、记录上限，以及完整结束标记、会话、时效和结果校验。慢请求可能耗尽后续阶段的时间；此时整次采集仍失败，不接受部分结果。已进入的阻塞 native 请求不能由期限强制中断。

作者和 Root 使用 `D:/bt_api_py/bt_api/bt_api_ctp/src` 的当前 SDK，分别运行三个受影响测试文件，均为 73 项通过、1 条既有 pytest 配置 warning；独立源码审查通过。测试包括真实 SDK Client/SPI/QueryResult 配合合成请求叶子下的异质耗时、总期限和缺结束标记。首次使用环境中旧安装版 SDK 时夹具初始化失败，未计为通过。

本轮是 SOURCE/SYNTHETIC_QUERY_ONLY；并未连接账户或 provider，不能推断此前 R6 超时的实际原因，也不增加真实行情或正式 AC 通过数。需在新源码提交后重新构建并核验隔离安装包，再准备只读运行。
