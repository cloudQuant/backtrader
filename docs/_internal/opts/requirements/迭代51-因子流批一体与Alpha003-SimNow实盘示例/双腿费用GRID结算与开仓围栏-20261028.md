# 双腿费用 GRID 结算与开仓围栏（2026-10-28）

Backtrader `dev` 的 Journal schema 从 v18 迁移至 v19，增加绑定双腿路线的候选及 GRID 结算记录。结算、事件、来源水位、决策与持久化容量在事务中处理；已有版本的迁移和归档合同保留。该组件信任调用方提交的 Store 事实，不自行证明 provider 数据或物理 tape 行。

独立审查发现第一腿可能获准派发，而第二腿在第一腿成交或成为在途单后因风险事实不完整被阻断，产生未对冲风险。本轮因此在已注册配对 scope 上对两腿 OPEN 的 prepare 和 claim 都强制 fail-closed；CLOSE/CANCEL 保留独立路径。缺少可验证的双腿金额、保证金和损失预留，以及成交/持仓对账前，不得开放此围栏。

作者与 Root 各运行五个相关测试文件，均为 338 项通过、1 条既有 pytest 配置 warning；两项独立源码审查分别核对开仓围栏及容量/迁移。覆盖真实 Store/Broker 投影配合合成查询数据、单 grant、回滚、旧 schema 和撤平路径。

证据为 SOURCE/FAKE_JOURNAL_SETTLEMENT_AND_FENCED_OPEN_ONLY。028 正常策略尚未接入该结算；本轮没有真实行情、账户或双腿开仓验收，也不增加正式 AC 通过数。
