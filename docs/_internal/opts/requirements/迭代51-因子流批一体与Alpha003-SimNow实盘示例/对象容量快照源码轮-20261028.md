# 对象容量快照源码轮（2026-10-28）

Backtrader `dev` 本轮新增有界、只含计数的 live 容量快照，并为因子诊断、cohort 和 RegisteredSim 订单状态提供容量投影。采样上限为 32 次；无界 line、不可观测状态、派单中的订单状态和超限或矛盾的投影均被显式记录，不能当作零或通过。active/UNKNOWN 订单不因终结缓存上限而被删除。

作者与 Root 各运行受影响容量、因子和派单/UNKNOWN 聚焦测试，最终均为 25 项通过；使用当前 CTP dev 源码的完整 Store 测试均为 59 项通过。均有一条既有 pytest 配置 warning。独立静态复核通过，包含 Store 状态与容量标志不一致的两个反例。测试直接注入多个 UNKNOWN 的场景只证明计数边界；真实 UNKNOWN 生命周期使用现有 Store 回归验证。

证据级别为 SOURCE/FAKE_COMPONENT_ONLY。采样器尚未接入 Alpha003 实际运行；调用方仍需绑定同一 run、实际 grid/ordinal、进程身份和串行回调。合成快照与既有 RSS 采样不能替代真实全池运行、对象增长检查或 AC51-23 验收。
