# 手续费刷新唤醒源码轮（2026-10-28）

028 示例在选中品种的手续费查询优先级变化或费用事实更新时，复用现有 cohort 唤醒和策略 idle 路径传递合并通知。通知只促使策略在引擎线程刷新事实，不自行产生决策或开仓；唤醒被拒绝时保留待处理通知并记录有限诊断。

作者与 Root 分别运行真实 Cerebro、QueryRefreshLoop、策略 idle 配合合成查询叶子的焦点测试，各 1 项通过、1 条既有 pytest 配置 warning；独立源码审查通过。该测试覆盖优先级去重、费用事实变化、idle 通知和唤醒返回 false，但不覆盖 CLOSE/CANCEL 或实际下单。

本轮证据为 SOURCE/FAKE_IDLE_WAKE_ONLY。它尚未接通同格费用等待、Journal 最终结算或 OPEN；同步 native 查询也可能阻塞刷新，传入 deadline 不代表调用可被强制中断。没有真实账户操作或新增正式验收通过项。
