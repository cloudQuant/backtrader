## 3. 一致性与有效性硬判据

1. 公开fixture覆盖320/640/1280评价格（必要预热另计）、3/5/20资产。完整矩阵以5资产三长度跑所有模式；3/20重点覆盖异步/缺格/顺序和容量。与50共同规划同一fixture矩阵，已覆盖部分引用run_id，不机械复制测试；50的1/2/6规模不能自动代51的3/5规模。
2. `close_time`、asset/instrument、主力epoch、membership、NaN mask、reason、首有效点、离散rank/分支必须一致。独立连续值沿用冻结数值口径，拟定 `abs(actual-reference) <= 1e-12 + 1e-10*abs(reference)`；实施前与前序正式合同核对，不能测试失败后放宽。
3. native/build与流批比较既看最终值也看open_rank、volume_rank、correlation10。不同物理节点布局按逻辑资产/节点对齐，不能因为面板优化而漏检中间节点。
4. 必须有真实有效值见证；全部NaN、全部拒绝、全部跳过不通过。对实际市场记录每品种有效率，恒定open rank是合法不可用原因，不需要强求每品种都有限；但必须存在可驱动既定策略的有效分数。
5. 实时输入带要保存封存格与实际available_at/接收顺序。离线复算包含原来的gap、主力版本、预热和cutover，不用事后补齐的完美历史替换当时缺失的数据。
6. 确定性回测与fake实时分两层配对：相同因子/参数/授权子集对比信号目标；再固定同一账户、在途、元数据和报价/时间状态对比子订单内容。真实市场价格、滑点、成交顺序不要求等于回测，不能用回测成交冒充真实成交。
7. native/build的数学及策略配对不要求对同一可写账户下两套相同订单。真实写入默认选冻结native模式，build完成同输入只读配对；若两模式分别实单，须分别授权并记录，不能外推未跑模式的账户结果。
8. 已封存输入不能因未来价格/未来主力/重启而改变。研究信号可标记grid时点，回测、COMPOSITION与实际交易的决策/提交/成交均不得早于各自输入可用时点。专测10:00截面在10:00:02才齐的情形：禁止按10:00:00 open回溯成交；只有分钟数据时最早匹配候选为开端不早于提交可用时点的后续bar，不能虚构bar内成交时序。

## 4. 运行规模与性能

以下为拟定门槛，R0记录硬件/OS/Python/SDK、N、队列/line/log容量和策略参数后冻结；如需调整，必须在实际测试前记录理由，不事后改阈值。R3先完成安装、20品种长流和实际全目标池规模的fake容量预检，R4才扩到同规模真实行情；固定容量超限明确阻塞，不临时少订几个品种冒充全池。

- **加速流**：20品种、单Alpha003、至少100,000格，native/build各跑；真实Feed/Cerebro/因子路径，外部叶子可fake，结果流式校验，不把全部参考/结果堆内存。可引用完全匹配的50-27a；实际目标池大于20时另以目标N按同门槛完成100,000格容量预检。
- **真实墙钟**：全目标池只读至少一个完整共同交易session，且在线总时长不少于2小时；需要同时满足AC51-19的100合格截面。正常休市与计划内缺格分别计数，不用加速回放换算真实在线时长。
- **有限值**：至少观察两个可交易候选的不同有限分数，报告rank变动/常量原因。若市场长期无此输入，保留阻塞并在事先固定的新观察窗口继续，不改公式或虚构信号。
- **本机延迟**：20品种单Alpha003，从完整截面全部可用到持久决策（远端RPC之前）p99≤100ms、最大≤500ms；全目标池亦实测同指标并按冻结容量验收。分别报告bar闭合等待、同步、计算、持久化与网络，不能将网络等待藏入“计算完成”。
- **内存**：预热稳定后首末两个等长窗口RSS增量不超过 `max(32MiB, 稳态RSS×10%)`，且line/pending/diagnostic/终结订单缓存无随bar数线性增长；核对对象/容量，不只看RSS。
- **资源与活性**：没有活单/UNKNOWN被为压内存而删除；无重复派发/重复累计成交；等待缺腿时订单回报/查询和idle继续推进；同机空闲profile不忙轮询。日志有轮转/磁盘上限，写失败停止新订单。
- **批路径回归**：保持前序优化输出与已冻结性能门槛；本轮若改共享热路径，使用前序配对方法复测受影响例子，不凭一次耗时声称加速，也不重跑无关已接受账户实验。

4. 在已知可控、无未知风险状态下做一次获准应用重启，用本次保存的合格bar历史预热并接真实live，先对账再恢复新格；预热/切换阶段禁止写入并单独记录，可供50-28b引用。故障无安全依据时继续查询/保持BLOCKED，而非新订单重试。
5. 到期停止新决策，撤销/平仓只针对已授权本策略对象；分别核对远端残单、持仓/成交、Broker状态和本地资源，供51-21b与50-30b引用同一收尾。

若时间窗未产生有效因子、挂单立即成交而未完成撤单子项、限价未成交、某品种缺数据或所选路由失败，保留真实结果并继续修复或另约有限窗口；不得降低AC到“已调用buy”或“已收到tick”。真实换月若尚未遇到，报告只有COMPOSITION通过，不影响已明确限定的一次当前主力实跑结论。
