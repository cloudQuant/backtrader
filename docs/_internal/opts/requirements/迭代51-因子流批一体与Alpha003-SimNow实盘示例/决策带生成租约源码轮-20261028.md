# 决策带生成租约源码轮（2026-10-28）

Backtrader `dev` 的 028 示例增加可选的决策带生成租约。协作进程在创建决策带前取得本地操作系统锁，持有到数据文件完成刷盘和关闭；已有决策带仍以独占创建方式拒绝覆盖。租约文件保留，锁没有超时自动失效。默认路径不启用该功能，正常策略和真实账户尚未接入。

本轮在 Windows 上运行三个相关集成测试文件：28 项通过、2 项 POSIX 专属测试跳过；关闭不兼容的 asyncio 插件后，pytest 报一条既有配置项 warning。测试覆盖真实 Windows 子进程间互斥、进程异常退出后的锁释放、已有文件拒绝覆盖、句柄继承、替换检查、刷盘及关闭顺序，以及初始化写入和刷盘失败清理。POSIX fork 处理经过源码审查，未在 POSIX 环境实测。

证据为 WINDOWS_LOCAL_OS_LOCK_AND_SYNTHETIC_WRITER_ONLY。该锁针对遵循协议的本地进程，不证明不合作的进程无法绕过，也不证明断电恢复、已有带恢复、真实行情、费用查询、OPEN 或正式账户验收。本轮不增加正式验收通过数。
